    DOC2.2 PROFILE SELECTION (STEP 2 OF 4)

    The previously drawn section must be applied to a suitable profile.

    The profile can be linear or curved, in the X/Y plane or vertical. Certain machining modes are then enabled or disabled according to the selection. For example, a curved profile in the XY plane can only be machined with the blade vertical, while the opposite applies to a curved profile in the XZ or YZ plane.

    The profile type is selected using the buttons on the left. The parameters used to define the profile geometry are displayed at the top centre, while a preview of the result is shown at the bottom centre.

    The source document contains conflicting information about blade orientation. Refer to the

    Linear profile

    Set the direction and length. The sign of the Delta Z value follows the Z axis: positive upwards and negative downwards.

    Parameters

    Profile Direction

    Choose between Along X and Along Y.

    Line length (L)

    Horizontal length of the base of the inclined segment, measured between the starting point and the horizontal projection of the end point.

    End point Delta Z (H)

    Height difference between the start and end of the segment.

    Curved profile

    Define the direction, working plane, concavity and geometric characteristics. Any change to the geometric characteristics affects the other variables.

    NOTE

    The maximum radius that can be set is 9999 mm.

    Parameters

    Profile Direction

    Choose between Along X and Along Y.

    Machining orientation

    Select the working plane for the profile.

    Machining type

    Choose between a Concave and Convex.

    Length (L)

    Horizontal distance between the two ends of the arc, i.e. the chord connecting the start and end points.

    Starting radius (R)

    Distance from the centre of the arc to a point on the arc itself; this determines the overall curvature.

    Vertical rise (H)

    Maximum height of the arc relative to chord L.

    Angle width (A)

    Central angle subtended by the arc, expressed in degrees.

    NOTE

    Changing the Length, Starting radius, Vertical rise or Angle width automatically recalculates the remaining parameters.

    Circular profile

    Only the outside is machined, using the blade horizontally. The Guard flag indicates whether the C axis rotates during machining (guard enabled) or remains stationary at C = 0_ (guard not fitted).

    Circular profile parameters

    Starting radius (R)

    Defines the radius from the starting point.

    Guard

    Indicates whether the C axis rotates during machining or remains stationary at C = 0_.
