    DOC2.1.3 OFFSETMOVE SELECTION

    When the Move command is enabled, the window containing the movement parameters appears. The selection can be moved by clicking directly in the drawing area, including with snapping enabled, or by setting the parameters.

    The movement must be confirmed using the OK.

    Parameters

    Position selector
    Moves by the set “Delta” value in the direction of the arrow.
    The central button resets the movement to zero.

    Translation
    Total movement relative to the initial position.
    The numbers in the boxes on the right are used for the “array copy” command.

    Move copy

    When enabled, the function creates a copy of the selected entity and applies the movement only to this copy, leaving the original entity unchanged.

    NOTE

    This command is visible only if the values in the second column of the “Translation” parameter are equal to 1.
