    DOCCORE

    This is the minimum DMES product package. It includes:

    DASHBOARD

    Overview page for machines and stations connected to DMES. It displays machine status, the current job and selected production data.

    AREA INFORMATION

    Detailed machine page displaying real-time data and production data, such as the number of pieces produced and the square metres of slab cut.

    ALARMS

    This page displays the history of alarms generated by the machine over a selected period.

    PRODUCTION

    Page dedicated to production data over a selected period. It displays the number of slabs processed each day and allows an ideal production target to be entered.

    WORK FILE TRANSFER

    Work file management page where a DXF, CSV or ISO file can be selected and sent to the machine for processing.

    REPORT

    Reporting page where a work file name can be searched and a PDF or CSV report generated.
