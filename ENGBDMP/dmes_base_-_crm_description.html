    DOCDMES BASE - CRM description

    By interconnecting production, DONATONI MES BASE provides a single control panel where the status of all managed machines and/or work areas can be monitored in real time.

    Features:

    • OVERALL DASHBOARD: Overview page for the machines and stations connected to DMES, showing machine status, the name of the current job and various production data.

    • INDIVIDUAL MACHINE DETAILS

      • AREA INFORMATION: detailed machine page displaying real-time and production data, such as the number of pieces produced and the m² of slab cut.

      • ALARMS: displays the history of alarms generated by the machine over a specified period.

      • PRODUCTION: page dedicated to production data over a specified period, showing the number of slabs processed each day and allowing an ideal production target to be set.

    • WORK FILE TRANSFER: work file management page where a dxf, csv or iso file can be selected and sent to the machine for processing.

    • REPORT: reporting page with various filters, allowing you, for example, to search for the name of a work file and generate a pdf or csv report.
