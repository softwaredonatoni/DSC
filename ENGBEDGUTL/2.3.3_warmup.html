    DOC2.3.3 WARMUP

    In this section it is possible to modify warmup parameters and start presser, spindle or element pneumatics warmup.

    Commands

    This section collects commands to force the machine to execute warmup cycles.

    Warmup presser pneumatics
    Starts the presser pneumatics warmup.

    Warmup element spindles
    Starts the element spindles warmup.

    WARNING!

    This cycle activates the elements spindles. Remove any piece beneath befor starting.

    Warmup element pneumatics
    Starts the element pneumatics warmup.

    Parameters

    From this section, the user can modify the settings of the warmup cycles.

    Activation time
    Configured activation duration for warmup.

    Element activation offset
    Configured time offset between element activations.

    Number of cycles
    Number of warmup cycles to perform.
