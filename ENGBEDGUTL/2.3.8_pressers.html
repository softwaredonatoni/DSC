    DOC2.3.8 PRESSERS

    Adjust presser corrections, piston speeds and stroke, and apply an X offset.

    Corrections

    In this sectio the user can adjust the parameters for the machines pressers.

    The reference image above the fields shows the presser orientation and follows the configured machine direction.

    Standard piece start descent advance
    Advance distance used to lower the pressers at the start of a standard piece.

    Standard piece end ascent advance
    Advance distance used to raise the pressers at the end of a standard piece.

    After-obstacle descent advance
    Advance distance used for presser descent after an obstacle.

    Before-obstacle ascent advance
    Advance distance used for presser ascent before an obstacle.

    Special piece start descent advance
    Advance distance used for presser descent at the start of a piece classified as special by the machine.

    Special piece end ascent advance
    Advance distance used for presser ascent at the end of a piece classified as special by the machine.

    Piston extension speed
    Configured piston extension speed.

    Piston retraction speed
    Configured piston retraction speed.

    Pressers stroke
    Configured presser stroke.

    Pressers Offset

    X offset
    Offset along the X axis, following the belt direction, of all the machine’s pressers.

    Apply Offset
    Send the entered X offset to the PLC.
