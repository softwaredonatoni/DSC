    DOC2.3.10 WORKINGS

    Set machining depth limits and working parameters.

    Working Parameters

    These values define machining depth limits and working settings.

    Maximum calibration depth
    Maximum depth used for calibration machining.

    Maximum cutting depth
    Maximum depth used for disk cutting.

    Side rectify Z axis initial position
    Initial Z-axis position used for side rectification.

    Pneumatic descent speed
    Pneumatic head descent speed.

    Pneumatic ascent speed
    Pneumatic head ascent speed.

    Chamfer skater quota mode
    Chamfer skater height management mode.

    Synchronize angular sensor positions
    Indicates whether angular sensor position synchronization is enabled.

    Piece ID referenced to edge-side sensor
    Indicates whether the piece ID is referenced to the edge-side sensor.

    Piece height assignment mode
    Piece height assignment mode reported by the PLC.

    Chamfer Z collision tolerance
    Z tolerance used for top chamfer height collision checking.

    Top cutting height from recipe
    Enables or disables the use of the recipe thickness for the top cutting height.
