DOC2 DSLAB

The system allows the user to configure, load and view slab information. The software can be used to:

  • Load individual new slabs

  • Bulk-load new slabs with the same configuration

  • Manage loaded slabs

  • Configure additional features

Sidebar

This bar appears on all the main pages available from it: “Home”, “Browse Slabs” and “Machine settings”.

Menu
This button toggles between expanding and collapsing the sidebar.
When the sidebar is expanded, the button names are displayed.

Home
Returns to the Home screen.

Browse Slabs
Pressing this button opens the “Browse Slabs” screen, as does the corresponding card on the Home screen.

Machine settings
This button provides access to the system parameters page.

Home Screen

When the application starts, the following initial screen is displayed:

The cards shown below allow different actions to be performed by clicking each one.
Each card is described individually in the following chapters.

Take Photo
Selecting this card opens a window for loading a photo of a slab using a connected camera.

Open Photo
When this card is selected, the user can select an image from the device storage.
The selected image is imported as a slab; a new window then opens, allowing its parameters to be set.

Browse Slabs
Selecting this card opens the “Slab List” page, which displays all slabs added to the system.
From this page, the user can search for slabs and view, edit, export or delete them.

Open Photo

This function allows the user to import an image of a slab by selecting it directly from the device storage.

DOC2.1 TAKE PHOTO

This function imports an image of a slab using a camera connected to the device.
When the panel opens, the following screen is displayed, initially without a preview image:

Photo Preview

The Photo Preview is the area occupying most of the central and left-hand part of the panel.
The preview of the currently loaded image can be loaded by pressing the “Take Photo” button.

Parameters

The Parameters section is located at the top right of the panel and contains the following types of parameters:

Main Parameters

NOTE

The “*” symbol next to a name indicates that the parameter is mandatory.

Name
Unique identifier of the slab.

Slab thickness
Actual slab thickness.

Total Thickness
Total thickness of the slab.

Material
Type of stone associated with the slab.

Finishing
Surface treatment of the slab.

Context Parameters

Block
Slab origin code.

Supplier
Company that supplied the slab.

Pack
Logistics and commercial grouping.

Parameter Buttons

Some parameters have dedicated buttons on the right that allow the user to perform specific actions:

Lock/Unlock Parameter
Indicates that the parameter is respectively locked and cannot be modified, or unlocked and can be modified.
The parameter can be toggled between locked and unlocked by clicking this button.

Select
Allows the parameter to be set by selecting from values previously entered in the system.

Take Photo Action

Take Photo
Pressing this button allows the user to take a photo using the camera properly configured and connected to the system.
The captured image is then displayed in Photo Preview.

WARNING!

A photo cannot be taken until all mandatory parameters have been configured.

Bottom Bar

Confirm
After taking the photo and completing the parameters, confirm to open the window that allows additional parameters to be added or modified.

WARNING!

Clicking this confirmation does not yet add the slab to the system; this must be done in the next window.

Cancel
Closes the window without applying changes and returns to the Home screen.

DOC2.2 EDIT SLAB

In this panel, the user can edit and manage a single slab.
The following example window is displayed both when the user adds a new slab and when an existing slab is edited using the dedicated section:

Slab Preview

This section occupies the central and left-hand part of the panel and displays the slab image.

View Tools

These tools, located at the top center of the Slab Preview, allow the user to perform the following actions:

Home
Restores the initial view regardless of any movement made within the preview.

Magnifying Glass
Activates a magnifying glass that temporarily zooms in on the area under the mouse pointer.

Zoom Window
Allows an area to be enlarged by selecting a perimeter with the mouse.

Zoom
Allows the zoom area to be enlarged or reduced.

Pan
Allows movement within the preview area along the X and Y axes.

Rotate
Allows the slab image to be rotated within the preview area around the X, Y and Z axes.

Zoom Fit
Sets the view to the full image size and the preview perimeter.

Perimeter

The perimeter can be set in the Slab Preview and is displayed as follows:

Perimeter
Represents the entire perimeter area in the preview. The perimeter can be resized using the corners, highlighted by yellow circular indicators, and modified using the Perimeter Tool.

Corner
Represents a perimeter corner. To be valid, a corner must be connected to two sides.
The corner can be added, moved or deleted.

Side
Represents a side of the perimeter, which appears only if both adjacent corners are connected.

Perimeter Tools

Rectangle
Allows the perimeter of the slab preview to be set using a resizable rectangle.

Points
Allows the perimeter of the slab preview to be set using the corners.

Perimeter Actions

Remove Last Point
Allows the last point added to the preview perimeter (yellow circle) to be removed without closing the perimeter.

Move Perimeter
Activates the mode for moving the entire perimeter within the Slab Preview.

Delete Point
Activates Delete Point mode: clicking a perimeter corner removes it and recalculates the perimeter using the remaining points.

Close Perimeter
Closes the perimeter by joining the two end corners of the polyline.

Slab Defects

All perimeters present in the image are shown at the bottom of the Parameters section.

At the bottom of the Parameters section, the last area contains a Perimeter list indicating how many perimeters are present.

The first always indicates the perimeter of the entire slab; the others have a red perimeter to indicate defective areas.
The first perimeter in the list refers to the perimeter of the entire slab.
Each subsequent perimeter is shown in red and indicates defective areas to the user, as shown in the following example image:

Buttons

Add
Allows a defect perimeter to be added to the list and to the Slab Preview for configuration.

Remove
Removes the currently selected defect perimeter from the list and the preview.

NOTE:

If only the main perimeter is present in the list, this button is disabled.

Parameters

Main Parameters

NOTE

A red asterisk indicates that the field is mandatory.

Name
Unique identifier of the slab.

Thickness
Actual slab thickness in millimeters.

Material
Type of stone associated with the slab.

Finishing
Surface treatment of the slab.

Recovery Slab
Indicates whether or not the slab is a recovery slab.

Additional Properties

Block
Code of the block from which the slab originated.

Supplier
Origin of the slab.

Pack
Logistics/commercial grouping.

Perimeter Properties

Width
Value indicating the width of the perimeter drawn in the preview.

height
Value indicating the height of the perimeter drawn in the preview.

Area
Value calculated based on the slab width and height.
This field cannot be modified by the user.

Volume
Value calculated based on the area and slab thickness.
This field cannot be modified by the user.

File Location

In the lower section of the Edit Slab panel, the user can view and access the location of the slab image and parameter files.

The absolute path of the image linked to the slab is set automatically. The following buttons are also available to the user:

Open
Opens the image folder in Explorer.

Copy
Copies the absolute path of the image.

DOC2.3 BROWSE SLABS

This tab allows slabs in the system to be viewed, searched, edited, deleted and exported.

Structure

The tab is divided into the following sections:

  • Filters and Sorting

  • Slab List

  • Actions

Filters and Sorting

This section allows filters to be set and slabs to be sorted according to their parameters, using the “Search” action.

Filter

Most filters are used as shown in the Edit Slab panel.
The only exception to the parameters shown previously is the Yes/No parameter (for example, “recovery slab”), which has three selectable states:

Any
Filters while ignoring this parameter.

Yes
Filters slabs whose value is set to yes.

No
Filters slabs whose value is set to no.

Sorting

The advanced sorting system allows the “Add” button at the top right to be used to select the sorting parameters, their order, and whether they are ascending or descending.

Add
Activates sorting parameters by adding them to the dedicated list.

When a parameter is added to the sorting list, it appears as follows:

It has three action icons:

Move
The user can change the order by selecting a parameter and dragging it above or below another one when multiple sorting parameters are used.

Ascending/Descending Sorting
Sets the parameter sorting to ascending or descending order.

Remove
Removes the parameter from the sorting list.

Actions

Search
Searches for slabs based on the filter and sorting settings configured previously.

Clear Filters
Clears all configured filters and sorting settings and restores their default state.

Reload
Updates the displayed slabs to the latest loaded state.

Slab List

This section displays a preview of the slabs in the system, with options to filter and sort the view.

Card

A single card can be selected for editing or deletion.

The following information can be seen in the image:

  • Creation Date: indicates the date and time when the slab was added to the system (top left);

  • Slab Preview: displays the slab image;

  • Name: the first text value (in bold) indicates the unique slab code

  • Dimensions: indicates the slab dimensions (Width x Height x Thickness)

  • Material: material code set for the slab

  • Block: indicates the block set for the slab

  • Pack: indicates the pack set for the slab

In addition to the information, buttons are available:

Open Folder
Opens the image folder in Windows File Explorer.

Copy
Copies the absolute path of the slab image to the clipboard.

Edit
Opens the panel for editing the slab using the data of the selected slab.
This action can also be performed by double-clicking the card.

Layout Size

At the bottom right, two buttons can be used to enlarge or reduce the cards, making the slabs easier to view or allowing more slabs to be displayed at the same time.

Zoom in
Enlarges the cards in the list.

Zoom out
Reduces the cards in the list.

Actions

Edit
Opens the selected slab in edit mode.

Export CSV/PDF
Exports the displayed slabs to the device as a CSV table or PDF list.

NOTE

Only the displayed slabs are exported; if the list is filtered, only the slabs in the list are exported.

Delete
Deletes the selected slab from the system.

DOC3 OPTIONAL FEATURES

This chapter describes the optional features that can be configured during the initial installation by our technician, at the end user's request.

Automatic naming

This optional feature allows the slab Name parameter to be assigned automatically by the system when the slab is created, using the date and other parameters that can be customised by the technician.

WARNING!

The slab name always contains the creation date and time in the format “YYMMDDhhmmss”. Its position (before, after or in the middle) can be configured by the technician on request.

The other slab parameters are used for the parameters included in the name. Numeric values are entered directly, while for text values the full text or a 3-letter acronym formed from the initials can be requested.

The parameter is displayed as follows:

The parameter is set to read-only to prevent changes, but an Edit button is displayed next to it.

The Edit button opens a pop-up as follows:

The user can update the slab name or press the AUTO button to restore the automatically generated name, then click “OK” to update the name.

Parameter removal

This option allows parameters considered unused by the user to be hidden. Their removal can be requested from our technicians during the initial installation.

Set parameters as mandatory

This optional feature allows selected parameters to be made mandatory when creating a new slab, i.e. parameters considered important by the user. This feature can be requested from our technicians during the initial installation.

Bulk Slab Import

This optional feature allows multiple identical slabs to be imported simultaneously.

NOTE

For a detailed description, see the dedicated
Import Slabs
chapter.

DOC3.1 IMPORT SLABS

This section describes the “Bulk Slab Import” optional feature, which allows multiple identical slabs to be loaded into the system. The system then manages the numbering of the slab names. This optional feature can be requested from our technician during the initial installation.

When this optional feature is enabled, the “Homepage” screen is displayed as follows:

Card

A new selectable card is now available:

Import Slabs
This card opens a new window similar to 2.3 Edit Slab, with some additional parameters.

Window

When the window opens, the following screen is displayed:

As can be seen, the screen is similar to Edit Slab, but with some differences.

Slab Preview

Unlike the other methods for adding a slab to the system (Take Photo and Open Photo), the slab can be loaded without an image by creating a simulated slab using a rectangle that represents the slab dimensions.

The size of this image is managed by the parameters in “Bulk Slab Import” (the drop-down menu currently closed). Other image data can also be configured, such as the background color, slab color and distance of the slab from the bottom edge.

The slab perimeter can be modified using the basic “Width” and “Length” parameters.

The Slab Preview becomes the same as in Edit Slab if a slab image is imported using the “Open Photo” button; in this case, the only difference between “Edit Slab” and “Import Slabs” is the ability to bulk-import slabs of the same type.

The following is the situation when a slab image is available for bulk import:

Parameters

Most parameters work exactly as described in the Edit Slab chapter in both cases; the data described below are those in the “BULK SLAB IMPORT” subsection.

Basic bulk import parameters

The parameters in this group are displayed both when creating a “virtual” slab and when importing a slab image.

NOTE

The “*” symbol next to a name indicates that the parameter is mandatory.

Code sequence separator
Adds to the slab name the separator that divides the Slab Name parameter from its sequence number.

From
Sets the number from which slab numbering must start.

No. of slab copies
Sets the number of copies to create.

WARNING!

Enter a number of copies lower than 1000.

“VIRTUAL” slab parameters

The parameters in this group are displayed when bulk import is performed without an image:

NOTE

The “*” symbol next to a name indicates that the parameter is mandatory.

Image Width
Sets the width of the entire image.

WARNING!

This value must be greater than the slab width.

Image Height
Sets the width of the entire image.

WARNING!

This value must be greater than the slab height.

Background Color
Sets the background color of the “virtual” image.

Slab Color
Sets the background color of the “virtual” slab.

Bottom Margin Distance
Sets the distance of the “virtual” slab from the bottom edge of the image.

DOC3.2 IMAGE TEMPLATE

This section describes the “Image Template” optional feature, which allows a background and watermarks to be configured and displayed when the slab is saved. This optional feature can be requested from our technician during the initial installation.

When this optional feature is enabled, the “Homepage” screen is displayed as follows:

Card

A new selectable card is now available:

Image Template
This card opens a new window where the template used to save the image can be configured when a new slab is saved or an existing slab is modified.

Window

When the window opens, the following screen is displayed:

The screen is divided into several sections:

Template Preview

The preview section displays a selected slab with the base background. The image can be modified using the Add Images section on the right.

This section is for display purposes only.

Slab Settings

The preview slab can be managed in this section using the following parameters:

Preview Slab
Sets the slab to preview by selecting it from the list of slabs in DSlab.

Slab in Foreground
Sets whether the slab is displayed above or below the images that are added.

Add Images

Images can be added to the template in this section.

Background

The buttons on the right can be used to perform actions on the image background:

Select Background
Allows an image stored on the computer to be loaded.

Remove Background
Clears the background and restores the default background.

Open Folder
Opens File Explorer at the location of the loaded image file.

Watermark

Images can be added above the background in this section so that they appear in the image.

The buttons in the lower section can be used to perform various actions:

Add
Allows an image stored on the computer to be loaded as a watermark.

Remove
Removes the selected watermark.

Clone
Creates a copy of the image selected in the list.

Open Folder
Opens File Explorer at the location of the loaded image file.

Move
Allows the display order of the watermarks to be changed, giving priority to the one positioned lower in the list.

Watermark Properties

This section is displayed only when a watermark is selected from the list and allows its settings to be modified.

Corner
Sets the image corner from which the offsets are measured.

X/Y Offset
Sets the X and Y distance of the watermark from the selected corner.

Width/Height
Sets the width and height of the watermark.

Opacity
Sets the watermark opacity.

Rotation
Sets the watermark rotation.

Lower Section

The lower section manages all actions for the entire screen, from confirmation to changes.

Reset
Resets all parameters as if no changes had been made since the window was opened.

Save
Saves a copy of the preview image.
