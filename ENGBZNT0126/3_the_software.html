    DOC3 THE SOFTWARE

    The application manages the machine configuration and programming of workpiece processes.
    The following are some of the basic concepts used by the software:

    TOOL

    physically describes the tool by its length and diameter and stores certain essential properties required for its use

    PASS

    a movement performed by the machine, identified by its type and certain parameters

    KIT

    an ordered set of passes performed with a specific tool. Identified by a name, it also includes the required pressure during processing.

    MATERIAL

    identified by a name, it represents an ordered set of kits.

    WORKPIECE

    Work area with a specific thickness.
