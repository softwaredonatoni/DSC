    DOC2.3 USING THE PANEL-MOUNTED CONTROL PANEL

    The control panel contains the joysticks, potentiometers, function buttons and emergency stop button that provide immediate machine control. Other buttons with various functions, including cycle start and stop, are located at the top below the monitor.

    Manual movement is controlled using the joysticks on the control panel, while speed is adjusted using the corresponding potentiometers beside them.

    CYCLE STOP
    Stops any movement and places the machine in a standby state. When the Start button is pressed again, movement resumes from the point at which it was interrupted.

    If a polishing process is being performed (not loaded from ISO), pressing the Stop button causes the machine head to rise rapidly and automatically, moving the polishing plate to the material clearance position.

    NOTE

    Holding the button for more than 5 seconds resets the alarms and completely cancels the movement command.

    CYCLE START
    Starts automatic programs or restarts them after a cycle stop (see above).

    RESET
    Cancels all movements and any programs currently running. It also resets active alarms.

    NOTE

    Do not press the button while manually moving the axes, as this could cause sudden and damaging stops.

    SLOW SPEED
    Enables slow-speed movement ( 2 m/min ) of the axes. This mode is intended for use during manual movements and is indicated by the orange light on the signal tower above the monitor remaining steadily lit and by the “Slow JOG active” message on the monitor.

    WARNING!

    When Slow JOG is active, the speed of all axes, including the X and Y axes, is controlled by the interpolated potentiometer.
