    DOC3.10 OPTIONS

    This page contains controls and data.

    The data include the software version and the machine serial number (SN).

    Minimise
    Minimises the application without closing it, reducing it to an icon on the taskbar.

    Close application
    Closes the application without shutting down the PC.

    Restart application
    Restarts the application.

    Shutdown
    Shuts down the machine completely. Wait until the monitor is completely off before disconnecting the power supply.

    Advanced parameters
    Installer-only area containing certain software configuration parameters.

    Licence data
    Displays the licence data.

    Assistance
    Activates the remote assistance service. See the relevant chapter.
