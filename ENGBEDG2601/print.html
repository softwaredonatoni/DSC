DOC1 PRELIMINARY NOTES

Generalities

The informations contained in this document are applicable only to the software versions listed on the cover page.
It is possible that not all functions explainable by the product are described in the present documentation; in these cases DONATONI MACCHINE SRL is not, however, obliged to guarantee these functions nor to preserve them in future versions.
The present document is provided as attachment 'Section B', software part, of the machine usage and maintenance manual.

Purpose of the manual

This manual provides the necessary usage instructions for proper understanding of the D-Edge program and useful information to find solutions to malfunctions.
Compliance with what is described in this manual determines the proper operation, duration, and operating economy of the machine itself.
The user and maintenance manual of the machine and the present software manual must always be available at the installation site of the plant, in a safe and easily accessible location. If one of them is lost, contact the prevention and protection service manager.
Failure to comply with what is described in this manual, negligence, improper and inadequate use of the machine may result in cancellation, by the Manufacturing Company, of the warranty it provides for the machine itself, and furthermore, the benefits for which this machine was built may not be obtained.
DONATONI MACCHINE SRL remains available to provide prompt and accurate technical assistance and all that may be useful for optimal machine operation and to achieve maximum performance from the machine.
The Manufacturer reserves the right to modify, at its own discretion, this publication and the data contained therein whenever deemed necessary for technical or commercial improvement of the product.

Manual storage

The present Software Manual must be kept throughout the machine's operational life, even in case of transfer to third parties.
To properly save the Software Manual it is recommended:

  • Use the Manual in such a way as not to damage all or part of the Content; in particular it is recommended not to leave the Manual unattended during use and to store it in the assigned place immediately after the end of consultation;

  • Do not remove, tear or rewrite any parts of the Manual for any reason;

  • Store the Manual in areas protected from moisture, heat and other environmental agents that could compromise its integrity or durability;

  • In case of loss or damage to all or part of the Content of this Manual, request a copy of such documentation from the Manufacturer.

DOC2 D-EDGE

The system has been designed to facilitate the operator in the working of pieces. Through the software it is possible:

  • Create recipes for piece workings

  • Check and modify the configuration of the Group and Elements that make up the machine

  • Monitor execution of workings on screen

  • Display statistics related to the machine and the work performed by it

Operational status of the Machine

Operational status of the machine indicates whether it is in Working, waiting for instructions, on alert or in Error.
Each state is associated with a color, visible in the background of the application pages.

Waiting
No working is running, and the machine detects no errors.

Working
The machine is Running correctly, and is working one or more Working Piece.

Error
The machine sensors have detected errors preventing its operation.

Alert
Indicates presence of anomalies to check.

Side menu

The sidebar allows navigation between the different program pages.

Menu
Allows the expansion and contraction of the sidebar.
When the menu is expanded, page names are visible.

Home

Recipes

Statistics
Page that allows viewing of the Machine Statistics and Workings.

Settings
Allows access to the system Parameters page.

Top bar

The active warning and error messages are displayed in the application's top bar. Additionally, the name of the recipe currently loaded on the machine is shown.
The operator can access the alarms page by pressing the messages.

Active Recipe
Current Recipe Name Loaded On Machine.

Error
Error message.

Notice
Warning message.

Bottom bar

Utility buttons are located to the right of the lower section of each screen.

Remote Assistance

Minimize to icon
Allows hiding the program window by moving it to the taskbar.

Stop system

NOTE

INDEX2.1 HOME PAGE

The 'Home' page is the software startup page, where it is possible to view some information and check the machine status during working.

  

Machine View

The main section of this page displays a three-dimensional model of the machine, including its groups and components, allowing the operator to interact with them.

Based on the loaded recipe in the machine, elements and groups are depicted differently. Colored if the current recipe requires them, transparent otherwise.

Disabled Elements

Active Elements

By pressing on the depicted elements, pop-up windows open with some data related to the corresponding component and its respective working group.
Each of these windows allows the operator to view real-time data and configure the group and element parameters.

Machine visualization management

This section allows editing the machine view.

Default View
Set default view.

Front View
Set front view.

High front view
Set top-down front view.

Top View
Set top view.

Restore view
Set zoom to contain the entire machine.

Pieces on the Belt Management

From this section the operator can track the working pieces, and possibly unload them in case of malfunction.

Pieces on the belt
Accounts for the number of pieces on the belt in working.

Delete All
This button, pressed during the working cycle, causes the deletion of all pieces on the belt. The workings will therefore be interrupted and the pressers raised, and the pieces will proceed toward the working area discharge zone at the maximum speed allowed by the belt.

NOTE

If new pieces are inserted without interrupting the working cycle, they will be executed normally.

Belt Data and Management

In the bottom section below the machine preview are some user data and controls for belt management.

Fast belt forward
Command the belt advance at maximum possible speed if the machine is not working.

Belt working speed
This text box allows setting the belt speed during working. Depending on the user's preference, it is possible to select other measurement units (cm/min or m/min).

Decrease/Increase Belt Working Speed
Allow respectively to reduce and to increase by 100 mm/min the speed of the machine's belt.

Ampere consumption
Current absorption visualization.

Current belt speed
Current belt speed visualization.

Management Information

Currently displayed are the management information with the 3 fields Customer, Job and Job Order.
Via the edit button it is possible to modify the informations, or it is possible to modify them remotely through the dedicated .csv shared file.
Once modified, the new informations will be associated with all pieces inserted from the moment of the modification.

Customer
Specify the customer who commissioned the work.

Job
Job ID to perform.

Job order
Item identifier.

Requested Recipe

Edit Job Data
Allows editing the management information assigned to pieces.

Active Recipe Informations

Name

Useful for working pieces that may have different dimensions, but similar thickness.

Dimensions

Edit Recipe

Select recipe

Selection of recipe to activate

DOC2.1.1 USER GROUPS AND ELEMENTS MANAGEMENT

Pressing the machine's three-dimensional model opens windows related to the pressed element and its belonging working group.
In these windows there are two sections with the real-time data visualization and the group and element configuration.

Sections

The informations provided by each window are divided into two sections.

Variables
Allows real-time monitoring of the selected element's variables and its belonging group.

Configuration
Section where the operator must enter data related to the tool mounted on the element. In some cases, it provides tools to control the positioning of the group it belongs to.

Variables

This section allows real-time monitoring of the selected element's variables and its belonging group.

Group

The upper section displays the specific axis quotes of the group. On one side the current quote where it is located, on the other the target quote for recipe working.
Additionally, it is always indicated whether the water for the group is running or not.

Water Operation
Indicate whether water is active or not for the selected group.

Item

The lower part concerns instead the specific variables of the selected element. Those related to spindle start and ampere consumption are always available.
The operator can decide whether to force the disabling of the element regardless of the presence or absence of the related working in the recipe loaded on the machine.

Working status
Indicates whether the selected element is currently being worked on. It will be displayed in green when the spindle is running, grey otherwise.

Ampere consumption
Enables monitoring of the spindle current consumption of the element.

Element Enabled
Forces the deactivation of the selected element regardless of whether the related operation is present in the recipe loaded on the machine.

Configuration

Section where the operator must enter the data related to the tool mounted on the element.

Group

Icons of the workings that the group can perform are shown in the upper part. In some cases, buttons are present that allow managing the group positioning.
In case a group may have multiple configurations, the operator can decide which to use.

Item

In the lower section the operator must enter the data related to the tool mounted on the element. It is necessary to correctly enter these data to achieve maximum precision in the workings.
Always necessary to insert the measurement of the tool diameter.

Calibrator Cleaner Group

Variables

In the section dedicated to the group the Z axis variables are shown. On one side the current quota, on the other the target quota for recipe working.

For both the calibrator and cleaner elements, no additional variables are shown beyond those common to all elements.

Configuration

In the section dedicated to group configuration, the icon for top polishing and calibrate working is displayed.
Below it the button to send the group to the safe position.

Safety Position
Allows the operator to move the calibrator cleaner group to its out-of-the-way position.

Define the dimensions of diameter and thickness for the tool mounted on the calibrator unit group element.

For the calibrator group element, the diameter dimension of the mounted tool must be entered.

Side Edge Polisher Group

Variables

The upper section displays the spindle consumption enabling the oscillation of the group. Above it is possible to see whether oscillation is enabled or not.

Oscillation Status
Oscillation of the group is Running or not.

Below, for each calibrator item, only common variables across all items are shown.

Configuration

In the dedicated group configuration section, the icon of the side polishing working is displayed.
For each cleaner element in the group, the diameter size of the mounted tool must be inserted.

Top Chamfer Group

Variables

In the section dedicated to the group the Z axis variables are shown. On one side the current quota, on the other the target quota for recipe working.

For the calibrator element, the guide positioning dimensions are also displayed.

For the calibrator element, no additional variables are shown beyond those common to all elements.

Configuration

In the dedicated group configuration section, the icon for the top chamfer working is displayed.
Define the dimensions of diameter and thickness for the tool mounted on the calibrator unit group element.
For the calibrator group element, only the diameter size of the mounted tool must be entered.

Bottom chamfer group

Variables

In the section dedicated to the group no axis variables are displayed.
For the calibrator element, the guide positioning dimensions are also displayed.

For the calibrator element, no additional variables are shown beyond those common to all elements.

In the section dedicated to group configuration, the icon for the bottom chamfer working is displayed.
Define the dimensions of diameter and thickness for the tool mounted on the calibrator unit group element.
For the calibrator group element, only the diameter size of the mounted tool must be entered.

In the section dedicated to the group, the dimensions of the Y-axis and the Z-axis are displayed. On one side, the current dimensions, on the other, the dimensions to be reached for recipe processing.

Belt management

This section allows to manage the speed of the belt when a bush-hammering working is executed.

Belt bush-hammer working speed
Speed of the belt when a bush-hammering working is being executed on a piece.

Belt bush-hammer reduced working speed
Speed of the belt in the initial and final interval set for the bush-hammering working.

If enabled, the speed of the belt during a bus-hammering working is changed regardless of the presence of other pieces.
If disabled, the speed of the belt is not changed for the bush-hammer in case other pieces need to perform other workings.

DOC2.3.1 WORKINGS

Each working allows the operator to modify the parameters defining its geometry. The affected dimensions are shown in the preview on the right.

Available Workings

The program provides the following workings.

Top Calibration
Material removal from the top surface of the piece.

Calibrate Top Polishing
Material removal from the top part of the Piece and Top Polishing the same area.

Side Rectify
Material removal from the Piece Edge.

Side Polishing
Side polishing of the piece.

Top Bevelling
Top chamfer of the upper edge of the piece.

Bottom Chamfer
Bottom chamfer of the piece's edge.

Top Cut
Cut on the top surface of the piece.

Lower Cut
Cut on the bottom surface of the piece.

Side Cut
Cut on the piece's side.

Manual positioning cut
Manual cut performed by positioning the disk.

Bush-hammering
Bush-hammering a part of the upper surface of the piece.

Polish top
Polishing a zone of the upper surface of the piece.

Warning!

The actually available workings depend on the machine configuration, i.e., which groups are mounted on it.

Recipe Workings

The workings that make up the recipe are listed within the list in the left section.
Each entry displays a preview of the working, the name identifying it, and some characterizing measurements.

Selecting the recipe displays all defining parameters and a preview. The operator can edit the parameters.
Use the button located to the right of the respective row to remove a working from the current recipe.

Remove Working
Allows removal of the corresponding working from the recipe.

Working parameters

Working parameters may be inserted in the dedicated section.

The specific parameters for the selected working are shown in the top part.
For workings that allow it, the operator can decide whether they must be executed for the entire length of the piece or not.

Pass-through working
Indicates that the working is applied for the entire length of the working piece. If disabled, allows entering parameters for non-through working.

Additional parameters are displayed in case of non-through working.

Start Distance
Space between the start of the piece and the point where the working begins.
Non-passing workings only.

End Distance
Space between the point where to stop the working and the end of the piece.
Non-passing workings only.

In case the advanced recipe has been set, the operator is given more control over non-through working parameters.

Length
Distance between the start point of the working and the point where it ends.
Only for non-through workings with advanced recipe.

Lock measurement
Allows locking the entered measurement. Changing any other measurement will automatically recalculate the locked one.
Only for non-through workings with advanced recipe.

Start Reference From Start
Uses the start of the working as reference if the start of the piece.
Only for non-through workings with advanced recipe.

End Reference From Start
Uses end of working as reference the piece start.
Only for non-through workings with advanced recipe.

Preview

In the right section, a preview of the working is shown on the piece model, highlighting the dimensions the operator must enter within the parameters.

Moving the view on the machine model highlights in green the group assigned to the working.

DOC2.3.2 CORRECTIONS

The advanced parameters panel allows viewing leads/lags of the various operations performed by the group assigned to the selected working and its elements.
The highlighted group is shown in green within the preview with the machine model view.

Sections

The informations provided by each window are divided into two sections.

Base
Allows viewing the parameters defining default behaviors for the group and related elements when performing passing workings.
Non-passing working behaviors are automatically calculated by the machine based on the geometry of the workings to be performed.

Correction
These parameters allow applying fixed positive or negative offsets to displayed actions. They are used to correct any detected delays or advances in the execution of these actions.
Corrections apply to both passing and non-passing workings.

NOTE

All parameter modifications in this panel are disabled for the standard operator; they can only be performed by an authenticated expert using a specific password.

Base

In this section you can view the parameters defining the default behaviors for the group and related elements when performing passing workings.
Non-passing working behaviors are automatically calculated by the machine based on the geometry of the workings to be performed.

NOTE

The parameters always refer to the distance between the center of the element, or group, which must perform the indicated action, and the reference point, whether head or tail, of the piece they must work.
To represent delays, negative values are used. For delays instead, positive values are used.
The zero represents the moment when the reference point of the piece, whether head or tail, is exactly under the center of the element or group in question.

Group

The parameters managing the operation of some specific behaviors of the selected group are shown in the top section.
The timing of water start and end for the group is always indicated.

Water Start
Distance between the piece head and the group center to command water start.

Water End
Distance between the piece tail and the group center to command water end.

Item

Below is the list of parameters controlling each element composing the group. The delays and advances of the element positioning are always indicated.
Additionally, the operator may decide whether to use or not the element for the selected working.

Element Enabled
Enable or disable the group element for the selected working.

Positioning Start
Distance between the piece head and the element center to command its movement to the working position.

Positioning End
Distance between the piece tail and the element center to command its removal from the working position.

Corrections

These parameters allow applying fixed positive or negative offsets to displayed actions. They are used to correct any detected delays or advances in the execution of these actions.
For example, if element 1 of group 5 always performs the positioning start with a 10mm delay, it is possible to set the related parameter to -10 to correct the issue.
Corrections apply to both passing and non-passing workings.

NOTE

The parameters always refer to the space difference between the moment an operation is performed with the element’s or group’s default settings and the moment it is desired to be carried out.
To represent delays, negative values are used. For delays instead, positive values are used.
The zero represents the exact moment when the action is performed using the basic parameters.

Group

The top section is dedicated to corrections of the group operations.
Correction of the advance/delay of water start/end is always indicated.

Correction Water Start
Correction value for the base water start parameter.

Correction Water End
Correction value for the base parameter of water end.

Item

The list below shows the parameters that allow corrections to be applied to operations performed by each element of the group.
It is always possible to set delays or advances for element positioning or spindle start.

Correction Position Start
Correction value for the base positioning parameter of the element.

Correction Position End
Correction value for the base removal parameter from the working position.

Correction Spindle Start
Set value to configure spindle start advance or delay.

Correction Spindle End
Set value to configure spindle shutdown advance or delay.

Calibrator Cleaner Group

Base

Both the calibrator element section and the cleaner element section do not add anything to the already described basic settings.

Corrections

The calibrator element is bound to the Z-axis of the group. If corrections are to be made, it is necessary to act on the group parameters.
In the section dedicated to the group, it is possible to act on the Position delays and advances related to the axis positioning.

Correction Move To Quote Start
Correction value for the axis movement of the group to reach the working position.

Correction Move To Quote End
Correction value for the group axis movement to disengage from the working position.

As a result, in the calibrator element section, it is not possible to apply corrections to the element positioning.

For the cleaner element no other parameters are shown besides those common to all elements.

DOC2.4 STATISTICS PAGE

The 'Statistics' page is the page where it is possible to view the statistics related to the machine and the work performed by the machine.

Categories

The main page provides two buttons allowing access to the specific sub-pages for the desired type of statistics.

Machine Statistics
Usage-related machine statistics.

Processed pieces
Statistics related to the working pieces.

Available at the top left of each screen are the following buttons for navigation.

Back
Allows returning to the Statistics home page.

Reload
Reloads the page.

Machine Statistics

Monitored on this page are the statistics related to machine usage.

Tracking of the following Statistics is kept on this page:

Total Pieces

Number of executed pieces.

Total pieces length

Total length of executed pieces.

Belt advance

Distance traveled by the belt.

Belt operation

Distance traveled by the belt during working.

Belt Operating Time

Belt Operating Time.

Machine Running Time

Machine Running Time.

Machine Working Time

Machine Working Time.

The Machine Statistics page allows viewing statistics through the three panels:

  • Daily Totals

  • Work Totals

  • Machine Totals

Each panel displays statistics concerning the same measured quantities, but with different conditions depending on the observed section.

Daily Totals

In this section there is a chart showing the desired statistics in the selected time frame.

Top bar contains a filter for the statistics to be displayed in the chart.

The first component of the bar allows selecting the desired Statistics.

The buttons allow selecting a time interval, highlighting the selected one in green.

Daily Statistics
Display current day and previous week statistics.

Monthly Statistics
Display last month's statistics.

Annual Statistics
Display last year's statistics.

Total Statistics
Display statistics from always.

Custom Statistics
Display the statistics of the custom time interval.

The custom range can be modified using the dedicated components located to the right of the button. Press the calendar-shaped icon to the right of the date and select the desired date for the range.

Work Totals

In the Work Totals it is possible to view through the circular chart the advancement percentage of the work, calculated as the ratio between the progress made and the final target.

Statistics related to the target quota are displayed at the top left.

Target

Fixed length value for pieces to be worked.

Edit target quota
Allows the operator to edit the target quota for piece working.

Progressive

Length of pieces worked since last reset.

Advancement percentage

Advancement percentage of the work, calculated as the ratio between the progress made and the final objective.

Press the button located at the top right to reset the counters.

Reset counters
Reset the statistics fields within the Work Totals section.

Machine Totals

General statistics for the entire machine activity period are displayed in this section.

Processed pieces

Through this page the operator can filter and view specific information of the executed pieces.

In the list forming the main part of this screen, all working pieces are cataloged. Each row corresponds to a piece.
Pressing the square located on the left allows row selection.
Export the selected statistics using the button located at the top right.

Export
Generate an export file of the selected Statistics.

Filtering Statistics

The filtering bar allows selecting different conditions to filter the Statistics.

Pressing the first bar component allows selecting the property to filter.

Pressing the second component allows selecting the operation to be performed to determine which elements will result after filtering.

The value to be used for the filtering operation must be entered in the adjacent bar to the two components just described.

The selected filter is added to the bar to the right of the button, it is possible to remove it by pressing the X on the left.

Listed below are the buttons useful for performing the operations described above.

Add filter
Add the newly inserted criterion to the active filters.

Remove filters
Removes all applied filters.

If the number of selected items exceeds those visible, it is possible to navigate pages using the numbered buttons at the bottom. The selected page number is highlighted in green.

It is possible to select the number of rows per page that can be displayed.
