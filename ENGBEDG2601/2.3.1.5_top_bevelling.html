2.3.1.5 TOP BEVELLING

    This working allows performing a top edge chamfer of the piece side.

    Parameters

    Vertical Distance
    Specify the vertical distance at which the chamfer working must end relative to the reference edge.

    Horizontal Distance
    Specify the horizontal direction distance at which the chamfer working must end relative to the reference edge.

    Chamfer length
    Specify the diagonal dimension that the chamfer must have.
