    PE0023MUTE ENABLED

    Before proceeding, carefully read the

    SAFETY INSTRUCTIONS

    Description“Muting active” alarm

    SeverityLow01 / 05

    Authorized personnelMachine operator

    Required PPE:

    Description

    The "Muting active" alarm is generated automatically whenever the mode selector key is removed from its designated position on the console. 
    To reset the alarm, insert the safety key into the console and enable work mode.

    Symptoms

    …..

    Possible causes

    1. Mode selector key not inserted or set to 0;

    2. Faulty or incorrect electrical connection;

    Possible solutions

    1. Turn the key or insert it into the designated slot (the selector must be set to one)

    2. Check that all connections are correct; refer to the

      Electrical diagram
