PE0000GENERAL EMERGENCY

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionGeneral machine emergency

SeverityLow01 / 05

Authorized personnelMachine operator

Required PPE:

Description

Machine in an emergency condition: the red light is flashing and the machine does not move. The emergency circuit is open.

Symptoms

  1. Flashing red light

  2. The machine does not move

Possible causes

  1. Emergency stop button pressed;

  2. Emergency stop button fault;

  3. Fault in the safety control unit inside the electrical cabinet;

  4. Faulty multicore cable connecting the console to the electrical cabinet;

Possible solutions

  1. Release the emergency stop button:

  2. Check that the emergency stop button and the connected electrical contacts located underneath it (console push-button panel) operate correctly;

  3. Check that the safety control unit operates correctly. After verifying, according to the electrical diagram, that the emergency circuit is closed, the control unit must operate as follows:

    1. With the emergency stop button pressed (emergency circuit open):

    2. With the emergency stop button released (emergency circuit closed):

  4. Check continuity between the cables connected to the emergency stop button contacts and the corresponding cables connected to the relevant terminal block in the electrical cabinet; refer to the electrical diagram for the information;

SAFETY INSTRUCTIONS

DescriptionMachine mains power failure

SeverityModerate02 / 05

Authorized personnelMachine operator

Required PPE:

Description

The machine is not supplied by the mains because the supply voltage is absent.

Symptoms

…..

Possible causes

  1. No incoming voltage at the electrical cabinet;

  2. Faulty voltage relay on the UPS or incorrect connections;

Possible solutions

WARNING!

Assistance from a Donatoni technician on site or an electrician is recommended.


  1. Using a multimeter in AC mode, check whether voltage is present at the input of the machine main switch. If no voltage is present, the problem is upstream of the machine;

  2. Check that 220 V AC is present at the input of the voltage relay on the UPS and that 0 V DC is present at the output (the relay must be connected NC);

PE0006WORKTABLE PUMP THERMAL PROTECTION ACTIVE

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionWorktable pump thermal circuit breaker active

SeverityModerate02 / 05

Authorized personnelMachine operator

Required PPE:

Description

Fault in the worktable lifting system; the motor protection circuit breaker for the worktable has tripped. It protects the system against both short circuits and overloads. To reset the circuit breaker, move the selector to 0 and then to 1;


Symptoms

…..

Possible causes

The causes can be divided into problems Mechanical or Electrical

Mechanical problems:

  1. Oil pump motor jammed; try starting the worktable pump and check whether it actually rotates. If it is completely jammed, replace the oil pump;

  2. The oil level inside the tank is insufficient;

  3. The oil level inside the tank is low and the oil is very dirty, or the filter is dirty;

  4. Tilting worktable jammed


Electrical problems:

  1. Short circuit between motor phases;

  2. Missing phase;

  3. Short circuit in the motor windings;

  4. Faulty circuit breaker

Possible solutions

The photos below show the pump with the relevant points of interest marked;

MECHANICAL

  1. First, check that the motor cooling fan rotates freely; for example, try moving the fan with a screwdriver. If it is jammed, the pump must be replaced.

  2. Check the oil level with a clean dipstick and check for deposits at the bottom:

    1. If the level is low, top up with grade 32 oil and periodically monitor the system. If it becomes empty again, there may be leaks;

    2. If there is a lot of dirt, drain the tank (there is a plug in the tank), clean it with diesel fuel, and then refill it;

  3. Check that the piston joints and the worktable joints are not jammed, then grease them at the relevant points.


ELECTRICAL

WARNING!

Assistance from an electrician or a Donatoni technician on site is recommended.

  1. Check that there is no continuity between the phases; disconnect the cable from the pump electrical box, insulate the terminals, reset the circuit breaker and activate the oil pump. If it trips, the problem may be the cable;

  2. Measure the input voltage with a multimeter and verify that all phases are present. If, for example, one phase is missing, check that all terminals are tightened;

  3. If, when carrying out the test in point 1, the circuit breaker does not trip, connect the cable to the pump. If the circuit breaker trips when the pump is started, the problem is the pump and it must be replaced;

PE0008COLLISION LIMIT SWITCH ACTIVE

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionCollision limit switch sensor active

SeverityLow01 / 05

Authorized personnelMachine operator

Required PPE:

Description

The state of the collision limit switch sensor located above the Z-axis ball nut has changed.


Symptoms

…..

Possible causes

There are several possible causes for this error:

  1. The machine is stuck in the material or in the worktable, so the sensor above the Z-axis ball nut is covered;

  2. The sensor is faulty

  3. The cable from the sensor to the passive distributor on the carriage is faulty;

  4. Possible faults in the cables from the passive distributor to the electrical cabinet

Possible solutions

  1. Press the reset button on the console to clear the collision error message, then slowly raise the Z axis until the machine is clear of the worktable/material

  2. Check the operation of the sensor: verify that the LED on the sensor is on, and that the LED switches off when a metal object is placed in front of the sensor. Replace the sensor if it is malfunctioning;

  3. If the sensor is off, try changing the input on the passive distributor and check whether the sensor switches on (for example, connect it in place of the X-axis sensor). If there is no difference, the problem may be the cable or the connections up to the electrical cabinet.

PE0015SPINDLE OVERCURRENT

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionSpindle overcurrent alarm

SeverityModerate02 / 05

Authorized personnelMachine operator

Required PPE:

Description

During automatic working cycles, the PLC may generate a spindle overcurrent alarm when the maximum load capacity of the relevant motor is exceeded. The threshold is set according to the type of machining and therefore to the spindle speed.

Normally, start a machining operation and observe the saw blade/milling cutter current draw; then set the threshold value 3/5 A higher than the value drawn during normal operation.

Symptoms

…..

Possible causes

  1. An incorrect alarm threshold value has been set for the type of machining;

  2. Spindle current draw is too high due to machining at excessively high speeds.

  3. Tool not suitable for the type of machining being performed

  4. Bearings to be replaced

Possible solutions

  1. Correct the ampere threshold value

  2. Gradually reduce the speeds until the correct speeds are found

  3. Check whether the tool is suitable for the machining operations being performed and whether it is excessively worn and therefore no longer cuts properly

PE0021TILTING TABLE NOT IN POSITION

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionTilting table out of position

SeverityModerate02 / 05

Authorized personnelMachine operator

Required PPE:

Description

The tilting table is not in the parking position.

Symptoms

…..

Possible causes

There are several possible causes for this alarm, both mechanical and electrical:

For the machine, the table is not in the parking position. The possible reasons may be:

  1. The table is tilted and does not touch the limit switch;

  2. The table is in the parking position but does not touch the limit switch;

  3. Faulty table limit switch;

  4. Fault in the connection between the table limit switch and the electrical cabinet.

  5. For a mechanical reason, such as broken hoses, insufficient oil or a faulty pump, the table cannot be returned to the parking position

Possible solutions

WARNING!

With the alarm active, the machine cannot be moved. Therefore, if the machine is not in the parking position, it will be locked. In Parametrix, open the first "Padlock", press the "Wrench_Screwdriver" button and disable the table. (For older Parametrix versions, open KvIsoGui.exe, enter the restricted area using the password: "esagv", and disable the "Table" optional.).


After making sure that the machine is in the parking position, carry out the following procedures:

  1. Use the appropriate selector on the console to move the table to the parking position;

  2. Physically check whether the table in the parking position touches the sensor. If it does not, check whether the table stops against the bolts; if so, adjust the sensor so that it is actuated by the table;

  3. Open KvIsoGui.exe, press the "Menu" button, open "I/O Monitor" and, by pressing the limit switch, verify that the corresponding input operates correctly. (FC_SUPP_LOW AT %IW4.13; * IW4.13 lower table limit switch)

    1. If the input does not change state, use a tester to check whether the limit switch operates correctly (for example, if the probes are placed on the NO terminals, pressing the limit switch must close the contact)

    2. If the limit switch operates correctly, check the connections; follow the

      Electrical diagram

  4. Check that the pump operates correctly and verify that the system is not actually faulty;

NOTE: Remember to re-enable the table

Description

Fault in the worktable lifting system; the motor protection circuit breaker for the vacuum pump has tripped. It protects the system against both short circuits and overloads. To reset the circuit breaker, move the selector to 0 and then to 1;

Symptoms

…..

Possible causes

The causes can be divided into problems Mechanical or Electrical

Mechanical problems:

  1. Vacuum pump motor jammed; try starting the vacuum pump and check whether it actually rotates.

  2. The vacuum pump tank is empty

Electrical problems:

  1. Short circuit between motor phases;

  2. Missing phase;

  3. Short circuit in the motor windings;

Possible solutions

MECHANICAL

  1. First, check that the motor cooling fan rotates freely; for example, try moving the fan with a screwdriver. If it is jammed, it is necessary to

  2. Fill the tank up to the overflow level


ELECTRICAL

  1. Check that there is no continuity between the phases; disconnect the cable from the pump electrical box, insulate the terminals, reset the circuit breaker and activate the oil pump. If it trips, the problem may be the cable;

  1. Check the pressure gauge on the machine's main air distributor and verify that at least 6 bar is present. If not, set the pressure to six bar using the regulator and check that at least 6 bar actually reaches the system.

  2. If the pressure gauge reads 6 bar, turn the screw inside the sensor half a turn clockwise and check whether the alarm disappears. If it does not disappear, use the input map in the software to check when the signal is active

  3. If the alarm does not disappear despite adjusting the sensor, disconnect the sensor and connect the sensor wires together. If the alarm disappears, the sensor is faulty.

  4. If the error message lasts for a few seconds and then disappears, it is probably caused by a pressure drop; monitor whether the pressure drops frequently

PM0011PROBE PISTON OUT OF POSITION

Before proceeding, carefully read the

SAFETY INSTRUCTIONS

DescriptionLock due to probe piston out of parking position

SeverityModerate02 / 05

Authorized personnelMachine operator

Required PPE:

Description

A lock is applied if the probe piston is not in the parking position. All axes are set to "hold".

Symptoms

…..

Possible causes

  1. Piston position slightly beyond the threshold

  2. Probe piston faulty

  3. Wiring error

Possible solutions

Check the IW40 value relating to the slab probe position.

  1. If the value read is below 100, the threshold value is most likely too low. In this case, in the KvIsoGui interface open EditorShared - Parameters - Slab Probe and change the value "Parking position" = 100

  2. If the value read is above 100, check the actual probe position and carry out the electrical checks according to the machine electrical diagram.

  3. If the fault cannot be found, the slab probe can be disabled to clear the alarm (with the slab probe disabled, the probing result, if performed, is fixed at 30 mm)
