    PE0028A AXIS NOT IN THE CORRECT POSITION

    Before proceeding, carefully read the

    SAFETY INSTRUCTIONS

    DescriptionA axis out of position

    SeverityLow01 / 05

    Authorized personnelMachine operator

    Required PPE:

    Description

    The system generates the message "A axis not in the correct position" whenever the "Parking" button or the "Manual tool change" button is pressed and the "A" axis is not in the correct position (zero degrees).

    Symptoms

    …..

    Possible causes

    The parking P button was pressed while the A axis was not at 0.00_.

    The manual tool change button was pressed while the A axis was not at 0.00_

    Possible solutions

    1. Move the A axis to 0.00_ before pressing the parking or manual tool change buttons
