Technical troubleshooting sheet Emergency diagnostic procedure

    PE0008PE COLLISION ENABLED

    Before proceeding, carefully read the

    SAFETY INSTRUCTIONS

    DescriptionCollision limit switch sensor active

    SeverityLow01 / 05

    Authorized personnelMachine operator

    Required PPE:

    Description

    The state of the collision limit switch sensor located above the Z-axis ball nut has changed.


    Symptoms

    …..

    Possible causes

    This error may be caused by several conditions:

    1. The machine is stuck in the material or in the worktable, and the sensor above the Z-axis ball nut is therefore covered;

    2. the sensor is faulty

    3. the cable from the sensor to the passive junction box on the carriage is faulty;

    4. possible faults in the cables from the passive junction box to the electrical cabinet

    Possible solutions

    1. Press the reset button on the console to clear the collision error message, then slowly raise the Z axis until the machine is clear of the worktable/material

    2. Check sensor operation: verify that the LED on the sensor is on and that it switches off when a metal object is placed in front of the sensor. Replace the sensor if it is faulty;

    3. If the sensor is off, try connecting it to a different input on the passive junction box and check whether it switches on (for example, connect it in place of the X-axis sensor). If there is no change, the problem may be in the cable or connections up to the electrical cabinet.
