    DOC4.1.3 LABEL PRINTING

    To print a label for a single working stage, right-click the desired stage and select Labels printing. A screen similar to the one shown below opens. Then select the workpiece whose label you want to print.

    PIECES PARAMETERS

    The PIECES PARAMETERS panel allows you to configure the graphical and display parameters of workpieces and geometries in the working layout, adjusting distances, thicknesses, text and colours.

    PIECES PARAMETERS OPTIONS

    Nearby entity distance

    Sets the minimum tolerance or proximity distance between different entities or geometries on the work area.

    Perimeter thickness

    Sets the thickness of the lines defining the contours and perimeters of workpieces displayed on the screen.

    Black and White Mode

    On/Off switch to enable monochrome display of the graphical interface or drawing.

    Text size

    Changes the character size for text labels and informative dimensions associated with workpieces.

    Workpiece colour

    Defines the perimeter or fill colour of workpieces using a hexadecimal code or graphical selector.

    Text colour

    Allows you to choose the colour of the informative text overlaid on the workpieces (e.g. identifiers or measurements).

    Show nearby entities

    Enables or disables visual highlighting of geometries or workpieces located close to one another.

    QUOTES PARAMETERS

    The QUOTES PARAMETERS panel allows you to manage and configure the generation, style and positioning parameters of graphical dimensions within the working layout.

    QUOTES PARAMETERS OPTIONS

    Generator type

    Drop-down menu for selecting the type of automatic dimensions to apply.

    Generation mode

    Defines the logic used to insert dimensions.

    Black and White Mode

    On/Off switch to force dimensions to be displayed in black and white rather than in colour.

    Angular dimension distance

    Uses a slider to adjust the visual distance of linear dimension lines from the workpiece profile.

    Angular dimension distance

    Uses a slider to adjust the spacing and positioning of angle dimensions in the drawing.

    Text size

    Sets the character size of numerical values and dimension text to ensure readability.

    Dimension line thickness

    Changes the graphical thickness of the lines and strokes that make up the dimensions.

    Line colour

    Allows you to choose the colour of dimension and reference lines using a palette or hexadecimal colour code.

    Text colour

    Defines the specific colour for dimension text and numerical values.

    Arrow size

    Adjusts the size of arrows or terminators positioned at the ends of dimension lines.

    Arrow positioning

    Drop-down menu for setting where the arrows are placed (e.g. automatically, inside or outside the dimension line).
