    DOC8 SETTINGS

    On this page, the MES settings can be configured. The options are organised by functional area to make it easier to find and modify the required parameters.

    BUTTONS

    User
    Opens the user settings page, where operator preferences and data can be managed.

    Application
    Opens the page dedicated to general MES application settings.

    Graphics
    Opens the graphics settings page, including the interface appearance and information display.

    Label printing
    Opens the settings page for printing labels used in production processes.

    Content
    Opens the settings page for content managed by the MES.

    Machine
    Opens the settings page for machines connected to the MES.

    Workpiece import
    Opens the settings page for importing data for workpieces to be produced or managed into the MES.

    Database
    Opens the database configuration page, where the connections and data used by the MES are managed.

    REST
    Opens the REST interface configuration page used to exchange data with other systems.

    All settings
    Displays all available MES settings on a single page.
