    DOC5.5 BLOCKS

    This MES page allows you to manage the blocks in the warehouse, i.e. the materials available for production.

    BUTTONS

    ADD BUTTON
    Adds a new block.

    EDIT BUTTON
    Edits an existing block.

    COPY BUTTON
    Copies an existing block.

    DELETE BUTTON
    Deletes an existing block.

    PRINT LABEL BUTTON
    Prints a label for the selected block.

    ADDING A NEW BLOCK

    To add a new block, click Add. A screen opens where you can enter the name, code, dimensions and other characteristics of the block.

    PRINT LABEL

    To print a label for a block, click Print label. A screen opens where you can choose the template, print the label or save it as a PDF.
