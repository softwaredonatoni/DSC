    DOC4.1.1 WORKING STAGES

    On this page, you can manage all workpiece processing stages within the MES. The MES is the software used to track production progress, from creating or importing workpieces through to printing labels and sending them to production.

    BUTTONS

    Import
    Allows workpieces to be imported into the MES from a .dxf file.

    Export
    Allows information on the working progress status to be exported.

    Options menu
    Opens the menu of actions available for the selected working stage. From this menu, you can delete the stage, close the work order, send the stage to production, print the stage label or recreate the work order.

    Note

    The menu is displayed by right-clicking the selected working stage.

    Edit
    Allows the data of the selected working to be edited.

    Print
    Allows a label to be printed for the entire working.

    Send
    Allows the working to be sent to production.

    WARNING

    After being sent to production, the working can no longer be edited.

    WORKING STATES

    Green

    Indicates that the working stage has been completed.

    Light blue

    Indicates that the working stage has not yet started.

    Yellow

    Indicates that the working stage has been accepted and is being managed.

    WORKPIECE IMPORT

    To import the workpieces, click the Import button. A screen similar to the one shown below opens.

    Press OK on the next screen. When complete, check that all workpieces have been correctly added to the working.

    EXPORTING WORK STATUS

    To export the statuses of a working, press the Export button. A screen similar to the one shown below opens, where you can choose or change the information to be exported.

    LABEL PRINTING

    To print a label for the entire working, press the Print button. A screen similar to the one shown below opens.

    PRINTING LABELS FOR A WORKING STAGE

    To print a label for a single working stage, right-click the desired stage and select Labels printing. A screen similar to the one shown below opens. Then select the workpiece whose label you want to print.

    NEW PRODUCT

    To add a new product to the working, click the three dots and select New product. A screen similar to the one shown below opens.

    NEW PRODUCT BUTTONS

    Add
    Adds a new working to the list.

    Move up
    Moves the selected working up in the execution list.

    Move down
    Moves the selected working down in the execution list.
