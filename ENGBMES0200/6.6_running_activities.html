    DOC6.6 RUNNING ACTIVITIES

    On this page, activities running in the MES can be managed. A running activity is a work stage that has already started in production: it can be started, paused, resumed or completed according to the actual status of the production process.

    BUTTONS

    ADD
    Creates a new activity in the MES. Use this button when a new operation or work stage must be added to the production process.

    EDIT
    Updates the data for an existing MES activity, such as its name, description or the information required to perform it correctly.

    COPY
    Duplicates an existing activity. This is useful when creating a new activity with characteristics similar to one that has already been configured.

    DELETE
    Deletes an activity from the MES. Use this button only when the activity is no longer required and must no longer be used in the production process.

    PLAY
    Starts or resumes the selected activity. Use this button when the activity must begin or restart after a pause.

    CREATING A NEW RUNNING ACTIVITY

    To create a new running activity, press the ADD button or select the appropriate item from the menu. A screen similar to the one shown below opens, where the required information can be entered and creation of the activity can be confirmed.

    STARTING AN ACTIVITY

    To start an activity, select the required activity and press the PLAY button. When the confirmation window appears, press OK. The activity is now shown as started in the MES.

    PAUSING AN ACTIVITY

    To pause an activity, select the required activity and press the PAUSE button. When the confirmation window appears, press OK. The activity remains recorded in the MES but is temporarily suspended.

    COMPLETING AN ACTIVITY

    To mark an activity as completed, select the required activity and press the completion button. When the confirmation window appears, press OK. After confirmation, the MES records the activity as completed.
