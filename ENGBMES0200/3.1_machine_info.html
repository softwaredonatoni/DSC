    DOC3.1 MACHINE INFO

    On the Home page, additional information about the selected machine can be viewed.

    MACHINE INFORMATION

    INFO PAGE

    INFO
    Displays information about the selected machine.

    After pressing the Info button, a screen similar to this one opens:

    This page provides detailed information about the machine workings.

    BUTTONS

    DATE
    Filters the workings by the selected date.

    DETAILS
    Displays detailed information about the workings performed by the machine.

    SETTINGS
    Displays the physical characteristics of the machine.

    WORK STATISTICS

    This section displays the machine's work statistics.

    BUTTONS

    CATEGORY
    Filters the statistics by category: general, blocks or pieces.

    SLABS
    Selects the unit of measurement for blocks: number, area, cutting area, length, total area or used area.

    AGGREGATION
    Groups the statistics according to the selected interval: hours, days, weeks, months or years.

    WORK CYCLE STATISTICS

    This section displays the machine's work cycle statistics.

    MACHINE EFFICIENCY STATISTICS

    This screen provides a detailed analysis of machine efficiency and status, showing the breakdown of operating time between productive, non-productive and error periods over a selected time range.
