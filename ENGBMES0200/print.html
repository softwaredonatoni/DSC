DOC2 DMES

Donatoni MES (DMES) software provides simplified production management, up to a complete solution for managing the company's production stages.

DMES CORE

DONATONI DMES CORE is the basic package of the DMES system, designed to provide complete, simple and centralized control of the production process from the outset.
It is the ideal solution for starting to digitalize your factory, with practical tools to improve organization, traceability and productivity.

DMES TRACE

DONATONI DMES TRACE is the complete package for digital production management. It includes all basic functions and adds advanced tools for label customization and printing.
A solution designed to provide full production control and accurate, professional traceability of pieces, from project to shipment.

DMES MATRIX

DONATONI DMES MATRIX is an advanced platform that combines all DMES TRACE functions with a powerful operating module dedicated to slab management.
It is the ideal solution for those who require full control of the entire production cycle, from planning and piece labeling through to organizing the slabs to be processed.

DMES PRO

DONATONI DMES PRO is the most complete and comprehensive package in the entire DMES suite. It combines all the functions of the MATRIX package in a single platform and enhances them with advanced tools for managing jobs, work cycles and the company's entire production process.

With DMES PRO, you are not limited to monitoring machines or managing slabs: you have an integrated system to plan, control, assign, track and document every stage of the work, from order receipt to delivery of the finished piece. It is designed for companies that want to digitalize and optimize every link in the production chain, increasing efficiency and improving customer service.

This page allows the MES settings to be configured. The options are organized by functional area, making it easier to find and modify the required parameters.

BUTTONS

User
Opens the page dedicated to user settings, where operator preferences and data can be managed.

Application
Opens the page dedicated to the general MES application settings.

Graphics
Opens the page dedicated to graphics settings, such as the interface appearance and information display.

Print labels
Opens the page dedicated to settings for printing labels used in production processes.

Content
Opens the page dedicated to settings for content managed by the MES.

Machine
Opens the page dedicated to the settings of machines connected to the MES.

Piece import
Opens the page dedicated to settings for importing data into the MES for pieces to be produced or managed.

Database
Opens the page dedicated to database configuration, where the connections and data used by the MES are managed.

REST
Opens the page dedicated to REST interface configuration, used for data exchange with other systems.

All settings
Displays all available MES settings on a single page.
