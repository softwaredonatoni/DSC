    DOC4.4 SUPPLIERS

    On this MES page, supplier records can be managed. The user can create new suppliers, edit existing ones, copy or delete them, and associate a preview image.

    BUTTONS

    ADD
    Creates a new supplier record in the MES.

    EDIT

    Updates the data of a supplier already registered in the MES.

    COPY

    Duplicates an existing supplier record, allowing a new supplier to be created from existing data.

    DELETE

    Removes a supplier record that is no longer required from the MES.

    IMAGES

    Associates a preview image with the supplier record during creation or editing.

    CREATING A NEW SUPPLIER

    To create a new supplier, click the ADD button. The MES opens a screen where the supplier data can be entered.
