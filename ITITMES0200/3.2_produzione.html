    DOC3.2 PRODUZIONE

    In questa pagina puoi gestire le fasi di produzione dei file da inviare alla macchina tramite il MES.

    GUIDA

    Dopo aver aggiunto un file .dxf con il pulsante Nuovo, il file compare nella schermata principale, come mostrato nell’immagine.

    Per inviare il file alla macchina, clicca sul pulsante Invio e conferma con OK nella finestra che si apre. Verifica poi che lo stato passi da Ready a Sended.

    PULSANTI

    INVIO
    Invia il file selezionato alla macchina.

    STATISTICHE
    Mostra le statistiche del contenuto del file.

    NUOVO

    Aggiunge un nuovo file .dxf alla lista.

    STATO READY

    Indica che il file è pronto per essere inviato in produzione.

    STATO SENDED

    Indica che il file è stato inviato correttamente alla macchina.
