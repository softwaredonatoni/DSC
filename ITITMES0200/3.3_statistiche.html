    DOC3.3 STATISTICHE

    Questa pagina mostra le statistiche delle lavorazioni eseguite dalle macchine collegate al MES.

    REPORT
    Apre la schermata dedicata ai report delle lavorazioni.

    WORKING
    Apre la schermata con i dettagli dei cicli di lavoro.

    REPORT

    Questa pagina mostra i report disponibili per ogni lavorazione.

    PULSANTI

    TYPE
    Filtra i risultati per nome file, lavoro, cliente, blocco, nome pezzo o materiale.

    DATA
    Filtra i risultati in base alla data selezionata.

    SAVE
    Salva il report.

    SETTINGS
    Permette di scegliere il formato del report, ad esempio PDF o CSV, e di modificare i parametri del file da salvare.

    AUMENTO ZOOM
    Aumenta lo zoom dell'anteprima del file nella colonna a destra.

    DIMINUZIONE ZOOM
    Riduce lo zoom dell'anteprima del file nella colonna a destra.

    RIPRISTINO ZOOM
    Ripristina lo zoom predefinito dell'anteprima del file nella colonna a destra.
