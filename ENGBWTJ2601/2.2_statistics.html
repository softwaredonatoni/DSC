    DOC2.2 STATISTICS

    This window displays statistics for the operations performed by the machine.

    Top bar

    Refresh statistics
    Pressing this button refreshes the statistics page.

    Date filter
    The button preview displays the dates defining the start and end of the required time interval.

    List
    This view displays the statistics in a list.

    Chart
    This view displays the statistics divided into categories and arranged chronologically.

    Date filter

    This filter limits the period over which statistics are collected.
    After the date-filter button is clicked, the following panel opens. It allows the start date or end date to be changed or one of the time filters on the left-hand side of the panel to be selected:

    List Statistics

    The list view allows the operator to sort and filter the statistics using the available fields shown in the following example image:

    List statistics bottom bar

    Page selector
    The displayed statistics page can be managed in the lower-left section.
    The buttons from left to right are:

    • Go to the first page

    • Go to the previous page

    • Currently selected page

    • Go to the next page

    • Go to the last page

    Displayed results
    The lower-right section shows the number of displayed statistics out of the total and the number of results that can be displayed per page.

    Chart Statistics

    The chart view allows the operator to view the statistics arranged chronologically and limited to the currently selected category.

    Categories

    The standard categories available in the chart statistics are listed below:

    Total cycles
    Displays statistics for all completed cycles.

    Linear lengths
    Displays statistics for all linear cuts.

    Working time
    Displays statistics relating to machining times.

    Rapid-movement lengths
    Displays statistics for all movements performed in rapid mode.

    Abrasive consumed
    Displays statistics for the amount of abrasive used.

    Water consumed
    Displays statistics for the amount of water consumed.

    Statistics totals

    This box is located in the upper-right section of the interface and provides the operator with total statistics values by category.
