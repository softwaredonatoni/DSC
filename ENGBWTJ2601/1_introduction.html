    DOC1 INTRODUCTION

    General information

    The information contained in this document applies only to the software versions specified on the title page.

    Not all the functions that the product can perform may be described in this documentation; in such cases, Donatoni Macchine S.r.l. is under no obligation to guarantee these functions or retain them in future versions.

    Purpose of the manual

    This manual provides the operating instructions required for a thorough understanding of the Waterjet software and Parametrix interface, as well as useful information for troubleshooting.
    Compliance with the instructions in this manual is essential to ensure the machine operates correctly, lasts as intended and remains cost-effective.
    The machine operating and maintenance manual and this software manual must always be available at the installation site, stored in a safe and easily accessible place. If either manual is lost, contact the prevention and protection service manager.
    Failure to comply with the instructions in this manual, negligence or improper and unsuitable use of the machine may cause the Manufacturer to void the machine warranty and may also prevent the machine from providing the benefits for which it was designed.
    DONATONI MACCHINE SRL remains available to provide prompt and accurate technical assistance and anything else that may help ensure optimal operation and maximum machine performance.
    The Manufacturer reserves the right to modify this publication and the data contained herein at its discretion whenever this is deemed necessary for the technical or commercial improvement of the product.

    Keeping the manual

    This Software Manual must be kept throughout the machine’s entire operating life, including if the machine is transferred to a third party.
    To keep the Software Manual in good condition, the following is recommended:

    • Use the Manual in a way that does not damage all or part of its contents; in particular, do not leave the Manual unattended during use and return it to its designated location immediately after consultation;

    • Do not remove, tear or rewrite any part of the Manual for any reason;

    • Keep the Manual in areas protected from moisture, heat and other environmental factors that could affect its integrity or durability;

    • If all or part of this Manual is lost or damaged, request a copy of the documentation from the Manufacturer.

    Users

    This document contains information intended for:

    • Machine operator

    • Authorised service technician

    Using the document

    The document is divided into chapters describing:

    • Description of the main software sections

    Reporting problems

    For any problems encountered while studying this document, contact the Donatoni Macchine S.r.l. service department.
