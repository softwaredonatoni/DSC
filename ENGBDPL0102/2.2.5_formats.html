    DOC2.2.5 FORMATS

    The Formats page is used to view the following (if supported by the model, e.g. B):

    Active format parameters

    The parameters of the active format can be viewed and edited in the “Formats” section:

    Code

    name of the format type.

    Length

    piece length.

    Width

    piece width.

    Thickness

    piece thickness.

    Material

    piece material type.

    Number of picks

    pieces picked up simultaneously.

    Weight

    piece weight.

    Initial orientation

    orientation of the pieces leaving the machine.

    Final orientation

    orientation of the pieces when picked up by the robot.

    Format list

    The format list contains all the different types of palletising format used.

    Format list top bar

    The following buttons provide the operator with functions for the selected format:

    Set
    Sets the selected format as the active format

    New
    Creates a new palletising format

    Delete
    Deletes the selected format

    Edit
    Edits the selected format

    Duplicate
    Creates a copy of the selected format
