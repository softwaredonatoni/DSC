    DOC2.8.2 WORKINGS

    Displays unloading statistics for each unloaded slab/cutting layout

    Parameters

    Name

    name of the unloaded working, e.g. 70

    Start date

    piece unloading start date

    End date

    piece unloading end date

    Time

    time required to unload all the pieces in the cutting layout

    Pieces

    number of pieces unloaded

    Containers

    containers in which the pieces were palletised
