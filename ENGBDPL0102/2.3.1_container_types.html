    DOC2.3.1 CONTAINER TYPES

    This page is used to manage container types:

    Top bar

    The following buttons are located on the right-hand side of the top bar:

    New
    Creates a new container.

    Delete
    Deletes the selected container.

    Edit
    Edits the selected container.

    Duplicate
    Creates a copy of the selected container.

    Menu
    Previous commands, plus import and export commands.
