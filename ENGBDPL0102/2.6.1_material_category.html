    DOC2.6.1 MATERIAL CATEGORY

    The “Material categories” page is used to view and create/edit the characteristics of a category for the material of the pieces to be palletised.

    Top bar

    New
    Creates a new category.

    Delete
    Deletes the selected category.

    Edit
    Edits the selected category.

    Duplicate
    Creates a copy of the selected category.

    New material

    Name

    Code assigned to the material category.

    Code

    Code assigned to the material category.

    Specific weight

    Specific weight of the material category.
