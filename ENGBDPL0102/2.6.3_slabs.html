    DOC2.6.3 SLABS

    The “Slabs” page is used to search for, view and edit the list of slabs loaded by the robot.

    Top bar

    New
    Creates a new slab.

    Delete
    Deletes the selected slab.

    Edit
    Edits the selected slab.

    Duplicate
    Creates a copy of the selected slab.

    New slab

    Code

    Code assigned to the slab

    Width

    Slab width

    Height

    Slab height

    Thickness

    Slab thickness

    Material

    used to select the relevant material or create a new one

    Weight

    Calculated slab weight

    Sample slab

    Defines whether or not it is a sample slab

    Preview

    a preview file for the slab can be uploaded, or the existing one can be deleted
