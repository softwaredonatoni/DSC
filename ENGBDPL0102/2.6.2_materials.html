    DOC2.6.2 MATERIALS

    The “Materials” page is used to search for, view and edit the characteristics of a material used for the pieces to be palletised.

    Top bar

    The following buttons are located on the right-hand side of the top bar:

    New
    Creates a new material.

    Delete
    Deletes the selected material.

    Edit
    Edits the selected material.

    Duplicate
    Creates a copy of the selected material.

    New material

    Name

    Code assigned to the material

    Code

    Code assigned to the material

    Value per m^2

    Specific weight

    Specific weight of the material

    Category

    used to select the relevant material category or create a new one

    Preview

    a preview file for the new material can be uploaded, or the existing one can be deleted
