    DOC2.3 PROGRAMA ISO

    A página de programação de ficheiros ISO permite gerir e iniciar maquinações através de ficheiros .pgm previamente criados por programas CAD-CAM.

    Lista

    A lista do programa ISO, inicialmente vazia, contém todos os programas ISO que podem ser executados sequencialmente.

    Botões

    Estão disponíveis vários botões para gerir a lista.

    Abrir Ficheiro
    Abre o explorador de ficheiros para criar uma lista de ficheiros a executar.

    Nova lista ISO
    Adiciona um ficheiro à lista de ficheiros a executar.

    Adicionar Pausa
    Adiciona uma pausa à lista de ficheiros a executar.

    Remover elemento selecionado
    Elimina um ficheiro da lista de ficheiros a executar.

    Esvaziar lista
    Elimina toda a lista de ficheiros a executar.

    Mover elemento selecionado para cima
    Move para cima o ficheiro ISO selecionado na lista de ficheiros a executar.

    Mover elemento selecionado para baixo
    Move para baixo o ficheiro ISO selecionado na lista de ficheiros a executar.

    Na parte inferior encontram-se ainda os dois botões relativos aos modos de execução dos programas:

    Manual / automático
    Define se o estado da máquina é manual ou automático.

    Único / próximo automático
    Define se o programa seguinte será iniciado automaticamente ou não.

    Função Dry Run (Ativada / desativada)
    Ao selecionar este modo de trabalho, é possível efetuar uma maquinação à velocidade máxima da máquina.

    ATENÇÃO !

    A utilização desta função obriga a NÃO utilizar QUALQUER tipo de material durante a maquinação, pois durante a execução não são respeitadas as velocidades definidas no programa ISO; o controlo numérico executará todo o programa à velocidade nominal máxima alcançável com eixos interpolados.

    Função Teste ISO (Ativada / desativada)
    Com esta opção, é possível testar o ficheiro carregado para verificar se existem erros de sintaxe.
    Prima o botão “START CICLO” e a máquina executará virtualmente todas as linhas de código sem mover os eixos.

    Pesquisa de bloco

    Durante a execução de ficheiros (.pgm), a função de pesquisa de bloco pode ser útil para reposicionar a ferramenta no ponto em que a máquina interrompeu a execução do programa, em caso de bloqueio da ferramenta no interior do material ou de outros tipos de bloqueio.

    Depois de premir o botão, é possível procurar a linha a partir da qual pretende continuar/iniciar a maquinação, através do número da linha premindo o botão “Pesquisa de bloco por linha“ ou percorrendo o ficheiro através da barra de deslocamento junto ao ficheiro e selecionando a linha pretendida.
    Depois de selecionar o ponto do programa a partir do qual a máquina continuará o trabalho interrompido, prima o botão “Start ciclo”; a máquina recalculará todas as linhas de código no ficheiro .pgm sem efetuar qualquer movimento. A velocidade desta operação depende do número de linhas de código que têm de ser geradas sem efetuar qualquer movimento.

    Concluído o recálculo, a máquina ativa uma pausa automática, solicitando que se prima novamente o botão “Start ciclo” para iniciar a maquinação.
    Antes de iniciar o ciclo, recomenda-se ter em consideração o posicionamento inicial da máquina, que envolve todos os eixos em simultâneo.
    Isto é necessário porque a máquina se desloca da posição atual para o ponto em que começa a trabalhar pelo percurso mais curto e, para tal, todos os eixos se movem para chegar exatamente a esse ponto.


    Isto significa que, por exemplo, o eixo Z não desce apenas quando chega ao ponto inicial, mas desce gradualmente durante o percurso. Isto pode danificar a máquina ou o material se houver uma colisão com material situado ao longo do percurso.
    Assim, consoante a situação, é possível desselecionar o movimento de um ou mais eixos, de modo a evitar danos.
    Para tal, basta selecionar os botões presentes acima de cada eixo, que passarão de verde para vermelho.

    Os botões voltarão automaticamente a verde depois de premir “Start Ciclo”.

    Execução da maquinação

    O operador pode criar uma lista de ficheiros PGM abrindo os ficheiros pretendidos através da função de carregamento adequada.

    Antes de iniciar a execução, é possível — opcionalmente — alterar a ordem dos ficheiros na lista e inserir eventuais pausas entre uma execução e outra. Essas pausas permitem gerir o processo de forma mais flexível e, se necessário, interrompê-lo em segurança.

    Ao definir o modo de execução para "Automático", fica também disponível a função "Teste ISO", útil para verificar a correção do programa ISO selecionado antes da execução efetiva.

    Para iniciar o ciclo de execução, o operador deve premir o botão “Iniciar Ciclo”. Desta forma, será executado o primeiro programa ISO carregado e apresentado na lista.

    Os programas ISO podem ser executados segundo dois modos operativos:

    O modo “Único” permite interromper a execução da programação no final da execução de cada ficheiro ISO. É necessário premir novamente o botão “Iniciar Ciclo” para prosseguir com a execução do ficheiro seguinte na lista.

    O modo “Próximo automático” permite executar os ficheiros ISO em sequência, sem necessidade de intervenção manual, até ao fim da lista.

    Em ambos os modos, eventuais pausas inseridas entre os ficheiros permitem ao operador interromper o ciclo a qualquer momento, garantindo assim um controlo contínuo da execução.
