    DOC3.22.2 PROJECT MATCH (OPCIONAL)

    O Project Match foi concebido para o planeamento de projetos de grande escala.
    Permite gerir várias chapas em simultâneo, de modo a programar todas as maquinações necessárias para o projeto com uma visão geral.

    Painel de controlo

    Ao premir o botão na barra inferior, abre-se um painel através do qual é possível navegar na funcionalidade.

    Para aceder ao Project Match, serão apresentados estes botões.

    Novo projeto
    Permite criar um novo projeto.

    Carregar projeto
    Permite carregar um projeto já existente.

    Mostrar pré-visualização
    Permite abrir um ecrã onde é apresentada a pré-visualização de todo o projeto.

    Dentro de um projeto, o painel dispõe de botões diferentes.

    Guardar área de trabalho
    Permite guardar as alterações efetuadas na área de trabalho selecionada dentro do projeto.

    Guardar todas as áreas de trabalho
    Guarda simultaneamente as alterações efetuadas em todas as áreas de trabalho do projeto.

    Guardar e fechar projeto
    Permite sair do projeto Book Match, deixando ao utilizador a decisão de guardar ou não.

    NOTA

    O painel pode ser deslocado arrastando-o no ecrã.

    Novo projeto

    Ao premir o botão, abre-se uma janela que permite criar um projeto Book Match multichapa.

    Nome

    Nome com que o projeto será guardado.

    Linhas

    Permite definir o número de linhas do projeto.

    Colunas

    Permite definir o número de colunas do projeto.

    Chapas

    Número total de chapas que o projeto pode conter.

    Dimensões da área de trabalho
    Permite escolher as dimensões, em largura e altura, das áreas de trabalho que compõem o projeto.

    Carregar um projeto

    Neste ecrã são apresentados os projetos guardados que podem ser abertos.

    Fechar um projeto

    Abre-se uma janela que permite fechar o projeto.

    Para alterar o modo de fecho, utilize o botão:

    Modo de fecho
    Permite escolher se o projeto deve ser fechado guardando as alterações efetuadas ou sem as guardar.

    Projeto

    Um projeto está estruturado em linhas e colunas, onde podem estar contidas as chapas.
    Neste ecrã é possível inserir chapas no projeto, definir os respetivos perímetros e posicionar as peças.
    O operador pode mover livremente as peças de uma chapa para outra.

    Zonas de trabalho

    As zonas de trabalho são representadas pelas células do projeto.
    Cada zona permite gerir a maquinação de uma chapa, definindo um perímetro e inserindo peças no seu interior.

    No canto superior esquerdo de cada zona de trabalho são apresentadas algumas informações.

    Chapa

    Dimensões da chapa (largura x altura x espessura).

    Peças

    Número de peças posicionadas dentro do perímetro.

    Área das chapas

    Área do perímetro da chapa.

    Área das peças

    Área das peças posicionadas dentro do perímetro.

    Percentagem

    Percentagem da área do perímetro ocupada pelas peças.

    Cortes

    Comprimento total dos cortes a executar na chapa.

    Minutos

    Estimativa do tempo, em minutos, necessário para executar o programa de corte na chapa.

    Parâmetros do projeto

    No painel de parâmetros do utilizador é apresentada a secção “Chapas“, através da qual é possível alterar algumas propriedades do projeto atualmente aberto.

    Linhas

    O operador pode alterar o número de linhas do projeto atual.

    Colunas

    O operador pode alterar o número de colunas do projeto atual.

    Total

    Número total de zonas que compõem o projeto atual.

    Chapas

    Número de chapas inseridas no projeto atual.

    Peças

    Número de peças inseridas no projeto atual.

    Teclas de atalho
    Permite aceder ao ecrã das teclas de atalho do Project Match.

    Atalhos de teclado

    Para o Project Match estão disponíveis comandos de teclado que permitem executar facilmente ações de rotina, úteis para simplificar o trabalho no escritório.

    Zoom no projeto

    Amplia a vista para todo o projeto.

    Zoom na zona

    Restringe a vista à zona de trabalho selecionada.

    Modo pan

    Permite mover a vista através da interação com o ecrã.

    Navegar entre as zonas

    Permite alterar a zona selecionada utilizando as teclas.

    Mover peça

    Move a peça selecionada nas quatro direções.

    Rodar peça

    Roda a peça selecionada, respetivamente, no sentido anti-horário e horário.

    Rodar peça _90

    Roda a peça 90 graus no sentido horário.

    Selecionar tudo

    Se estiver selecionada uma zona de trabalho, este comando seleciona todas as peças no seu interior.
    Caso contrário, seleciona todas as peças do projeto.

    Ativar seleção múltipla

    Ativa a seleção múltipla de peças/zonas de trabalho.

    Anular

    Anula a última operação executada.

    Copiar chapa

    Copia a chapa dentro da zona de trabalho selecionada.

    Cortar chapa

    Corta a chapa dentro da zona de trabalho selecionada.

    Colar chapa

    Cola a chapa dentro da zona de trabalho selecionada.

    Desselecionar

    Permite desselecionar todas as peças/zonas de trabalho.

    Confirmar perímetro ou fotografia

    Utilizar para confirmar o perímetro/fotografia.

    Seleção seguinte

    Seleciona a peça seguinte dentro da zona de trabalho selecionada.

    Íman on/off

    Ativa/desativa o íman das peças.

    Comandos rápidos

    Com o botão direito do rato é possível aceder à janela de comandos rápidos.
    As funcionalidades disponíveis mudam consoante se clique dentro de uma zona de trabalho ou fora de todas elas.

    Comandos do projeto

    Guardar maquinações
    Permite guardar as alterações efetuadas em todas as zonas de trabalho.

    Relatório
    Permite guardar um ficheiro PDF com um relatório do projeto.

    Nesting
    Permite executar o nesting das peças em todas as chapas do projeto.

    Comandos da zona de trabalho

    Bloquear/Desbloquear
    Se uma zona de trabalho estiver bloqueada, não será possível mover as peças nela contidas nem inserir novas peças.
    Também não é permitido alterar o perímetro ou escolher outras fotografias.
    É necessário desbloqueá-la para voltar a permitir todas as operações.

    Cortar
    Leva o utilizador ao ecrã de gestão e otimização dos cortes da chapa selecionada para criar o programa ISO.

    Guardar
    Permite guardar as alterações aplicadas à zona de trabalho individual.

    Relatório
    Permite guardar um ficheiro PDF com um relatório da zona de trabalho selecionada.

    Importar ficheiro
    Carrega um ficheiro de gravação do estado de uma chapa dentro do projeto.

    Nesting
    Executa o nesting das peças dentro da zona de trabalho selecionada.

    Nesting

    Ao ativar a função de Nesting em todo o projeto, ficam disponíveis dois modos.

    Inserir as peças nas chapas atuais

    Insere as peças nas chapas já presentes no projeto, de modo a otimizar o espaço disponível.

    Inserir chapas e peças até esgotar

    São criadas chapas às quais é aplicado o Nesting até que todas as peças da lista se esgotem.
    As dimensões das chapas são iguais às da primeira que foi definida.
    É utilizado para dar uma indicação de quantas chapas poderão ser necessárias para concluir o projeto, sabendo que serão cortadas chapas da mesma forma.

    Para utilizar o Nesting até esgotar as peças, é necessário criar um perímetro para indicar ao programa as dimensões das chapas que serão utilizadas.
    Serão criadas chapas da mesma dimensão até que todas as peças da lista tenham sido inseridas com o Nesting.

    Pré-visualização

    Nesta janela é possível ver uma representação global do projeto em tempo real.
    É possível inserir as peças dentro da zona de trabalho selecionada premindo sobre elas na pré-visualização.
    Além disso, ao arrastar o fundo de uma peça, o operador pode alterar a posição da peça na bancada.

    Botões

    À esquerda encontram-se estes botões.

    Mover peças
    Permite mover as peças que compõem a pré-visualização.
    São apresentados os botões da barra inferior da janela.

    Mover vista
    Permite mover a vista da pré-visualização com todas as peças.

    À direita encontram-se estes botões.

    Abrir render
    Abre a pasta onde estão guardados os renders dos projetos.

    Personalizar pré-visualização
    Abre um painel que permite personalizar as cores das entidades da pré-visualização.

    Repor posição das peças
    Repõe as peças deslocadas na posição original.

    Repor configuração do projeto
    Repõe a configuração do projeto.

    Guardar render
    Abre um painel através do qual é possível guardar o render do projeto.

    Planeamento de um projeto

    Criar um novo projeto

    O operador cria um novo projeto indicando o nome, o número de linhas e colunas que o compõem, lembrando que cada célula corresponde a uma chapa, e as dimensões das células. Depois de confirmar, este será o ecrã:

    Adicionar as chapas

    Em seguida, insira as chapas nas zonas de trabalho. Para isso, selecione uma zona, carregue uma fotografia a partir de um ficheiro e escolha o perímetro.

    Importar as peças

    Neste ponto, importe as peças que pretende cortar. É possível carregar ficheiros DXF e peças padrão. Não existe limite para o número de ficheiros que podem ser carregados.

    Abrir pré-visualização

    Quando existirem peças na lista, é possível abrir a janela com a pré-visualização do projeto.
    Esta apresentará todas as peças que foram importadas.

    Inserir as peças nas chapas

    Para inserir as peças dentro das chapas, utilize o método clássico através da lista de peças ou selecione dentro das áreas das peças visíveis na pré-visualização.
    As peças serão então inseridas na chapa da zona de trabalho selecionada.
    Ao arrastar uma das peças a partir da pré-visualização, a peça também se deslocará na chapa, permitindo escolher a melhor zona da chapa para fazer coincidir os veios entre as várias peças. Também é possível fazer o contrário, ou seja, arrastar a peça a partir da chapa e verificar na pré-visualização se os veios coincidem ou não consoante a posição para onde é deslocada.
