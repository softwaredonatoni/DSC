    DOC3.12 PIECE LIST

    When one or more pieces are created and imported into Parametrix, the program adds them to the piece list located in the right-hand section of the main screen.

    Using the piece list, the operator can:

    • Insert pieces into the work area;

    • Keep track of machined pieces and pieces still to be machined;

    • Apply certain changes to the pieces.

    List elements

    Each row in the list represents a piece that has been imported into Parametrix.

    As shown in this image, a row contains the following information about the piece:

    Shape preview

    Simplified representation of the piece geometry.

    Piece mark

    Label added to the piece to identify it.

    NOTE

    If the operator does not choose a mark during creation, the program identifies the piece using the name of the file (DXF or CSV) from which it was imported, or the side dimensions if it is a rectangle.

    Number of inserted and total pieces

    Indicates the number of pieces in that row that have been inserted into the work area and the total number of pieces of that type that can be inserted.

    Insert pieces into the work area

    To insert pieces into the work area, use the following button found on each row of the list:

    Insert pieces into the work area
    Inserts the selected piece into the work area.

    The selected piece has been positioned in the work area and the number of inserted pieces in this row has been updated.

    NOTE

    Once the maximum number is reached, the “Insert pieces” button for that row disappears because all pieces in that row have been machined.

    Operations on pieces in the list

    The buttons below the list allow the list items to be managed. In particular:

    Clear piece list
    Deletes all contents of the piece list.

    NOTE

    Commercial pieces are not removed from the list.

    WARNING!

    All pieces linked to rows removed from the list are removed from the work area.

    Hide/Show commercial pieces
    Allows the rows in the list associated with commercial pieces to be hidden or displayed.

    WARNING!

    When rows associated with commercial jobs are hidden, all pieces linked to them in the work area are removed.

    Delete piece
    Allows individual pieces to be selected for deletion from the list.

    Filter/Sort pieces
    A filter can be applied to the pieces in the list, or they can be sorted according to different criteria.

    Additional piece properties
    The operator can assign and edit the additional properties of the selected piece.

    Delete piece

    This function allows pieces to be deleted from the list individually. After the button is pressed, the program asks the user to select the row to be deleted by replacing the arrow used to insert pieces into the work area with an eraser.

    Pressing this button deletes the corresponding row and therefore all the pieces it represents.

    WARNING!

    Deleting a row removes all pieces linked to it from the work area.
