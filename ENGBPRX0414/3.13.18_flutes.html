    DOC3.13.18 FLUTES

    This function allows workings to be applied to the selected cut, whether curved or straight, using the milling-cutter tool currently mounted on the machine in order to create flutes.

    Parameters

    The result varies according to the value of the following parameters:

    Number of drain board flutes

    Indicates how many flutes to apply to the current working on the selected cut.

    NOTE

    This parameter is visible only when the number-based flute insertion mode is selected.

    Recalculate Number
    Recalculates the number of flutes so as to fill the selected cut.

    NOTE

    This parameter is visible only when the number-based flute insertion mode is selected.

    Length

    Indicates how far the flutes extend into the cut.

    Distance

    This value represents the distance between the flutes and takes into account the diameter of the mounted tool.

    Start Distance

    This value defines the distance between the vertices of the flutes inside the piece, adjusting the empty space separating them.

    Internal extension

    Indicates how far the flutes will be extended beyond the reference cut.

    Start depth

    Penetration into the material at the starting point of the drain-board flute.

    Final depth

    Penetration into the material at the ending point of the drain-board flute.

    Flute Type on Arcs

    For flutes on curves, three modes are available as described below.

    NOTE

    This parameter is visible only when a curved cut is selected.

    Cut Thickness

    For flutes inserted in disk mode, the cut-thickness variable is available.

    NOTE

    This parameter is visible only when disk mode is selected to insert the flutes.

    Overlay on Drip System

    For flutes inserted in fill mode, the percentage can be modified.

    NOTE

    This parameter is visible only when fill mode is selected to insert the flutes.

    Recalculate Number

    Pressing the button to the right of the number of flutes fills the selected cut with as many flutes as possible, according to the values of the other parameters.

    Flute Insertion Mode

    These are the flute insertion options:

    Number-Based Insertion
    The flutes are inserted according to the entered number.

    NOTE

    If this insertion mode is selected, fill insertion cannot be used, and vice versa.

    Fill Insertion
    The flutes are inserted according to the entered distance.

    Disk Mode
    The disk will be used to cut the flutes.

    NOTE

    If this mode is selected, milling-cutter mode cannot be used, and vice versa.

    Milling Cutter Mode
    The milling cutter will be used to cut the flutes.

    Flute Mode on Arcs

    When a curved cut of a polygon is selected, a new parameter is displayed and can take one of three values:

    Radial
    The flutes are arranged along the curve so that they point toward the center of the arc.

    Arc Alignment
    The flutes are arranged parallel along the curve and with equal length.

    Tangent Alignment
    The flutes are arranged parallel along the curve. Their length varies so that all ends inside the piece lie on the same straight line, while respecting the extension of the ends outside the piece.

    Mode 1: Radial

    In this mode, the flutes share a common origin point and are perpendicular to the corresponding tangent on the selected curved cut.

    Mode 2: Arc Alignment

    In this mode, the flutes are parallel to each other and aligned along the arc both for spacing and internal extension.

    Mode 3: Tangent Alignment

    In this mode, the flutes are parallel to each other and arc-aligned for the internal extension, while they are extended until they reach the tangent at the distance specified by the length value.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the desired cut.

    Once the desired result has been obtained, displayed and continuously updated in the working preview, the operator can confirm the operation by pressing the green “OK” button located just below the set parameters.
    The flutes shown in the preview are then applied to the selected cut: their color changes to dark green, both in the preview and subsequently in the work area, indicating that they have been applied.

    The cut list on the left is also updated according to the newly applied working and the flute parameters.
    Multiple workings of this type can be applied to a single cut, provided that their parameters are not duplicated.
