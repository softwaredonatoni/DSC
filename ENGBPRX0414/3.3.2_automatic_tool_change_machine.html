    DOC3.3.2 AUTOMATIC TOOL CHANGE MACHINE

    The tools of a machine with automatic tool change can be managed from this panel.

    Tool list

    The section on the left shows the list of all tools available for the machine.

    The tool currently mounted on the machine is indicated at the top.
    Below it, a list shows the tools available for use by the machine. Two buttons are located next to each tool:

    Force mounted tool
    Allows the operator to indicate to the program which tool is currently mounted on the machine.
    Used when the tool has been changed manually.

    Start tool change
    Starts the automatic tool change procedure.

    Parameters tool

    The section on the left contains the parameters associated with the selected tool.

    Corrector
    Identification number of the selected tool. Identifies its position within the machine magazine.

    Laser
    Indicates which of the lasers mounted on the machine is to be used when the tool is mounted.

    Corrector

    This field indicates the position in which unused tools are stored within the machine magazine.

    Change corrector
    Assigns or changes the corrector for a tool.

    Delete corrector
    Deletes the corrector associated with a tool.

    Automatic tool change procedure

    By pressing the button associated with a tool, the operator can start the automatic tool change procedure.
    When the procedure starts, the operator is asked which workings are to use the new tool that is about to be mounted.
