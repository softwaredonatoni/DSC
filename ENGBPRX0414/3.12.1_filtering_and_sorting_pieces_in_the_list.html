    DOC3.12.1 FILTERING AND SORTING PIECES IN THE LIST

    This function allows the operator to filter and/or sort the pieces in the list.
    Pressing the button opens the following window.

    Filtered piece list

    Once criteria have been set for filtering or sorting the pieces, they can be applied using the button at the top right.

    Enable/Disable
    Applies/removes the filter and/or sorting to/from the pieces in the list.

    Pieces that do not match the selected filter criteria are not shown in the piece list.

    WARNING!

    Pieces in the work area that do not meet the filter criteria are removed.


    In the following example, only pieces with a height greater than 600 mm are to be shown and arranged in ascending alphabetical order.

    NOTE

    The filtering and sorting function does not work with commercial pieces.
    The filtering and sorting criteria are also respected by the nesting function.

    Filtering pieces

    In the upper section of this window, the operator can add a filter based on different piece characteristics.

    As shown, the following buttons are available.

    “Exclusion” filter application mode
    Pieces must simultaneously satisfy the last logical condition created and the result of the previous conditions.

    “Inclusion” filter application mode
    Pieces must satisfy at least one of the last logical condition created or the result of the previous conditions.

    Add filter
    Adds the created logical condition to the filter list.

    Delete filters
    Deletes all filters from the filter list.

    Creating a filter

    To create a filter, select the property to be used from the first drop-down menu on the left.

    After selecting the distinguishing characteristic, select a relational operator from the second menu.

    Then enter a value appropriate for the property in the adjacent box to create a logical condition.

    At this point, use the button to the right of the text box to decide how the filter being created interacts with any other filters in the list.

    NOTE

    In “Exclusion“ mode, a piece must satisfy
    both
    the logical condition being created and the result of the previous conditions.
    In “Inclusion“ mode, a piece must satisfy the condition being created
    or
    the result of the previous conditions.

    To complete creation of the filter, use the last button on this row. The filter is added to the list below.

    Sorting pieces

    In the lower section of the window, the operator can sort pieces according to certain properties.

    After selecting an item from the drop-down menu, the following actions can be performed:

    Ascending/Descending sorting
    The operator can sort the pieces by a given category in ascending or descending order.

    Delete sorting
    The operator can restore the original order by deleting the previously selected sorting criterion.

    Multiple sorting (Optional)

    This function allows the pieces in the list to be sorted using more than one criterion.

    In this mode, sorting criteria can be added using the following buttons:

    Add sorting criterion
    Adds a sorting criterion to the list.

    Change position
    Changes the position of a created sorting criterion in the list.

    NOTE

    The criteria in this list are applied from top to bottom.
    This means that pieces are sorted according to the first criterion. If two or more pieces have the same value for the property linked to the first criterion, they are sorted according to the next criterion, and so on for every criterion in the list.
