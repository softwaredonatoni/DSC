    DOC3.3 TOOL PANEL

    The following screen allows the operator to manage the machine tools.

    Tool type selection

    Each tool type has a selected tool, as shown in the following example image:

    Disk
    List of disks that can be mounted on the machine main spindle.
    “Disk 400” with a diameter of 400.0 mm is currently installed.

    Tools
    List of tools (milling cutters and core drills) that can be mounted on the machine secondary spindle.
    “Milling Cutter 26” with a diameter of 26.0 mm is currently installed.

    The background of the “Disk” type appears light blue because it is the currently selected tool category.
    Simply click the rectangle of the desired tool type to update the tool list below with the tools available for that type.
    As a result of changing the tool type, it is automatically selected as shown in the previous example image.

    List of available tools for selected tool type

    The tool list shown as an example in the following image contains four disks: “Disk 400”, “Disk 625”, “Disk 2755” and “Disk 325”.
    The first disk in the list is the one currently mounted on the machine; this is indicated by the light-green background and green check mark.
    In the right-hand section, the parameters relating to the selected tool are shown.

    List elements

    Tool type
    Shows the tool type (disk, milling cutter, core drill).

    Main tool information
    The main tool information is displayed: name (top) and diameter (bottom).

    Force Tool
    Allows the operator to tell the program which tool is currently mounted on the machine.
    It is used if the tool was changed manually.

    Search filter

    The bottom of the tool list contains a search bar consisting of the following elements:

    The elements making up the search filter are described below:

    Search by tool name button
    If this button is pressed, search-by-tool-name mode is enabled and the search-by-diameter button is disabled.

    Search by tool diameter button
    If this button is pressed, search-by-diameter mode is enabled and the search-by-tool-name button is disabled.

    Button to clear the applied filter
    It becomes selectable only if a filter has previously been applied; pressing it clears the search bar text and restores the view containing all tools of the currently selected type.

    Bottom bar

    The bottom bar of the tool list provides functions for adding and removing tools from the list.

    Add tool
    This button can be used to create new tools; a dedicated window, shown below, opens.

    Delete tool
    This button can be used to delete the selected tool.

    NOTE

    The tool currently mounted on the machine (indicated by the green check mark) cannot be removed from the list.

    Duplicate tool
    Creates a new tool by duplicating the parameters of the currently selected tool.
    The new tool has the same name as the previous one followed by the word “Copy”.

    Add tool

    This window is used to create a new tool. The required parameters change according to the type of tool to be created.
    The following image shows the new-tool creation window for the available types:

    Milling

    Parameter list for selected tool

    This list contains all parameters relating to the currently selected tool.
    Whenever the currently selected tool changes, the operator can view the updated values for the desired tool and make changes to each value if required.
    The parameter list and its values are also updated when a different tool type (Disk / Tools) is selected, showing the values of the selected tool for each category.

    Disk parameters

    The parameters associated with a disk are shown below.

    Name
    Name of the tool associated with the parameters currently displayed.

    Diameter
    Maximum tool diameter measurement.

    Disk thickness
    Disk thickness measurement, to be measured at the teeth.

    CRF - Flange Rotation Center
    Distance from the inner edge of the disk tooth to the C rotation axis.

    Junction Quote
    Safety position used by the machine when performing positioning movements during automatic programs.

    RPM
    Indicates the maximum spindle rotation speed in revolutions per minute.
    This value is associated with 100% of the disk control potentiometer.

    Internal water
    Allows the use of internal water during machining to be enabled or disabled.

    NOTE

    For disk-type tools it is always disabled.

    External water
    Allows the use of internal water during machining to be enabled or disabled.

    NOTE

    For disk-type tools it is always enabled.

    Disk rotation speed

    The following button is located to the right of the RPM parameter:

    RPM information
    Displays the table with speed-to-RPM conversions.

    This window displays a table containing conversions from rotation speed to RPM based on the diameter of the selected disk.
    Recommended values for the selected disk are highlighted in green.

    Milling cutter and core drill parameters

    Parameters relating to tools such as milling cutters and core drills are shown below.

    Tool length
    Indicates the distance from the tool tip to a reference point.

    Tool probing

    If the machine is equipped with the optional tool-probing device, the procedure can be activated from this panel.
    Starts a cycle that can calculate the diameter for a disk, or the length for milling cutters and core drills.

    Buttons

    One of the following buttons is located on the right side of the panel.

    Start disk probing
    Starts the probing cycle to measure the diameter of the mounted disk.

    Start secondary-tool probing
    Starts the probing cycle to measure the length of the mounted secondary tool.

    NOTE

    The disk probing button is available only in the “Disk” section of the panel.
    The secondary-tool probing button is available only in the “Tools” section of the panel.

    Procedure

    To measure the diameter of the disk or the length of the core drill/milling cutter currently mounted on the machine, press the corresponding button in the right-hand section of the panel.
    At the end of the cycle, the program automatically updates the value corresponding to the measured tool dimension.

    Other buttons

    The following button is located at the bottom left of the screen:

    Switch to the “Slab machining parameters” panel
    Pressing this button switches from the “Tool Panel” to the “Slab Parameters” panel.
