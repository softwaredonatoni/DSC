    WARNING!

    Top bar

    Parameters
    Provides access to the Parametrix program parameters.

    Parameters tool
    Pressing the button opens the tool parameters page. See the “Tool Configuration” chapter for a detailed description of the parameters page.

    Automatic 0/90-degree rotation
    The “C” axis is automatically moved to either 0 or 90 degrees when the button is pressed.

    Automatic parking
    When pressed, the machine automatically moves the “X”, “Y”, “Z” and “C” axes to their zero positions.
    The machine performs the movements in the following order:
    (A) - “Z” axis to the absolute zero position;
    (B) - “C” axis to the absolute 0 position;
    (C) - “X” and “Y” axes simultaneously to the absolute zero position;

    WARNING!

    Certain safety conditions must be met in order to perform automatic parking:
    The “A” axis position must be 0_.
    Make sure that the movement area involved in positioning (see figure alongside) is clear.

    Zero
    Performs axis zeroing (this operation is required when the machine is started or when the rectangular indicators are red).
    When the zeroing cycle is complete, the indicators turn gray.
    The zeroing procedure includes sequential movement of the axes:

    1. Z axis

    2. A axis

    3. C axis

    4. X and Y axes simultaneously

    5. B axis (Optional: controlled lathe)

    NOTE

    Zeroing is permitted only when the coded key is inserted in the designated position on the operator console.

    Internal water ON/OFF
    Pressing this button activates the water supply through the inside of the tool.
    The indicator above the button changes color: Green = On; Red = Off.

    Water ON/OFF
    Pressing this button activates the water supply from the main line.
    The indicator above the button changes color: Green = On; Red = Off.

    Manual Tool Change
    Pressing the button starts the tool change procedure.

    Maintenance
    Pressing this button displays a window containing all machine maintenance operations.
    Both maintenance operations that need to be performed and those within normal limits are displayed.
    If at least one maintenance operation requires it.

    Help
    Pressing this button slightly changes the appearance and behavior of all buttons currently visible. You can then press any button with a small question mark in the upper-left corner to learn about the function provided by that button through a short message. To exit this help mode, simply press the “Help” button again.

    Axes

    This interface displays the machine axis values.

    Example of the “Axes” interface element with origin 0 and the axes already zeroed:

    Example of the “Axes” interface element with origin 0 and the axes not yet zeroed:

    The elements making up this section of the common interface are explained below, using the elements shown when the axes have already been zeroed as reference.

    Actual position: indicates the axis position relative to the active origin.
    Target position: indicates the position to be set in order to move the axis by pressing the MDI or RTCP button.
    F: Feed, movement speed expressed in mm/minute.
    DTG: Distance To Go, distance from the target.
    A: Ampere.

    Axis Reset
    Pressing this button sets the zero point of the active origin at the current position of the corresponding axis (X, Y or Z).
    The axis reset operation can only be performed on origins other than 0 (zero).
    To use the tool-coordinate origin (TCP), the correct dimensions of the mounted tool must be set before pressing the Axis Reset button.

    Automatic _90-degree rotation
    The “C” axis position is increased by 90 degrees clockwise.
    Example: if the machine is at 12 degrees, pressing the “Automatic _90-degree rotation” button moves the machine to 102 degrees: 12 _ 90.

    Automatic -90-degree rotation
    The “C” axis position is decreased by 90 degrees counterclockwise.
    Example: if the machine is at 102 degrees, pressing the “Automatic -90-degree rotation” button moves the machine to 12 degrees: 102 - 90.

    Controls

    This panel contains several buttons whose behavior is explained below:

    MAN (Enable manual movement)
    To use the machine in manual mode, the spindles must be positioned correctly and certain functions must be enabled. This button is provided for this purpose.

    NOTE

    When manual operation is enabled, the adjacent indicator LED turns green.

    Suction cup axis
    Reference axis on which the suction cups are mounted.

    Ampere threshold
    Indicates the threshold above which the alarm is activated and spindle rotation is stopped.

    Selected origin
    Clicking the “Origin” field allows the operator to change the origin to be used.
    Changing this field triggers an update of the Axes values.
    Origin values can range from 0 to 19 inclusive.

    MDI
    When pressed, the machine moves until the positions set as target positions are reached (see above).
    The speed of the X and Y axes is controlled by their respective potentiometers, while the other axes are controlled by the interpolated potentiometer.

    Suction cups

    The suction cups can be used manually to move pieces from one work zone to another.

    Suction cup buttons

    Enable / disable suction cups
    The screen shows the suction cup assembly viewed from above, divided into its various zones. Pressing the relevant area changes its status.
    Green indicates that the zone is set for vacuum.
    Red indicates that the zone is set for blowing.

    SUCTION CUPS: RAISE - Suction cup parking
    When the button is pressed, the suction cups are retracted to the rest/parking position.

    SUCTION CUPS: LOWER - Prepare suction cups
    When the button is pressed, the suction cups are lowered from the parking position to the limit stop. It is important that there is enough space for the suction cups to extend completely.

    LIFT PIECE: RELEASE - Unload piece
    When the button is pressed, the Z axis is lowered until the material contacts the work surface, the vacuum pump is switched off, and blowing is activated from all suction cups to release the piece. After a timeout, the axis is raised to the safety position.

    LIFT PIECE: START - Lift piece
    With this command, the suction cups are brought into contact with the material, the vacuum pump is switched on in the areas marked green and blowing is activated in the areas marked red; once the vacuum switch indicates that vacuum has been generated, the axis is raised to the position set for movements.

    WARNING!

    Pay attention to the active suction cups and use the largest possible area to lift the piece.

    VACUUM - Vacuum pump control
    This button switches the vacuum pump on and off. The indicator shows whether the pump is on (green) or off (red).

    BLOW - Blow control
    The button switches blowing on or off from suction cups that are not set for vacuum. The indicator shows whether blowing is on (green) or off (red).

    Safety conditions

    Pay particular attention to the active suction cups during lifting, ensuring that the areas used are sufficient to lift the piece being moved. Always try to use the largest available vacuum area to grip the piece and check that there are no defects or breaks in the material that could create hazards or machine operating problems.
    Once the vacuum pump has been switched on, it may only be switched off using the automatic functions provided for this purpose. Pressing the reset button or the emergency stop mushroom has no effect on the vacuum pump, which will continue to operate. The pump can be forcibly switched off using the dedicated button on the “Additional Controls” page.
    During automatic procedures, before lifting the piece, the vacuum status is checked by a dedicated sensor: if a sufficient vacuum value is not detected, the “vacuum missing” alarm appears. The pump will remain active until the vacuum switch detects a correct value or until it is disabled from the “Additional Controls” page.

    WARNING!

    Loss of power to the vacuum pump causes a rapid loss of vacuum and consequently causes the material lifted by the suction cups to fall.

    Alarm display - Standard

    The standard display of one of the alarms consists of:

    Online link
    A button with a link to the relevant online guide.

    Alarm code
    Identification code of the problem that caused the alarm.

    Description
    A brief description of the detected error.

    Alarm display - History

    In addition to the items already described, the daily alarm history also includes the following data:

    Status change time
    Date and time when the alarm status changed.

    Alarm status
    Status reached by the alarm (ON / OFF).

    Alarm display - Groups

    The grouping system displays a single entry for each alarm, avoiding duplicates.

    Number of occurrences
    The number of times the alarm has been activated.

    First activation time
    Date and time of the first alarm activation.

    Last activation time
    Date and time of the most recent alarm activation.
