    DOC3.11.2 CREATING RECTANGLES

    Rectangular pieces can be created by entering their width and height and placing them in the list of pieces to be machined.

    The program can also associate an identifying mark (or label) with each piece and set the number of repetitions for rectangles of the same size.

    Parameter description

    The following data is required to create rectangular pieces:

    Number of pieces
    Number of copies of the piece having the same dimensions.

    Width
    Width of the rectangle. It is measured in the unit shown to its right.

    Height
    Height of the rectangle. It is measured in the unit shown to its right.

    Mark
    Label added to the piece for identification. This parameter is optional, as it is not essential for creating the piece.

    Additional buttons

    The following side buttons can also be used to perform additional actions.

    Single import
    When this button is enabled, multiple separate pieces can be created with a quantity of one each, instead of one piece with multiple copies.

    Dynamic Tag Top
    Assigns the Dynamic Tag Top to one side of the rectangle.

    To enable the function associated with a button, press the button. It is then highlighted in light green.

    NOTE

    The “Dynamic Tag Top“ buttons next to the width and height boxes are mutually exclusive. The Dynamic Tag Top can therefore be assigned to only one side of the rectangle.
