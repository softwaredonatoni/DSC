    DOC3.13.13 LEVELING (OPTIONAL)

    This function allows the operator to level the piece.

    Parameters

    Pass Extension

    Each cut generated by this machining operation is extended at both the start and end by the length specified by this parameter.

    Executing the machining operation

    Starting from the slab thickness set in the material parameters, the piece is machined as follows to reach the target thickness set in the machining parameters:

    1. First, parallel cuts are performed from left to right at a distance set in the parameters, using the linear-cut parameters.

    2. Then cuts are performed along the Y axis to create a grid, again using the linear-cut parameters.

    WARNING!

    The initial slab thickness must be set as the material thickness (probing can then be added for greater accuracy).
    The target thickness is set in the machining parameters (and is referenced to the workbench position).

    NOTE

    The following machining operation can also be performed on commercial pieces.

    Slab machining parameters

    The operator can change leveling-related parameters from the slab machining parameters panel.

    Leveling cut parameters

    Parameter description

    Distance between horizontal passes
    Represents the distance between two parallel passes in the horizontal direction.
    The button selects whether the passes are performed from top to bottom or vice versa.

    Distance between vertical passes
    Represents the distance between two parallel passes in the vertical direction.
    The button selects whether the passes are performed from left to right or vice versa.

    Leveling position
    Sets the thickness the material must have after leveling.

    Rotate tool 90 degrees
    If enabled, leveling is performed with the A axis at 90_.
