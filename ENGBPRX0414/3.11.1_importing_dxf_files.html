    DOC3.11.1 IMPORTING DXF FILES

    In this section, pieces can be created by importing DXF files.

    File list

    On the left side of the window, a list shows all folders and DXF files contained in the currently selected path.

    The item at the top of the list

    allows you to return to the parent folder of the current folder.

    Initially, the list of DXF files in the PC working folder is shown. The folder can be changed using the dedicated buttons to the right of the file list.

    USB memory
    Provides access to the USB memory device inserted in the PC, allowing folders to be browsed and files displayed.

    Working folder
    Quick access to the PC working folder.

    Browse folders
    This button can be used to browse all folders on the PC.

    Delete file
    Switches to “Delete file” mode. In this mode, an eraser icon appears to the left of the name of each file in the list.
    Selecting a file in this mode permanently deletes it.

    Sort and filter displayed files

    The elements below the list manage the application of filters and sorting of the displayed files.

    At the top of the image there is a search bar that can be used to filter files by name, displaying only those containing the entered text.

    This section of the screen also contains the following buttons:

    Clear filter
    Clears the text entered in the search bar, removing the file display filter.

    Sort by date
    Sorts the files in the list by creation date. By default, they are sorted from newest to oldest. Pressing the button again sorts the files from oldest to newest. The operation can be repeated several times to change the sorting order.

    Sort by name
    Sorts the files in the list by name. Press the button to choose whether the files are sorted in ascending or descending order.

    NOTE

    Search by name applies only to files contained in the folder and not to any subfolders.
    By contrast, sorting by name and by date applies to every item in the list, while always showing folders before files.

    Preview

    When a file is selected, a preview of the drawing is displayed in the panel at the center of the screen so that its contents can be identified immediately.

    The preview can be manipulated either by dragging its contents or by using the buttons to its right.

    Zoom in
    Increase preview zoom.

    Decrease zoom
    Decreases preview zoom.

    Restore view
    Restores the preview display to its initial state, with the entire drawing visible.

    Additional buttons

    The following buttons also allow additional actions to be performed.

    Panel Details
    Opens the panel for viewing details of the selected DXF file.

    Side panel

    Visibility and padding buttons

    In addition to the previously shown buttons for changing the zoom level and restoring it, there are two new buttons:

    Highlight selected piece
    Zooms in on the piece selected from the polyline list.

    Pan view
    Allows the preview to be moved by interacting with the screen.

    Polyline list

    On the center-right side of the panel, the pieces making up the selected DXF are shown as polylines.
    Selecting one of the values in the list highlights the corresponding piece visible in the preview in yellow.

    When the button next to each piece is pressed, the list of polylines making up the piece becomes visible.
    A single DXF polyline can also be highlighted simply by selecting its corresponding row in the list:

    Bottom buttons

    These buttons are located at the bottom of the side bar.

    Find previous open polyline
    Moves through the list of open polylines in the selected DXF toward the beginning of the list.

    Find previous open polyline
    Moves through the list of open polylines in the selected DXF toward the end of the list.
