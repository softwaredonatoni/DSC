    DOC3.13.16 SPLIT

    The ‘Split’ function divides the piece using a reference, a side, a perpendicular line or a custom line.

    Parameters

    To use this machining operation, first select one of the three available modes by pressing the corresponding button:

    Parallel cut
    In this mode, the dividing cut is performed along the longitudinal axis of the selected side.

    Orthogonal cut
    In this mode, the dividing cut is performed obliquely relative to the selected side, with its origin at the centre of the side.

    Cut through two points
    In this mode, the dividing cut is defined by manually specifying the coordinates of the two endpoints that determine the separation line between the pieces.

    Parameters for ‘Parallel cut’ and ‘Orthogonal cut’

    The following two controls can be enabled or disabled by clicking the check box to the right of ‘Cut extension’.

    Cut extension

    This function allows the operator to extend the cut applied to the selected side so that it covers the entire length of the piece in the cutting direction.

    Offset

    The operator can set the transverse distance of the cut, measured from the centre of the reference side.

    Parameters for ‘Cut through two points’

    The following control allows the coordinates of the two points forming the dividing line to be defined.

    Set dividing-line point parameters

    When the function is enabled, four parameter fields are available in which the operator can specify the coordinates (X, Y) of the start and end points of the cutting line.

    Cut orientation
    Using the dedicated command, the user can select a horizontal, vertical or free cut orientation relative to the previously set line start point.

    Snap to vertices
    When Free Cut is selected in the previous parameter, an additional parameter appears to its right. When enabled, it facilitates selection of the shape vertices when defining the cutting-line points.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the required cut.

    Splitting pieces

    When one or more pieces have been associated with the selected piece through Split operations, a dedicated button for managing associated pieces appears at the top of the “Edit Piece” panel.

    Split pieces
    Separates the split pieces from the original piece.

    Before splitting, the associated pieces are managed as a single unit within the work area. In this state, they form a block of multiple elements that undergo the same operations and have not yet been separated.

    For example, when one of the pieces generated using Split is added to the work area from the piece list, all other associated elements are also inserted automatically.

    When the Split Pieces button is pressed, each piece generated using Split is disassociated from the original piece and treated as an independent item.

    The associated-piece list previously shown above the preview in the Edit Piece panel and the Split Pieces button then disappear from the interface.

    WARNING

    !
    The piece splitting operation cannot be undone once executed.
