    DOC3.21.5 SINGLE CUT

    This function allows linear disk cuts to be inserted manually on the workbench.

    Buttons

    Directional Movement
    Moves the selected vertex in one of the directions.
    The movement distance can be modified in the text box below.

    Delete
    Allows the cut and its vertices to be removed from the work area before confirmation.

    Horizontal Cut
    Allows a horizontally arranged cut to be inserted.

    Vertical Cut
    Allows a vertically arranged cut to be inserted.

    Executing the Function

    After pressing the button, the program asks the user to select the start and end points of the cut to be added in the work area.

    The positions of the cut ends can be changed by selecting and dragging them in the work area, or by using the directional movement arrows.

    The operator can force the resulting cut to be arranged horizontally or vertically.

    Upon confirmation, the new cut is added to the bottom of the list.
