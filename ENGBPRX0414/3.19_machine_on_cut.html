    DOC3.19 MACHINE ON CUT

    Allows the position of the piece in the work area to be checked against its position on the machine. When “Machine on cut” is enabled, a cut is selected on the screen and the machine moves to the corresponding position.
    This operation is useful for checking whether a cut lies within the material.

     

     

    Execution

    Pressing the button displays the machine in the work area.

    Pressing one of the cuts moves the machine so that the centre of the disk is positioned at the end of the cut closest to the selected point.

    NOTE

    Any type of cut can be selected, including core drilling and milling.

    WARNING!

    To perform the movement, the machine A axis must be at 0_.

    Advanced mode (Optional)

    Advanced mode allows different machine elements to be positioned at the selected point.
    When the function is enabled, the following panel appears:

    Disk centre alignment
    Positions the centre of the disk at the end of the cut closest to the selected point.

    Cross laser alignment
    Positions the cross laser at the end of the cut closest to the selected point.

    Second tool alignment
    Positions the second tool (milling cutter or core drill) at the end of the cut closest to the selected point.

    Tool Plus alignment
    Positions the Tool Plus at the end of the cut closest to the selected point.

    NOTE

    The fourth and final button in the small panel is visible only if the machine is equipped with “Tool Plus”.

    Disk centre alignment

    Equivalent to standard mode. The machine moves so that the centre of the disk is positioned at the end of the cut closest to the selected point.

    Cross laser alignment

    The machine moves so that the cross laser pointer is positioned at the end of the cut closest to the selected point.

    Milling cutter or core drill alignment

    The machine moves so that the centre of the second tool mounted on the machine, whether a milling cutter or core drill, is positioned at the end of the cut closest to the selected point.

    WARNING!

    To use this function, the A-axis inclination must be moved to 90_.

     

    Tool Plus alignment

    The machine moves so that the centre of the tool mounted on Tool Plus is positioned at the end of the cut closest to the selected point.
