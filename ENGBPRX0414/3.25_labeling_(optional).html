    DOC3.25 LABELING (OPTIONAL)

    This function allows the operator to generate labels on the piece before pressing the PGM button.

    Buttons

    The button for accessing the labeling function is located on the bottom bar of the Parametrix main screen.

    Labeling
    Opens the panel used to manage labeling

    There are two distinct labeling modes, described below.

    Basic Labeling Mode

    Basic mode provides the operator with three possible labeling methods in the corresponding panel.

    Labeling in the work area
    After selecting a piece, the operator presses this button to apply labeling directly in the preview.

    Labeling from piece list
    Clicking this button generates labels from the piece list.

    Labeling with manual information entry
    Clicking this button generates labels by manually entering the piece information.

    Labeling from piece list

    Print labels
    Starts the procedure for generating the selected labels.

    Labeling with manual information entry

    This mode allows label information and the related additional properties to be managed.
    A small panel similar to the one shown below opens:

    Additional Properties
    Provides access to the panel for editing a piece's additional properties.

    Additional label-printing properties

    Additional properties can be managed in the following panel according to the additional properties that have been correctly set.

    The following buttons allow the operator to quickly manage the additional properties:

    Copy additional properties
    Allows the operator to copy all values of the additional properties currently displayed.

    Paste additional properties
    Allows the operator to paste previously copied values into the additional-property fields.

    Advanced Labeling Mode

    As with the previous mode, this mode provides buttons for Labeling in the work area and Labeling from the piece list.

    The piece list on the left shows only one occurrence of each piece.
    The remainder of the window shows a preview of the currently selected label.

    The following buttons are available to the operator at the bottom of this panel:

    Enable/Disable multiple selection
    Enabling this mode allows multiple list items to be selected as desired.
    Disabling it allows the operator to select only one item at a time.

    Select all list items
    Enabling the button selects all items in the list, while disabling it deselects all items except the one currently selected.

    Print labels in Open State

    Once the PGM has been generated, the corresponding labels can be printed by accessing the "Open State" section located at the lower right of the window. At this stage, dimensions are automatically added to the drawing.

    Pressing the ‘Print Labels’ button displays the following panel, which allows the labels to be printed to be selected.

    The left side of the panel lists all pieces in the selected state, including repeated pieces.
    The remainder of the window displays a preview of the currently selected label.

    It is recommended to use a label format of suitable dimensions (e.g. 20 cm x 10 cm) to ensure that the dimensioned drawing is clearly legible.

    NOTE

    The label configuration (format and content) is set during installation; the configuration is unique and cannot be changed by the operator.
