    DOC3.13 EDIT PIECE

    This panel allows the operator to apply different types of machining to a selected piece.
    When it is opened, the following screen is displayed:

    WARNING!

    Some of the functions described in this section are also available on the Parametrix main page, but there is an important difference.
    If a piece or cut is edited using the ‘Edit Piece’ panel, all pieces in the selected row are changed accordingly with the same machining operations.
    By contrast, if machining is set from the work area, only the selected piece is changed.

    Machining types

    The “Edit Piece” panel can be used to apply one or more of the following machining operations, each of which is described below. In particular, Parametrix can:

    Miter
    Change the inclination of cuts, both under-square and over-square.

    Drip system
    Add a drip groove beside a cut.

    Add
    Add a cut parallel to one side of the piece.

    Delete
    Delete cuts from the piece.

    Offset
    Change the piece dimensions by applying offsets to its sides.

    Hole
    Add holes in the material, including to remove material that the saw blade could not cut.

    Milling
    Replace saw-blade machining operations with milling cuts.

    Recess
    Apply milled recesses. This is used, for example, to create sink cut-outs in kitchen worktops.

    Lower Cut - (Optional)
    Perform a cut on the lower surface of the piece using a dedicated mechanical option.

    Downstand
    Add upstands or lowered panels to the sides of the piece.

    Kerb
    Add a chamfered cut to one side of the piece.

    Surface - (Optional)
    Apply surface passes using vertical cuts and a horizontal saw blade.

    Surface Levelling - (Optional)
    Apply a surface-levelling cycle using vertical cuts and a horizontal saw blade.

    Channel - (Optional)
    Add a drainage channel to the piece using the saw blade.

    Fillet
    Round a vertex or side of the piece by applying a fillet.

    Split
    Cut the piece using a side or a custom line as a reference.

    Internal cut-out
    Add a rectangular, circular or elliptical internal cut-out to the piece.

    Flutes
    Create grooves by milling.

    Maximum Envelope - (Optional)
    Determine the maximum envelope of the piece.

    Mirror
    Create a mirrored version of the piece.

    NOTE

    Depending on the combination of options, some of these buttons may not be available.

    Cut list

    The cuts on the piece are displayed in the lower-left section of this panel.

    A dedicated subdivision indicates whether a cut belongs to the external perimeter or to one of the internal perimeters. This classification makes it possible to show/hide the list of cuts belonging to a polygon by pressing the icon for the corresponding section.

    As shown in the image, each row displays information about the cut it represents. In particular:

    Manage machining
    Button used to interact with the cut and apply the current machining operation.
    On the main page, it enables/disables the cut.

    Cut information

    • T - indicates the cut type (“Line”, “Curve”, “Milling”, etc.).

    • D - indicates the cut length.

    • I - indicates the cut inclination.

    • P - indicates the cut penetration.

    Machining information

    • Machining type (“Linear”, “Arc”, “Miter”, etc.).

    • Pass mode (Full-depth pass or Step pass).

    • Cut feed speed.

    • Diameter of the tool used for machining (Saw blade, Milling cutter, etc.).

    NOTE

    This information changes according to the cut type. Not all information is always displayed.
    For holes, for example, only penetration into the material can be displayed.

    NOTE

    If no cut is present on part of the piece, this is indicated by “None”.

    Preview

    The main part of the "Edit Piece" function provides the operator with a complete preview of the selected piece, showing all machining operations currently applied.

    The displayed piece can be manipulated simply by moving the preview or by using the zoom controls to its right.

    This section also contains other functions, which are described below.

    Mark
    Allows the mark of the selected piece to be changed.

    Number of pieces
    Allows the number of machined pieces and the total number of pieces to be changed.

    Add favourite
    The piece shown in the preview is added to the favourites list together with all changes applied when it is added.

    Cut selection

    A cut can be selected directly in the preview; its colour changes to yellow to confirm selection. Alternatively, select the corresponding row in the cut list in the bottom-left menu.

    Clicking the green indicator to the left of each list element disables the corresponding cut.
    The indicator turns red and the piece preview is updated, with the disabled cut changing to grey.

    Bottom bar

    This bar provides functions that make the Edit Piece operations easier to use:

    Cuts
    Displays the list of cuts on the piece.
    This is the default view of the panel.

    Sides
    This button displays the lengths of the Piece sides in the list instead of the cut lengths. Selecting directly in the image or list highlights the selected piece side in yellow.

    NOTE

    Machining operations cannot be added to the piece in this mode.

    History
    Displays the history of operations applied to the piece.
    It also allows the piece to be restored to the required operation.

    Undo
    Undoes changes made to the piece.
    Pressing this button repeatedly restores the piece to its initial conditions.

    WARNING!

    The button works only while the “Edit Piece” panel remains open for the piece being examined.
    If the panel is closed, the option to undo changes to that piece is lost, even if the panel is reopened.

    Edit view
    Enables or disables certain piece entities to improve visibility and make the piece easier to edit.

    History

    Displays all changes applied to the current piece and, if necessary, restores the current piece to a previous state.
    If changes have been applied to the current piece, they are shown in the list on the left:

    The menu on the left displays the machining states of the piece.

    Machining state
    Identifies a specific point in the machining history of the piece. It displays:

    • Name of the current piece;

    • Date on which the machining operation was applied;

    • Name of the machining operation applied;

    • Icon identifying the machining operation performed.

    The unmodified state of the current piece is called "Default".
    Selecting an item from the menu on the left displays the preview corresponding to the point at which that machining operation was applied.

    Pressing the confirmation button restores the piece to the selected state. Any changes made after the selected state are removed.

    At the bottom of the panel are three utility buttons for displaying the piece in the preview:

    Show cuts
    Shows the cuts on the shape.
    This is the default active view.

    Show dimensions
    Shows the dimensions of each side of the shape.

    Show angle
    Shows an angle of the shape with its dimensions.

    Edit View

    This mode provides the operator with buttons that are visible only when “edit view” is enabled.

    Each of the following buttons enables or disables one of the following piece elements:

    Cuts
    Shows/hides saw-blade cuts in the preview.

    Holes
    Shows/hides holes.

    Milling operations
    Shows/hides milling operations.

    Recesses
    Shows/hides recesses.

    Cut arrows
    Shows/hides the arrows indicating the direction of saw-blade cuts.

    Piece name
    Shows/hides the piece name.

    Dynamic Tags
    Shows/hides the piece Dynamic Tags.

    Highlight Perimeter
    Highlights the piece perimeter with a black line.
