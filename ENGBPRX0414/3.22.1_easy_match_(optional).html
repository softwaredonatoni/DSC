    DOC3.22.1 EASY MATCH (OPTIONAL)

    With the Easy Match function, the operator can see in real time the background that pieces will have in the original position in which they were designed while moving them on the workbench over a slab.

    NOTE

    Easy Match mode works only for pieces imported from DXF files.

    Buttons

    After pressing the button, the following panel opens:

    Side-by-Side View
    Displays both the project preview and the workbench on the same screen.

    Preview View
    Allows pieces to be moved by clicking inside the perimeter of the piece itself, making it possible to position the piece in the desired location more precisely.

    Workbench View
    Allows pieces to be moved on the workbench using the entire screen.

    Save Preview
    Saves an image representing the preview of the current project.

    Edit preview
    Provides access to a screen where the arrangement of elements within the project preview can be modified.

    Preview View

    Allows pieces to be moved by clicking inside the perimeter of the piece itself, making it possible to position the piece in the desired location more precisely.

    The preview displays all pieces from the imported file in the exact position in which they were designed.
    The preview size corresponds at a 1:1 scale to the dimensions of the designed pieces.
    Pieces added to the workbench take on the slab color, while pieces still to be added have a uniform background.

    From the preview it is possible to:

    • Add a piece to the work area by clicking inside the area to be processed.

    • Move a piece located on the workbench.

    • Select a piece on the workbench by clicking inside the piece.

    • Delete a piece from the preview by selecting the eraser below the piece list and then selecting the piece in the preview to be deleted. In this case, the piece is also deleted from the workbench and from the piece list.

    Workbench View

    Classic Parametrix workbench view. Allows pieces to be moved on the workbench using the entire screen.

    Side-by-Side View

    Displays both the project preview and the workbench on the same screen.

    Save Preview

    Allows the preview of the current working to be saved.
    The following screen opens:

    The operator is asked to choose the preview name, whether to save it as an image or PDF, where to save it, and its resolution.
    For the resolution, the available choices are auto (automatic resolution), low, medium, high, ultra, and custom (the operator chooses the exact resolution).
    Once confirmed, the preview photo or PDF opens automatically.

    Edit preview

    On this screen, the pieces that make up the preview can be arranged as desired.
    All changes made here are also reflected later in the other views.

    The following buttons are available on the top bar.

    Move pieces
    Allows the pieces that make up the preview to be moved.
    Displays the buttons on the bottom bar of the window.

    Pan view
    Used to move the preview view containing all pieces.

    Preview Customization

    In the program parameters panel, on the user values tab, the colors of some elements in the project preview can be changed.

    Perimeter

    Shows/hides the perimeter of the pieces in the preview.
    The display color can be changed using the adjacent button.

    Name

    Shows/hides the names of the pieces in the preview.
    The display color can be changed using the adjacent button.

    Background

    Sets the preview background color.

    Remove Background
    Removes the background from the preview.

    Workflow

    To work using Easy Match, the project must be imported into Parametrix from a DXF file.
    The program displays a Book Match preview for the pieces contained in the file.

    After taking a photo of the workbench, the pieces to be cut can be placed on the slab.
    To do this, use the standard procedure from the piece list or press inside the perimeter of one of the pieces shown in the preview.

    Dragging the piece from the preview also moves it on the slab, which is useful for matching the veining between the various pieces.
    The reverse can also be done: drag the piece from the slab and use the preview to check whether the veining matches depending on where it is moved.

    At this point, proceed with the standard working procedure: create the ISO program and cut the slab.
    Once finished, press the button to move to the next working.
    The preview retains the project progress status.
    Proceed by acquiring a photo of a new slab and placing the pieces inside the perimeter.

    Continue in this way until the project is completed.
