    DOC3.21.4 MATERIAL HANDLING WITH SUCTION CUPS

    This function divides the slab and moves the material using the suction cups.

    Buttons

    Manual movement
    Gives the operator full control over the movements to be performed.

    Automatic movement
    Automatically performs the most suitable movements.

    Manual movement

    This function allows the operator to divide the slab using cuts and move the material to the required position using the suction cups.
    Depending on the number of selected cuts, this function has two modes.

    Single-selection mode

    To perform a movement using the suction cups, select a saw blade cut, either linear or arc, and press the button.
    The cut is extended to the slab edge where possible.
    If the selected cut is inclined, a dedicated linear cut is added automatically so that the slab can be divided.

    The following panel opens, where the direction, orientation and distance of the required movement can be specified.

    The right-hand section contains these buttons:

    Directional movement
    Moves part of the cut slab in one of the directions.
    The movement distance can be changed in the text box below.

    Select an arrow in the work area or press one of the buttons on the right to select the direction and orientation of the movement.
    The slab is divided and moved according to the type of cut selected.
    In both cases, the slab movement distance can be changed in the text box below the four directional buttons.

    The selected cut is moved as high as possible in the list of cuts to be performed. The suction-cup movement is executed immediately afterwards.

    WARNING!

    The operator is responsible for checking whether the movement is feasible.

    Multiple-selection mode

    Multiple-selection mode allows pieces of any shape to be lifted. To do this, select the cuts required to divide the slab using multiple-selection mode.

    After making the selection, press the button to start the procedure.

    The selected cuts are extended, where possible, to form a continuous path that divides the slab. If one or more selected cuts are inclined, they are automatically replaced with non-inclined cuts.

    The following panel then opens.

    After selecting the slab section to be moved, the movement can be defined by dragging it in the work area or using one of the following buttons:

    Step
    Enter the movement distance in mm applied whenever one of the directional buttons is pressed.

    Movement along the axes
    These boxes display values representing the vertical and horizontal movement of the slab relative to its starting position.
    The values can be changed manually to define the slab movement.

    Cut collision check
    Parametrix automatically checks that no protruding cut damages the other section of material at the new slab position. If a problem is detected, the slab is moved to the nearest suitable position.
    This check can be disabled to give the operator full control over the movement.

    Restore original position
    Returns the moved slab section to its original position.

    When confirmed, the selected cuts are moved to the top of the list of cuts to be performed. The suction-cup movement is executed immediately afterwards.

    WARNING!

    Multiple-selection mode allows pieces of any shape, including overhanging pieces, to be lifted.
    The operator is responsible for checking whether the movement is feasible.

    Rules for a valid cut selection

    To divide the slab correctly, the following cut-selection instructions must be observed.

    • The selected cuts may be saw blade cuts, either straight lines or arcs, milling operations, or multiple holes at corners.

    • The selected cuts must form a path that divides the slab into two sections. Cuts forming a closed path cannot be selected.

    • The program automatically extends linear saw blade cuts until a solution that divides the slab is found. Arc cuts, milling operations and holes are not modified automatically.
      It is therefore advisable for the first and last cuts in the path to be linear saw blade cuts.

    • At internal corners where saw blade overcut does not separate the material completely, vertex milling operations or multiple holes must be inserted.

    • The penetration of the selected cuts must be sufficient to separate the slab.

    • The first and last cuts must be able to extend outside the slab.

    Operation not possible message

    If the program considers the movement operation impossible, the causes may be as follows:

    • The selected cuts are insufficient to create a path that divides the slab into two sections;

    • The selected cuts form a closed path;

    • The selected cuts cannot detach the piece because of saw blade overcut;

    • Extending the selected cuts would damage other pieces;

    • The penetration of at least one selected cut is insufficient to separate the slab;

    Automatic movement

    This function attempts to resolve automatically situations in which one or more pieces in the work area would be damaged by other cuts.

    The algorithm analyses the cut arrangement and independently determines how and where to perform movements, optimising the operation sequence.

    However, automatic calculation cannot always manage every situation. In particularly complex cases, manual intervention may be required to complete or correct the movements.

    WARNING!

    The operator is responsible for checking whether the movements are feasible.

    Changing the suction cup position

    During this phase, the operator can change both the suction cup gripping position and activation of the corresponding vacuum zones to ensure an optimal and safe grip on the material.
    To do this, select the “Move“ item in the list and press the cut editing button.

    The buttons in this panel allow the operator to interact with the suction cups.

    Directional movement
    Changes the suction cup position.
    The distance of this movement can be selected in the text box below.

    NOTE

    The suction cups can also be moved by interacting with them in the work area.

    Suction cup rotation
    Rotates the suction cups about their axis.
    The value in the adjacent text box indicates how far the suction cup assembly rotates each time an arrow is clicked.

    Suction cup assembly diagram
    The suction cup assembly diagram allows the operator to select which vacuum zones are switched on or off during movement. If a zone is green, the machine activates the vacuum; if it is red, it does not.
