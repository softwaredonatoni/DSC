    DOC3.13.14 CHANNELS (OPTIONAL)

    This function allows the operator to add a channel in an area of the piece.
    The interface for this function resembles the following image:

    Parameters

    Distance from edge

    The operator must enter the required distance in mm from one of the piece edges.
    To position the channel against the edge, leave the value at 0; otherwise, enter the required distance.

    Cut width

    The operator must enter the channel machining width in mm.

    Cut depth

    The operator must enter the channel machining depth in mm.

    Start Distance

    The operator can enter the distance in mm from the channel reference cut.

    End Distance

    The operator can enter the distance in mm from the piece reference cut for the channel.

    Automatic drip grooves

    The operator can decide whether drip grooves are created automatically on the piece after the channel is created.

    Thickness

    Material thickness.

    NOTE

    Start distance, end distance and automatic drip grooves can be enabled or disabled using the buttons to the right of the value.
    When disabled, Parametrix ignores them; when enabled, the program calculates the offset.

    Executing the machining operation

    Channel with start and end distances disabled

    The channel is created 250mm from the selected cut and extends along the entire length of the piece, with a machining width of 100mm and a cut depth of 10mm.

    Channel with start distance enabled and end distance disabled

    The channel is created 250mm from the selected cut, with a machining width of 100mm and a cut depth of 10mm.

    As shown, with a start distance of 100mm, the channel starts 100m from the selected cut.

    Channel with start distance disabled and end distance enabled

    The channel is created 250mm from the selected cut, with a machining width of 100mm and a cut depth of 10mm.

    As shown, with an end distance of 100mm, the channel ends 100m from the selected cut.

    Channel with start and end distances enabled

    The channel is created 250mm from the selected cut, with a machining width of 100mm and a cut depth of 10mm.

    As shown, with a start distance of 100mm and an end distance of 100mm, the channel starts and ends 100m from the selected cut.

    Channel with automatic drip grooves enabled

    Drip grooves are automatically added to the piece (for drip grooves, see section 3.12.2).

    The drip grooves are positioned halfway between the channel and the nearest cut.

    Slab machining parameters

    The operator can change the channel parameters from the slab machining parameters panel.

    Machining with single passes

    This screen shows the machining parameters for single passes.

    Parameter description

    Z position at work start
    Sets the position at which the machine is maintained while it is not performing cuts.

    Excess material
    Thickness of material to be left above the required final section.

    Arc step
    Sets the arc discretisation step.

    Check probing
    Selects whether check probing is performed before the machining operation.

    Machining with step passes

    This screen shows the machining parameters for step passes.

    Parameter description

    Forward
    Indicates the cutting depth in the material when the machine cuts in the direction of saw-blade rotation.
