    DOC3.17 LOAD JOB

    This function loads a job previously saved in Parametrix.

    Piece list

    The list of state files that can be loaded is located in the left-hand section.

    Buttons

    Sort by date
    Sorts the files in the list by creation date. By default, they are sorted from newest to oldest. Pressing the button again sorts the files from oldest to newest. The operation can be repeated several times to change the sorting order.

    Sort by name
    Sorts the files in the list by name. Press the button to choose whether the files are sorted in ascending or descending order.

    USB memory
    Provides access to the USB memory device inserted in the PC, allowing folders to be browsed and files displayed.

    Working folder
    Quick access to the PC working folder.

    Browse folders
    This button can be used to browse all folders on the PC.

    Delete file
    Switches to “Delete file” mode. In this mode, an eraser icon appears to the left of the name of each file in the list.
    Selecting a file in this mode permanently deletes it.

    Search file
    Searches the files in the folder for those containing the text entered in the adjacent box.

    Preview

    This section displays a preview of the file selected from the list.

    Below the preview, the slab and tool parameters of the selected file and the machine are shown in the upper and lower sections respectively.

    WARNING!

    To fully open a job, the file parameters must be identical to the machine parameters.
    Otherwise, file parameters that differ from the machine parameters are highlighted in red.
    If the parameters are not the same, the job opens partially, with piece placement only. A message warns the user that changes to cuts cannot be applied.

    Other buttons

    Slab Matching
    Allows pieces to be positioned in the office installation of Parametrix using an image of the slab, then realigns the perimeter and pieces with the actual position of the same slab placed on the machine workbench.

    Load state
    Loads the state saved in the selected file.

    How to load a state

    From the main page, open the state loading panel.
    Then select the file corresponding to the job to be reproduced.

    After confirmation, the pieces are created and inserted into the work area with all operations that were applied to them.

    In the same way, a previously programmed job can be loaded with all operations already performed.

    This function is used to reload a previously saved job on the machine.

    Import DXF (Optional)

    This function loads the state of a job saved in a DXF file.

    Import headings from DXF layout

    It is now possible to import a slab into Parametrix with its heading cuts by drawing them on a dedicated layer of the DXF file.

    The name of the layer dedicated to heading cuts must be defined together with a Donatoni technician. Once configured, it can no longer be changed.

    Within this layer, each heading cut must be represented by a line.

    WARNING!

    When creating the DXF file, the following rules must be observed:
    the slab perimeter must be present;
    the slab perimeter must be rectangular;
    the perimeter sides must be horizontal or vertical and must not be rotated;
    each heading line must be parallel to one of the rectangle sides;
    there must be at most one heading line for each side;
    if multiple lines are drawn for the same side, Parametrix uses only the one closest to the edge.

    To import the file, open the DXF Layout Import page in Parametrix and select the desired file.

    Available settings

    On the file selection screen, certain settings can be changed using the buttons below the preview on the right side of the screen.

    Automatic mode
    If the selected DXF file does not contain the heading-cuts layer, Parametrix adds them automatically based on the perimeter settings of http://pannello.Se if the layer is present, priority is given to the heading cuts
    defined in the DXF file.

    Magnet mode
    Parametrix slightly moves the heading cuts to overlap the nearest cut, provided the distance between them is sufficiently small. This automatic correction can help optimize cut execution.

    Magnet distance
    Defines the maximum permitted distance between a heading cut and a piece cut for them to be overlapped using magnet mode. Heading-cut recognition is available both during standard import and during import with Slab Matching.
