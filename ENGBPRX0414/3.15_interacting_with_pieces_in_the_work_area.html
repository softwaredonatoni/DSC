    DOC3.15 INTERACTING WITH PIECES IN THE WORK AREA

    The operator can change the positioning of pieces on the worktable by interacting with them in the work area.

    Functions

    Multiple selection
    Selects or deselects several pieces at the same time.

    Select all
    Selects or deselects all pieces in the work area at the same time.

    Remove pieces
    Removes the selected pieces from the work area.

    Move pieces
    Opens a panel used to move the selected pieces by specified distances.

    Rotate pieces
    Opens a panel used to rotate the selected pieces through specified angles.

    Undo operation
    Undoes the last operation performed.

    Magnetise pieces
    Function used to join two cuts together.

    Miter cut
    Opens a panel used to incline a cut on a piece in the work area.

    Edit commercial piece
    Opens a panel used to change the dimensions of a commercial piece.

    Select pieces

    To select a piece, press inside it. The background of an unselected piece is light blue and the background of a selected piece is red.

    NOTE

    Normally, only one piece can be selected at a time.

    Multiple selection

    Pressing the button enables multiple-selection mode. In this mode, several pieces can be selected at the same time. To deselect a piece, press inside an already selected perimeter.

    Select all pieces

    This button selects or deselects all pieces in the work area at the same time.

    Remove pieces

    Pressing the button removes the selected pieces from the work area and returns them to the piece list so that they are available later.

    Move pieces

    To move the selected piece, press and hold inside the perimeter and drag it in the work area.
    Alternatively, use the directional-arrow movement panel.

    NOTE

    This function is applied to all selected pieces. Several pieces can therefore be moved at the same time.

    Buttons

    Directional arrows
    Buttons used to move the piece in different directions.
    The movement distance can be set using the text box on the left.

    Movement along side axis
    Performs movements parallel or orthogonal to the selected side of the piece.
    If several pieces are selected at the same time, they all move consistently relative to the selected side.

    Move pieces along the standard axes

    Move the piece 1500 mm to the left.

    Move pieces along the side axis

    Move the piece 1500 mm to the left relative to the axis of the piece side.
    The relevant button must be enabled to do this.

    Rotate pieces

    To rotate the selected pieces, press and hold outside the perimeter and drag them in the work area.
    Alternatively, use the panel for rotation through specified angles.

    NOTE

    This function is applied to all selected pieces. Several pieces can therefore be rotated at the same time.

    Buttons

    Clockwise rotation
    Rotates the piece clockwise by the angle entered in the text box below.

    Anticlockwise rotation
    Rotates the piece anticlockwise by the angle entered in the text box below.

    90_ rotation
    Rotates the piece 90_ clockwise.

    Apply rotation

    Rotate the piece 45 degrees clockwise.

    Undo operation

    This function undoes the last operation performed.
    For example, if the operator deletes a piece by mistake, pressing this button restores the state before the piece was deleted.

    NOTE

    There is no displayed history of changes, but pressing the button repeatedly undoes several operations.
