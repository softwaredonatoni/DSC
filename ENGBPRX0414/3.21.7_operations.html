    DOC3.21.7 OPERATIONS

    This function allows custom sorting and operations to be applied to the cuts.

    Available Operations

    Sort by working
    Sorts the cuts in the list according to working type.

    Macro
    Allows macros to be applied to cuts.

    Individual operations
    Allows standard operations to be applied to cuts.

    Move workings to start
    Moves all cuts associated with a working type to the top of the list.

    Move workings to end
    Moves all cuts associated with a working type to the bottom of the list.

    Sort by cuts
    Changes the cut order according to the position of the cuts in the work area.

    Working execution order

    Allows the operator to select the cut execution order according to the working type used.
    The list consists of the workings required to perform the cuts.
    Changing the working order also changes the order of the cuts in the list.

    NOTE

    The working types shown in this list refer to those associated with the cuts in the work area.
    Different items may therefore be shown.

    Bottom bar

    The items in the list can be sorted using movement buttons.

    Move
    Moves the selected operation to the previous or next position.

    Go to top/bottom
    Moves the selected operation to the top or bottom of the list.

    Macro

    Macros can be defined and applied. Each macro allows the operator to apply advanced cut-sorting options.
    Selecting a macro at the top of the panel allows the operator to view all operations contained in that macro.

    NOTE

    The macros available to the operator can be managed in the user parameters.
    Different items may therefore be shown.

    Buttons

    Apply operation
    Executes the selected operation.

    Individual operations

    Some operations can be applied by pressing the green arrow shown to the right of each item in the list.

    Available individual operations

    Move auto
    Applies the automatic slab handling function.

    All cuts out slab
    Allows the operator to extend all disk cuts to the slab edge at the same time.

    Order by tool
    Changes the cut order to group all cuts that can be performed with the same tool.

    Order by working type
    Changes the cut order to group all cuts that require the same working.

    Shorten cuts with intersections
    Allows intersecting cuts to be shortened to prevent damage to the inside of a piece.

    Available individual operations (Optional)

    The availability of some individual operations can be configured according to how the following options are set.

    Unload Piece

    When the Unload Piece function is enabled, some specific individual operations become available:

    Unload pieces

    Unload all pieces with repetition

    Unload wireframe with repetition

    Double disk

    When the Double disk function is enabled, some specific individual operations become available:

    Extend cut for double disk

    Verify for double disk

    Move workings to start

    The operator can change the working execution order and place one of the workings shown in this window first.

    NOTE

    The working types shown in this list refer to those associated with the cuts in the work area.
    Different items may therefore be shown.

    Move workings to end

    The operator can change the working execution order and place one of the workings shown in this window last.

    NOTE

    The working types shown in this list refer to those associated with the cuts in the work area.
    Different items may therefore be shown.

    Sort by cuts

    These operations change the order of the cuts in the list according to criteria based on their position in the work area.

    Cut-based sorting operations

    First bottom cuts
    Sorts the cuts by performing those at the bottom first and proceeding upwards.

    First top cuts
    Sorts the cuts by performing those at the top first and proceeding downwards.

    First right cuts
    Sorts the cuts by performing those on the right first and proceeding towards the left.

    First left cuts
    Sorts the cuts by performing those on the left first and proceeding towards the right.

    Horizontal cuts first 0_
    Sorts the cuts by performing horizontal cuts first.

    Vertical cuts first 90_
    Sorts the cuts by performing horizontal cuts first.

    First cuts with direction
    Sorts the cuts by giving priority to those with the highest rotation/translation value.

    External internal
    Sorts the cuts by performing the outermost cuts first and then progressively moving inwards.

    Internal external
    Sorts the cuts by performing the innermost cuts first and then progressively moving outwards.

    NOTE

    For these sorting operations, the starting point of the cuts is considered.
