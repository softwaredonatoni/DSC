    DOC3.13.17 INTERNAL CUT-OUT

    The ‘Internal Cut-out’ function adds a rectangular, circular or elliptical internal cut-out to the piece.
    The interface for this function resembles the following image:

    Machining types

    To use this machining operation, first select one of the two available modes by pressing the corresponding button:

    NOTE

    The ‘Rectangular’, 'Circular’ and 'Elliptical' modes are mutually exclusive: enabling one automatically disables the others.

    Rectangular cut-out
    Selecting this mode provides access to the specific parameters required to perform a rectangular cut-out.

    Circular cut-out
    Selecting this mode provides access to the specific parameters required to perform a circular cut-out.

    Elliptical cut-out
    Selecting this mode provides access to the specific parameters required to perform an elliptical cut-out.

    Rectangular Cut-out

    When this mode is enabled, the rectangular cut-out preview is displayed directly in the machining preview and highlighted in light green. The size and position of the cut-out depend on the default parameters, which can be changed by the user.

    Rectangular cut-out parameters

    In this mode, the following parameter panel is displayed:

    Offset O

    Distance between the cut-out edge and the reference side of the selected piece.

    Centre offset D

    Distance between the side of the piece parallel to the selected side and the centre of the cut-out.

    NOTE

    For curved cuts, a button can be used to select whether centre offset D is specified in mm or degrees.

    Height H

    Cut-out height.

    Width W

    Cut-out width.

    Executing a rectangular cut-out

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the required cut.

    Cut-out radius.

    Elliptical Cut-out

    When this mode is enabled, the elliptical cut-out preview is displayed directly in the machining preview and highlighted in light green. The size and position of the cut-out depend on the default parameters, which can be changed by the user.

    Elliptical cut-out parameters

    In this mode, the following parameter panel is displayed:

    Offset O

    Distance between the cut-out edge and the reference side of the selected piece.

    Centre offset D

    Distance between the side of the piece parallel to the selected side and the centre of the cut-out.

    NOTE

    For curved cuts, a button can be used to select whether centre offset D is specified in mm or degrees.

    A

    Value corresponding to the semi-major axis of the elliptical cut-out.

    B

    Value corresponding to the semi-minor axis of the elliptical cut-out.

    A red icon with an 'X' indicates that the machining operation cannot be applied to the required cut.

    Optional tap holes

    Pressing the button to the left of the OK button enables the tap-hole option. This option creates additional holes around the main central hole and displays additional parameters to configure.

    NOTE

    If the tap-hole diameter is equal to or less than the maximum hole radius, the tap holes are created as holes; if the tap-hole diameter is greater than the maximum hole radius, the tap holes are created as internal cut-outs.

    Tap-hole parameters

    In this mode, the following parameter panel is displayed:

    Number of holes

    Specifies how many holes are applied to the current machining operation on the selected cut.

    Hole diameter

    Specifies the diameter of the holes applied to the machining operation.

    Distance between holes

    Specifies the distance measured between the centres of two consecutive holes.

    Distance from cut-out

    Specifies the distance between the hole centre and the cut-out edge.

    Executing tap holes

    NOTE
    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the required cut.
