    DOC3.7 ADDING A PHOTO TO THE WORK AREA

    This function allows a photo to be added to the work area.
    If Parametrix is connected to a camera device, a photo of the slab on the workbench is taken.
    Otherwise, the user is asked to select a photo from the computer files.

    Take a photo

    Generally, this function allows a photo of the machine workbench to be taken using the built-in camera device.
    Pressing the button opens a window asking for the thickness of the slab that is about to be captured.

    The photo is taken and then the panel opens allowing the operator to define the slab perimeter.

    Choose a photo from computer files

    This mode allows computers not connected to a camera device, usually located in an office, to insert photos from files into the program.
    Pressing the button opens File Explorer so that a file can be selected for loading.

    The user is then taken to the slab perimeter selection panel.

    Perimeter selection

    After selecting or taking the photo, this screen appears and the operator must define a perimeter within which pieces can be positioned.

    Once the perimeter is confirmed, the slab photo is added to the Parametrix work area.
