    DOC3.13.11 EDGE PROFILE

    This function adds a chamfer, a lower chamfer (bird's beak), or both to the cuts of the selected piece.
    The interface for this function resembles the following image:

    Parameters

    To use this machining operation, first select one of the three available modes by pressing the corresponding button:

    NOTE

    The ‘Chamfer’, 'Lower Chamfer' and 'Chamfer and Lower Chamfer’ modes are mutually exclusive: enabling one automatically disables the others.

    Chamfer
    Selecting this function performs the cut on the upper corner of the piece side.

    Lower Chamfer (bird's beak)
    Selecting this function performs the cut on the lower corner of the piece side.

    Chamfer and Lower Chamfer
    Selecting this function performs the cut on both the upper and lower corners of the piece.

    The following parameters are common to both machining types:

    X position

    Distance along the X axis from the piece edge.

    Y position

    Distance along the Y axis from the piece edge.

    Inclination A

    Cut inclination angle expressed in degrees.

    Inclination B

    Cut inclination angle relative to the lower chamfer, expressed in degrees.

    NOTE

    This parameter is visible only in “Chamfer and Lower Chamfer” mode.

    Thickness

    Displays the slab thickness currently set in Parametrix to help the user apply the machining operation.

    NOTE

    This parameter cannot be changed directly from the Edge Profile section.

    Perimeter

    Enabling this parameter applies the machining operation to the entire perimeter of the piece.

    NOTE

    Square check boxes, initially disabled, are located next to the first three geometric parameters. One must be enabled to specify which parameter is to remain constant; when a second value is provided, the third is calculated automatically. A check box cannot be enabled if the corresponding parameter value is zero, in order to prevent geometrically inconsistent or invalid configurations.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the required cut.

    The edge profile operation can be performed only on straight cuts.

    Whenever an edge profile is successfully added to the material, the preview is updated and the operation is automatically added to the 'Added Operations' section on the left.
