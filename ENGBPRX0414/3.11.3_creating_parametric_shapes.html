    DOC3.11.3 CREATING PARAMETRIC SHAPES

    In this section, pieces can be constructed using parametric shapes with predefined geometry. To draw a shape, simply enter the values that define it.

    Parametric shape categories

    Referring to the image above, the main categories of parametric shapes are shown in the left-hand column.

    Rectangular shapes
    Such as rectangles and squares with and without internal breaks.

    Quadrilaterals
    Such as scalene trapezoids, also intended for kitchen countertops.

    Triangular shapes
    Such as regular and curved triangles.

    Kitchen countertops
    Various kitchen countertop shapes with internal cutouts.

    Sector-type shapes
    Such as circular sectors and partial annuli.

    Elliptical shapes
    Such as circles and ellipses.

    Polygonal shapes
    Such as regular and curved hexagons.

    Bathrooms
    Various curved shapes for bathrooms.

    Stone or memorial shapes
    Such as pentagons and Latin crosses.

    Tables
    Shapes such as rounded rectangles and irregular octagons.

    Special shapes
    Such as stars and arcs.

    Preview and parameterized values

    Depending on the selected category, the next column to the right displays the available shape selection.
    An image in the center of the screen provides detailed guidance on the dimensions to be entered. To the right of the reference image, a preview of the shape being drawn is displayed and updates in real time whenever the values defining the shape are changed.
    As in the previous paragraphs, once the dimensions have been entered, the mark (or label) displayed on the piece when it is inserted in the work area can be entered, the number of copies of the piece can be set, and single import can be selected.

    Additional settings

    Additional parameters

    The following data are required to create rectangular pieces:

    Number of pieces
    Number of copies of the piece having the same dimensions.

    Mark
    Label added to the piece to identify it. This parameter is optional because it is not essential for creating the piece.

    Additional buttons

    Single import
    If this button is enabled, multiple distinct pieces can be created as single quantities instead of one piece with multiple copies.

    Mirror
    When enabled, these two buttons flip the piece vertically and horizontally respectively.

    Reset
    This button restores the shape being edited to its original state.

    Out-of-square piece bar

    Some pieces can be created using non-square angles (i.e. angles other than 90 degrees).
    To use this option, a bar located above the central image contains all available modification versions for that image. Editable parameters are shown in green.

    Mirror

    Using the two dedicated buttons, the result displayed on screen can be flipped along the vertical or horizontal axis respectively. This function adapts the display to operating requirements or the type of machining in progress.
