    DOC3.1.3.1 CREATING CUTS FROM DXF DRAWINGS

    The machine can perform cuts, milling operations and holes from drawings created with CAD software and saved in “.dxf“ format, automatically recognising certain machining operations to simplify and speed up the work of the machine operator.

    NOTE

    For Parametrix to interpret this information, certain conventions must be followed when creating the drawing:
    All drawn pieces must be closed and converted into polylines forming a polygon.
    To insert the piece mark for identification, it must be placed inside the polygon.

    Parametrix settings for recognising imported layers

    To open the customisation settings window for DXF file import, press the User Parameters button on the Parametrix top bar.
    Then go to the section for managing Layer names.

    Miter Cut mode

    Certain conventions must be followed to insert a miter cut automatically:

    • Miter cuts can only be inserted on piece sides; if the miter cut does not apply to the entire section, the side can be divided into several parts.

    • A miter cut can be applied to external arcs (e.g. a circular table or curved backsplashes, but only on the external cut).

    • For internal arcs (e.g. curved backsplashes), the cut is performed in passes; the saw blade is tilted automatically to avoid collisions with the material.

    For users of CAD systems, the procedure requires creating a Layer with the following properties:

    Layer Name

    Inclinato _ (followed by the number identifying the required inclination angle).

    NOTE

    The inclination is expressed in degrees.

    Example

    Inclinato45 or Inclinato-45

    When a negative value is entered, the inclination refers to a diverging cut; when the value is positive, the cut converges towards the inside of the polygon.

    Downstand mode

    The downstand function is a machining operation used to obtain a rectangular piece with the same length as the line set as the reference side.

    To insert the cuts automatically when creating a downstand, create a Layer named “Alzata” and then enter the height.

    Layer Name

    Alzata _ (followed by the downstand height).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Alzata100

    In Parametrix, this automatic function creates a new piece whose width is equal to the length of the line identifying the side of the required downstand. The two sides to be bonded together are cut at the same inclination, ready for a mitred-joint finish.
    The inclination associated with these sides can be set using the adjacent parameter.

    Degrees

    Sets the inclination used when importing the inclined sides of the machining operation.

    Backsplash mode

    The backsplash/downstand function is a machining operation used to obtain a rectangular piece with the same length as the line set as the reference side.

    Similarly, to insert the cuts automatically when creating a backsplash, create a Layer named “Rivestimento” and then enter the height.

    Layer Name

    Rivestimento _ (followed by the backsplash height).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Rivestimento150

    In Parametrix, this automatic function creates a new piece whose width is equal to the length of the line identifying the side of the required backsplash, without a miter cut and ready for a square-corner finish with edge gripping.

    Offset mode

    The offset function is very useful when extra material must be left beyond the finished piece dimensions. By drawing lines on the required sides, the functions associated with those sides are automatically shifted in the correct direction.

    To insert the required extra material automatically, create a Layer named “Offset” and insert all the lines corresponding to the sides to which the setting must be applied automatically.

    Layer Name

    Offset _ (followed by the number identifying the offset value).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Offset3

    Lower Cut mode

    The lower cut function is only available on machines fitted with the optional mechanical equipment that allows a cut to be made below the visible surface of the slab.

    To insert a lower cut automatically, create a Layer named “Sotto” and insert a line representing the cut.

    Layer Name

    below

    Example

    below

    NOTE

    The length of the resulting cut also depends on the saw blade diameter and material thickness set in Parametrix.

    Drip System mode

    The drip system function inserts a cut whose width is greater than the saw blade thickness and whose depth is less than the material thickness.

    To insert a drip groove automatically, create a Layer named “Gocciola” and insert a line or arc representing the centre of its width.

    Layer Name

    Gocciola _ (followed by the number identifying the drip groove width).

    NOTE

    The width is expressed in millimetres.

    Example

    Gocciola10

    The drip groove depth is then determined by the dedicated parameter.

    Pocketing

    Depth of the cut associated with the drip groove. This value is ignored if the user sets a value in the DXF file.

    The cut depth can be managed automatically using the dedicated Parametrix parameter, or the user can set a value by entering the character “&” followed by the required depth.

    Layer Name

    Gocciola _ (drip groove width) _ & _ (drip groove depth).

    NOTE

    The depth is expressed in millimetres.

    Example

    Gocciola10&5

    NOTE

    The length of the resulting cut also depends on the saw blade diameter and material thickness set in Parametrix.

    NOTE

    For curved drip grooves, a single cut is made with the saw blade outside the arc.
    Any parameters specified in the Layer name are ignored.

    Milling mode

    Certain conventions must be followed to insert an automatic milling operation.

    If a milling geometry is created for one or more sides of the external polygon, the milling cutter performs the machining operation outside the drawn perimeter. This also applies to a single perimeter side. If the entire perimeter is to be cut with the milling cutter, any saw blade cuts are removed.

    The cut depth can be defined by creating a dedicated Layer.

    Layer Name

    Fresatura _ (followed by the number identifying the milling depth).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Fresatura10

    If no depth value is specified in the “Fresatura“ Layer name, the thickness of the current machining operation is used.

    Another available function is the insertion of a polyline (open or closed, such as a circle or a single path made up of a linear polyline) to mill a shape within the larger perimeter.

    Recess / Flush-Mount mode

    The recess/flush-mount function is a machining operation used to recess a perimeter, usually to install appliances or sinks.

    To insert the required recess automatically, create a Layer named “Ribasso”.

    Layer Name

    Ribasso _ (followed by the number identifying the recess width).

    NOTE

    The width is expressed in millimetres.

    Example

    Ribasso20

    The recess depth is then determined by the dedicated parameter.

    Pocketing

    Recess depth. This value is ignored if the user sets a value in the DXF file.

    The recess depth can be managed automatically using the dedicated Parametrix parameter, or the user can set a value by entering the character “&” followed by the required depth.

    Layer Name

    Ribasso _ (recess width) _ & _ (recess depth).

    NOTE

    The depth is expressed in millimetres.

    Example

    Ribasso20&3

    NOTE

    The fillet radius between the perimeter sides cannot be modified by the user; it is determined by the milling cutter radius.

    The recess can be machined along a closed path that does not overlap the piece sides; in this case, the area inside the drawn perimeter is milled.

    Drilling mode

    The drilling function allows Parametrix to add drilling operations to pieces.

    To insert a drilling operation automatically, create a Layer named “Foratura” and draw a circle where the hole is to be made.

    Layer Name

    Foratura _ (followed by the number identifying the hole depth).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Foratura5

    If the depth is not specified, the hole is applied using the thickness of the material currently used by Parametrix.

    In basic mode, the circle radius corresponds to the radius of the tool currently set in Parametrix.

    Additional Cut mode

    The additional cut function allows Parametrix to add a cut.

    To insert an additional cut automatically, create a Layer named “Aggiunto” and draw a new line over the line representing the side on which the additional cut is to be created.

    Layer Name

    Aggiunto _ (followed by the number identifying the distance at which the cut is to be added).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Aggiunto50

    The cut is added inside the piece (where material is present) or outside the piece (where no material is present), according to the sign of the distance:

    • If the distance is positive, the cut is added outside the piece.

    • If the distance is negative, the cut is added inside the piece.

    When an additional cut is applied to internal cuts, for example a cut-out, the cut is added inside the piece, where no material is present.

    Anchoring Hole mode

    The anchoring hole function allows Parametrix to add anchoring-hole machining operations to pieces.

    To insert an anchoring-hole machining operation automatically, create a Layer named “Keil” and draw a circle where the anchoring hole is to be made.

    Layer Name

    Keil _ (followed by the number identifying the anchoring-hole depth).

    NOTE

    The measurement is expressed in millimetres.

    Example

    Keil5

    In basic mode, the circle radius corresponds to the radius of the tool currently set in Parametrix.

    Chamfer mode

    The chamfer function allows Parametrix to add chamfer machining operations to pieces.

    To insert a chamfer machining operation automatically, create a Layer named “Smusso” and draw a new line over the line representing the side on which the machining operation is to be created.

    Layer Name

    Smusso _ (distance along the X axis) _ & _ (distance along the Y axis) _ & _ (inclination angle).

    NOTE

    The measurements are expressed in:
    X: millimetres
    Y: millimetres
    A: degrees

    Example

    Smusso10&10&45

    If the three values are not geometrically compatible, the machining operation is not applied.

    Lower Chamfer mode

    The lower chamfer function allows Parametrix to add lower-chamfer machining operations to pieces.

    To insert a lower-chamfer machining operation automatically, create a Layer named “Becco” and draw a new line over the line representing the side on which the machining operation is to be created.

    Layer Name

    Becco _ (distance along the X axis) _ & _ (distance along the Y axis) _ & _ (inclination angle).

    NOTE

    The measurements are expressed in:
    X: millimetres
    Y: millimetres
    A: degrees

    Example

    Becco10&10&45

    If the three values are not geometrically compatible, the machining operation is not applied.

    Deactivate mode

    The deactivate function allows Parametrix to deactivate cuts on pieces.

    To insert a deactivate function automatically, create a Layer named “Disattiva” and draw a new line over the line representing the side to be deactivated.

    Layer Name

    Deactivate

    Example

    Deactivate

    Remove mode

    The remove function allows Parametrix to remove cuts from pieces.

    To insert a remove operation automatically, create a Layer named “Rimuovi” and draw a new line over the line representing the side to be removed.

    Layer Name

    Remove

    Example

    Remove

    Hole mode

    The drilling function allows Parametrix to recognise every circle within the piece area whose radius is smaller than the “Maximum core drill radius” parameter.

    Holes can be inserted freely in all Layers (except those identified as neutral).

    An additional core-drill option removes an island of material left attached after the saw blade cuts have been made. For Parametrix to apply this option, one or more circles must be drawn so that they intersect the sides of the island cut with the saw blade. The “Automatic holes distance” parameter is then used to position a series of holes calculated automatically according to the material remaining to be cut after the saw blade operation.

    Managing neutral Layers

    To retain parts of a drawing in the DXF file that must not be treated as cuts or other functions managed by Parametrix, they can be assigned to Layers recognised as neutral.

    Create the Layers using the names assigned in the Neutral Layers (1,2,3) fields on the “Layer Names” page of the Parametrix user parameters. The “*” character means that all imported Layers with the same text before and after the “*” symbol are ignored during import.
