    DOC3.13.15 FILLET

    This function allows the operator to add a fillet to a vertex or side of the piece.
    The interface for this function resembles the following image:

    Parameters

    NOTE

    The ‘Single vertex’, ‘Side’ and ‘Polygon vertices’ modes are mutually exclusive: enabling one automatically disables the others.

    Single vertex
    Applies a single fillet to the selected vertex.

    Side
    A fillet is added to the selected side.

    Polygon vertices
    In this mode, fillets are added to all vertices of the selected polygon.

    Parameters for ‘Single vertex’ and ‘Polygon vertices’

    Radius R
    Fillet radius.

    ‘Side’ parameters

    Offset 0
    Measures how much to widen the piece on the selected side, i.e. the side on which the fillet is performed.
    The movement is inward if the value is negative, or outward if it is positive.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the desired cut.

    The application of fillets in the different modes is shown below. A machining preview allows the operator to view the expected result. The machining operation is actually applied only after confirmation using the green 'OK' button.

    WARNING

    !
    Each time a fillet is applied, all settings previously applied to the piece cuts are lost.

    Executing fillet on a single vertex

    When this mode is selected, the machining operation can be performed on individual vertices of the piece.
    For the machining operation to be applied correctly, the radius parameter cannot be set to a negative value.

    In the following example image, three fillets with a radius of 100,0 mm have been applied.

    The cut list on the left shows several consequences each time a fillet is applied to a vertex:

    • If other machining operations are present, they are removed.

    • A curve is inserted in the list: the new fillet.

    • The lengths of the sides adjacent to the selected vertex are reduced by the amount specified by the Radius parameter.

    Executing fillet on a side

    When this mode is selected, the machining operation can be performed on the sides of the piece. In this mode, there are two main cases for fillets depending on the value of the offset parameter: a positive value and a negative value.

    In the following example image, a fillet has been applied to the lower cut of the selected piece, with the offset parameter set to 100,0 mm.

    The following image shows the opposite example: a fillet has been applied to the lower cut of the selected piece with the offset parameter set to a negative value of -100mm.

    The cut list on the left shows several consequences each time a fillet is applied to a side:

    • If other machining operations are present, they are removed.

    • The selected straight-line cut is replaced by a curved cut.

      • With a positive offset parameter value, the inserted fillet consists of a curve recessed relative to the selected polygon, whether internal or external.

      • By contrast, with a negative offset value, the applied fillet consists of a curve protruding relative to the selected polygon.

    Executing fillet on the vertices of the selected polygon

    This mode applies as many fillets as there are vertices in the selected polygon.
    For the machining operation to succeed, a negative radius value cannot be entered.
    The following image shows the machining operation on all vertices of the piece:

    As with single-vertex mode, using this mode has several consequences in the cut list on the left:

    • If other machining operations are present, they are removed.

    • The selected straight-line cut is replaced by a curved cut.

      • With a positive offset parameter value, the inserted fillet consists of a curve recessed relative to the selected polygon, whether internal or external.

      • By contrast, with a negative offset value, the applied fillet consists of a curve protruding relative to the selected polygon.
