    When the “Slab Parameters” panel is opened, the machining parameters screen is displayed, allowing the operator to manage machining data.
    Machining data can be set and edited using the parameters panel.

    Machining-type selection

    Selecting the machining type controls the contents of the parameter-management window.

    For each machining type, its preview shows the selected increment mode, the forward cutting speed (plunge/entry speed for Hole machining) and the tool diameter.

    Pass type

    Full-depth pass
    A Full-depth Pass performs the entire machining operation in a single pass. The tool therefore enters the full thickness of the material immediately and performs the operation.

    Step / spiral pass
    These passes do not enter the full material thickness immediately, but do so gradually.
    The machining operation is therefore repeated at different heights until the worktable position (end of the material) or the selected height is reached.

    Machining types

    Linear

    Full-depth pass

    Step pass

    Increment parameter description

    Forward
    Indicates the cutting depth in the material when the machine cuts in the direction of saw-blade rotation.

    Reverse
    Indicates the cutting depth in the material when cutting in the direction opposite to the tool direction.

    Final
    Indicates the cutting depth of the final tool pass through the material. This cut is always performed in the direction opposite to saw-blade movement.

    Speed parameter description

    Plunge
    Determines the speed during tool penetration into the material.
    This value is expressed in millimetres per minute.

    Forward
    Indicates the required speed for the forward cutting phase.
    This value is expressed in millimetres per minute.

    Reverse
    Indicates the required speed for the return cutting phase.
    This value is expressed in millimetres per minute.

    Final
    Indicates the speed that the machine must maintain during the final cutting pass.
    This value is expressed in millimetres per minute.

    Accelerate cuts
    If this parameter is set to a value greater than zero, the saw-blade rotation speed is increased progressively from the start of the cut up to the specified distance.
    The remainder of the cut is then performed at full speed.

    Decelerate cuts
    If this parameter is set to a value greater than zero, the saw-blade rotation speed is reduced progressively from the set distance before the end of the cut until the cut is completed.

    NOTE

    For increments and speeds, the “Reverse” and “Final” parameters may both be present, neither may be present, or only one may be present.
    These options are normally selected when the program is installed according to the customer's machining requirements.
    To change these options in order to use a different machining method, contact Donatoni Support.

    Step pass

    Executing machining with a step pass:

    • The machine approaches the material at maximum speed until it reaches the distance from the material specified in the APPROACH parameter.

    • The number of steps is calculated as:

      • Material thickness divided by step thickness

        • rounded up if necessary

    • The machine starts moving at machining speed.

      • If the ENTRY STEP parameter is set (non-zero and greater than zero), the machine operates at the speed set in the second ENTRY field until it reaches the distance set in the ENTRY STEP field.

    • The machine performs the steps calculated in the second point at the Step speed.

    • After each step (including the first), the machine returns to the material position at maximum speed, then moves at maximum speed to a short distance before the start of the next step.

    • If the EXIT STEP parameter is set (non-zero and greater than zero), the machine operates at the speed defined in the second STEP field until it reaches the distance defined in the first EXIT field.

      • The remainder of the step is performed at the EXIT speed.

    Description of Hole parameters with step pass

    Approach position
    The machine approaches the material at maximum speed until it reaches the distance from the material set in this parameter. From this point, the core drill starts moving at machining speed.

    Step
    These parameters define the thickness of the machining steps and the machining speed. The number of machining steps is calculated from the machining-step thickness and the material thickness.
    For example, if the user sets this parameter to 3 mm for material with a thickness of 20 mm, the hole is performed in 7 steps.

    Entry
    If this value is set to a value other than 0, an interval is defined from the first step and, where applicable, for the following steps, during which the machine operates at a speed different from that defined in “STEP”.

    Exit
    If this value is set to a value other than 0, an interval is defined from the final step and, where applicable, for the preceding steps, during which the machine operates at a speed different from that defined in “STEP”.

    Pause after
    If this parameter is enabled, the machine pauses after each hole is completed so that the operator can check for material residue trapped inside the tool.
    The operator must press the START button again to resume the program.

    Change of cutting parameters

    The parameters described previously for the saw blade, milling cutter and core drill can be changed if the user is authorised to use them.

    To select the tool whose parameters are to be changed, press the “Select tool” button on the right-hand side of the panel.

    Change cutting parameters
    Opens the screen for changing the cutting parameters of the selected tool.

    Pressing this button displays a window containing a saved parameter configuration for each available material. The results also depend on the selected machining type.
