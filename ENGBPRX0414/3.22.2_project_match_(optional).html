    DOC3.22.2 PROJECT MATCH (OPTIONAL)

    Project Match is designed for planning large-scale projects.
    Allows multiple slabs to be managed at the same time so that all workings required for the project can be programmed with an overall view.

    Control panel

    Pressing the button on the lower bar opens a panel used to navigate within the function.

    To access Project Match, these buttons are displayed.

    New Project
    Creates a new project.

    Load project
    Loads an existing project.

    View preview
    Opens a screen showing a preview of the entire project.

    Within a project, however, the panel contains different buttons.

    Save work area
    Saves the changes made to the selected work area within the project.

    Save all work areas
    Saves the changes made to all work areas in the project at the same time.

    Save and close project
    Allows the Book Match project to be closed, with the option to save or discard the changes.

    NOTE

    The panel can be moved by dragging it on the screen.

    New Project

    Pressing the button opens a window for creating a multi-slab Book Match project.

    Name

    Name used to save the project.

    Rows

    Allows the number of project rows to be selected.

    Columns

    Allows the number of project columns to be selected.

    Slabs

    Total number of slabs the project can contain.

    Work area dimensions
    Allows the width and height of the work areas making up the project to be selected.

    Load a project

    This screen shows the saved projects that can be opened.

    Close a project

    A window opens for closing the project.

    Use the following button to change the closing mode:

    Closing mode
    Allows selection of whether to close the project and save the changes or close it without saving them.

    Project

    A project is structured in rows and columns that can contain slabs.
    On this screen, slabs can be inserted into the project, their perimeters can be defined and pieces can be positioned.
    The operator can move pieces between slabs as desired.

    Work zones

    The work zones are represented by the project cells.
    Each zone allows the working of one slab to be managed by defining a perimeter and inserting pieces within it.

    Some information is shown in the upper-left corner of each work zone.

    Slab

    Slab dimensions (width x height x thickness).

    Pieces

    Number of pieces positioned within the perimeter.

    Slabs Area

    Slab perimeter area.

    Piece Area

    Area of the pieces positioned within the perimeter.

    Percentage

    Percentage of the perimeter area occupied by the pieces.

    Cuts

    Total length of the cuts to be performed on the slab.

    Minutes

    Estimated time, in minutes, required to execute the cutting program on the slab.

    Project parameters

    The “Slabs” section is shown in the user parameters panel and can be used to change some properties of the currently open project.

    Rows

    The operator can change the number of rows in the current project.

    Columns

    The operator can change the number of columns in the current project.

    Total

    Total number of zones making up the current project.

    Slabs

    Number of slabs inserted in the current project.

    Pieces

    Number of pieces inserted in the current project.

    Keyboard shortcuts
    Opens the Project Match keyboard shortcuts screen.

    Keyboard shortcuts

    Keyboard commands are available for Project Match to make routine actions easier and simplify office work.

    Zoom on project

    Expands the view to the entire project.

    Zoom on zone

    Narrows the view to the selected work zone.

    Mode pan

    Allows the view to be moved by interacting with the screen.

    Navigate zones

    Allows the selected zone to be changed using the keys.

    Move piece

    Moves the selected piece in the four directions.

    Rotate piece

    Rotates the selected piece counterclockwise and clockwise, respectively.

    Rotate piece _90

    Rotates the piece 90 degrees clockwise.

    Select all

    If a work zone is selected, this command selects all pieces within it.
    Otherwise, it selects all pieces in the project.

    Enable multiple selection

    Enables multiple selection of pieces/work zones.

    Undo

    Undoes the last operation performed.

    Copy slab

    Copies the slab in the selected work zone.

    Cut slab

    Cuts the slab in the selected work zone.

    Paste slab

    Pastes the slab in the selected work zone.

    Unselect

    Deselects all pieces/work zones.

    Confirm perimeter\photo

    Use to confirm the perimeter/photo

    Select next

    Selects the next piece within the selected work zone.

    Magnet on/off

    Enables/disables the piece magnet.

    Quick commands

    The quick commands window can be accessed using the right mouse button.
    The available functions change depending on whether the click is inside a work zone or outside all zones.

    Project commands

    Save workings
    Saves the changes made to all work zones.

    Report
    Saves a PDF file containing a project report.

    Nesting
    Performs nesting of the pieces on all slabs in the project.

    Work zone commands

    Lock/Unlock
    If a work zone is locked, the pieces within it cannot be moved and no new pieces can be inserted.
    Its perimeter cannot be changed and other photos cannot be selected.
    It must be unlocked to make these operations available again.

    Cut it
    Takes the user to the management and cut-optimisation screen for the selected slab in order to create the ISO program.

    Save
    Saves the changes applied to the individual work zone.

    Report
    Saves a PDF file containing a report for the selected work zone.

    Import File
    Loads a saved slab-state file into the project.

    Nesting
    Performs nesting of the pieces within the selected work zone.

    Nesting

    When Nesting is enabled for the entire project, two modes become available.

    Insert pieces into current slabs

    Inserts pieces on slabs already present in the project in order to optimise the available space

    Insert slabs and pieces until all pieces are used

    Slabs are created and Nesting is applied until all pieces in the list have been used.
    The slab dimensions are the same as those of the first slab that was defined.
    This is used to indicate how many slabs may be required to complete the project when slabs of the same shape are to be cut.

    To use Nesting until all pieces have been inserted, a perimeter must be created to give the program the dimensions of the slabs that will be used.
    Slabs of the same size will be created until all pieces in the list have been inserted using Nesting.

    Report

    Saves a PDF report in the dedicated folder for the current project/work zone.

    Preview

    This window provides an overall real-time view of the project.
    Pieces can be inserted into the selected work zone by pressing inside them in the preview.
    In addition, by dragging the background of a piece, the operator can change the position of the piece on the workbench.

    Buttons

    The following buttons are located on the left.

    Move pieces
    Allows the pieces making up the preview to be moved.
    Displays the buttons on the lower bar of the window.

    Pan view
    Used to move the preview view with all pieces.

    The following buttons are located on the right.

    Open render
    Opens the folder where the project renders are saved.

    Customise preview
    Opens a panel used to customise the colours of the entities in the preview.

    Restore piece positions
    Restores moved pieces to their original position.

    Restore project configuration
    Restores the project configuration.

    Save render
    Opens a panel used to save the project render.

    Project planning

    Create a new project

    The operator creates a new project by specifying its name, the number of rows and columns that make it up—remembering that each cell corresponds to one slab—and the cell dimensions. Once confirmed, the screen will appear as follows:

    Add slabs

    Then insert the slabs into the work zones. To do this, select a zone, load a photo from file and select the perimeter.

    Import pieces

    At this point, import the pieces to be cut. Both DXF files and standard pieces can be loaded. There is no limit to the number of files that can be loaded.

    Open preview

    When pieces are present in the list, the project preview window can be opened.
    It shows all pieces that have been imported.

    Insert pieces into slabs

    To insert pieces into the slabs, use the standard method from the pieces list or select inside the piece areas shown in the preview.
    They will then be inserted on the slab in the selected work zone.
    Dragging one of the pieces from the preview also moves the piece on the slab, so that the best area of the slab can be selected to match the veining between the various pieces. The reverse can also be done: drag the piece on the slab and use the preview to check whether the veining matches according to where it is moved.
