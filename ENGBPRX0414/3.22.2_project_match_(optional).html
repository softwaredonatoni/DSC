    DOC3.22.2 PROJECT MATCH (OPTIONAL)

    Project Match is designed for planning large-scale projects.
    It allows multiple slabs to be managed simultaneously so that all machining operations required for the project can be planned with an overall view.

    Control panel

    Pressing the button on the bottom bar opens a panel used to navigate the function.

    The following buttons are displayed when accessing Project Match.

    New project
    Creates a new project.

    Load project
    Loads an existing project.

    View preview
    Opens a screen displaying a preview of the entire project.

    Within a project, the panel contains different buttons.

    Save work area
    Saves the changes made to the selected work area in the project.

    Save all work areas
    Simultaneously saves the changes made to all work areas in the project.

    Save and close project
    Exits the Book Match project, allowing the operator to choose whether to save the changes.

    NOTE

    The panel can be moved by dragging it on the screen.

    New Project

    Pressing the button opens a window for creating a multi-slab Book Match project.

    Name

    Name used to save the project.

    Rows

    Sets the number of project rows.

    Columns

    Sets the number of project columns.

    Slabs

    Total number of slabs that the project can contain.

    Work area dimensions
    Sets the width and height of the work areas making up the project.

    Loading a project

    This screen displays saved projects that can be opened.

    Closing a project

    A window opens in which the project can be closed.

    Use the following button to change the closing mode:

    Closing mode
    Selects whether the project is closed with or without saving the changes.

    Project

    A project is organised into rows and columns that can contain slabs.
    On this screen, slabs can be inserted into the project, their perimeters defined and pieces positioned.
    The operator can move pieces freely between slabs.

    Work areas

    The work areas are represented by the project cells.
    Each area manages the machining of one slab by defining a perimeter and placing pieces inside it.

    Information is displayed in the top-left corner of each work area.

    Slab

    Slab dimensions (width x height x thickness).

    Pieces

    Number of pieces positioned within the perimeter.

    Slab area

    Area of the slab perimeter.

    Piece area

    Area of the pieces positioned within the perimeter.

    Percentage

    Percentage of the perimeter area occupied by pieces.

    Cuts

    Total length of the cuts to be performed on the slab.

    Minutes

    Estimated time, in minutes, required to execute the cutting program on the slab.

    Project parameters

    The “Slabs“ section in the user parameters panel can be used to change certain properties of the currently open project.

    Rows

    The operator can change the number of rows in the current project.

    Columns

    The operator can change the number of columns in the current project.

    Total

    Total number of areas making up the current project.

    Slabs

    Number of slabs inserted in the current project.

    Pieces

    Number of pieces inserted in the current project.

    Keyboard shortcuts
    Opens the Project Match keyboard shortcuts screen.

    Keyboard shortcuts

    Project Match provides keyboard commands for easily performing routine actions, simplifying office work.

    Zoom to project

    Expands the view to the entire project.

    Zoom to area

    Narrows the view to the selected work area.

    Pan mode

    Allows the view to be moved by interacting with the screen.

    Navigate between areas

    Changes the selected area using the keys.

    Move piece

    Moves the selected piece in the four directions.

    Rotate piece

    Rotates the selected piece anticlockwise and clockwise, respectively.

    Rotate piece _90

    Rotates the piece 90 degrees clockwise.

    Select all

    If a work area is selected, this command selects all pieces within it.
    Otherwise, it selects all pieces in the project.

    Enable multiple selection

    Enables multiple selection of pieces/work areas.

    Undo

    Undoes the last operation performed.

    Copy slab

    Copies the slab in the selected work area.

    Cut slab

    Cuts the slab in the selected work area.

    Paste slab

    Pastes the slab into the selected work area.

    Deselect

    Deselects all pieces/work areas.

    Confirm perimeter or photo

    Use to confirm the perimeter/photo.

    Next selection

    Selects the next piece in the selected work area.

    Magnet on/off

    Enables/disables magnetic alignment of pieces.

    Quick commands

    Right-clicking opens the quick command window.
    The available functions change depending on whether the click is inside a work area or outside all areas.

    Project commands

    Save jobs
    Saves the changes made to all work areas.

    Report
    Saves a PDF file containing a project report.

    Nesting
    Performs nesting of pieces on all slabs in the project.

    Work area commands

    Lock/Unlock
    If a work area is locked, the pieces it contains cannot be moved and new pieces cannot be inserted.
    Its perimeter also cannot be changed and other photos cannot be selected.
    Unlock it to re-enable all operations.

    Cut
    Opens the cut management and optimisation screen for the selected slab, where the ISO program can be created.

    Save
    Saves the changes made to the individual work area.

    Report
    Saves a PDF file containing a report for the selected work area.

    Import file
    Loads a saved slab-status file into the project.

    Nesting
    Performs nesting of pieces within the selected work area.

    Nesting

    When Nesting is enabled for the entire project, two modes are available.

    Place pieces on current slabs

    Places the pieces on the slabs already present in the project to optimise the available space.

    Add slabs and pieces until complete

    Creates slabs and applies Nesting until all pieces in the list have been used.
    The slab dimensions are the same as the first defined slab.
    This mode provides an indication of how many slabs may be required to complete the project when slabs of the same shape are to be cut.

    To use Nesting until all pieces have been placed, create a perimeter to provide the program with the dimensions of the slabs to be used.
    Slabs of the same size are created until all pieces in the list have been inserted by Nesting.

    Report

    Saves a PDF report in the folder dedicated to the current project/work area.

    Preview

    This window provides an overall real-time view of the project.
    Pieces can be inserted into the selected work area by clicking them in the preview.
    Furthermore, by dragging the background of a piece, the operator can change the position of the piece on the worktable.

    Buttons

    The following buttons are located on the left.

    Move pieces
    Moves the pieces in the preview.
    The buttons in the bottom bar of the window are displayed.

    Pan view
    Moves the preview view with all pieces.

    The following buttons are located on the right.

    Open render
    Opens the folder where the project renders are saved.

    Customise preview
    Opens a panel used to customise the colours of the entities in the preview.

    Reset piece positions
    Restores moved pieces to their original positions.

    Reset project configuration
    Restores the project configuration.

    Save render
    Opens a panel used to save the project render.

    Project planning

    Create a new project

    The operator creates a new project by specifying its name, the number of rows and columns it contains, bearing in mind that each cell corresponds to a slab, and the cell dimensions. Once confirmed, the following screen is displayed:

    Add the slabs

    Then insert the slabs into the work areas. To do this, select an area, load a photo from a file, and select the perimeter.

    Import the pieces

    At this point, import the pieces to be cut. Both DXF files and standard pieces can be loaded. There is no limit to the number of files that can be loaded.

    Open the preview

    When the list contains pieces, the project preview window can be opened.
    It displays all the pieces that have been imported.

    Insert the pieces into the slabs

    To insert the pieces into the slabs, use the standard method through the piece list, or select the pieces within the piece areas shown in the preview.
    They will then be inserted onto the slab in the selected work area.
    By dragging a piece in the preview, the piece will also move on the slab, allowing the best area of the slab to be selected so that the veins match across the various pieces. The reverse can also be done: drag the piece on the slab and use the preview to check whether the veins match according to its position.
