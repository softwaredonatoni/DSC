    DOC3.24 TOOL REDRESSING CYCLE (OPTIONAL)

    Starting the tool redressing cycle performs tool redressing.

    Button

    Tool redressing cycle
    Provides access to the Tool Redressing panel.

    Tool redressing from parameters page

    Opening the Parametrix parameters section displays the following window:

    Clicking the icon highlighted in red in the previous image opens a window similar to the one shown below:

    The following tool-redressing parameters can be set from this window.

    Parameters

    Plunge increment
    Indicates the plunge amount for each pass.

    Step passes
    Indicates the number of passes.

    Plunge speed
    Determines the speed during the tool penetration phase into the material.

    Forward speed
    Indicates the desired speed for the forward cutting phase.

    Restart cycle
    Clicking this button restarts the cycle.

    Width
    Width of the material used for redressing.

    height
    Height of the material used for redressing.

    Thickness
    Thickness of the material used for redressing.

    Tool redressing from manual controls panel

    Tool redressing can be performed from the manual controls panel.

    Clicking the icon highlighted in red in the figure below displays a dialog box that allows the procedure to be started or canceled.
