    DOC2.5 POCKET

    The pocket page is used to machine a rectangular pocket with fillets and a flat bottom.
    A suitable milling cutter mounted on the main spindle must be used for this machining operation.
    The “workbench level” is used as the bottom level.
    The cycle uses pass mode with a helical entry at the center and a pass distance that can be set in the parameters.

    Parameters

    X
    Length of the pocket to be machined.

    Y
    Width of the pocket to be machined.

    Radius
    Size of the fillet to be obtained at the corners of the rectangle.

    NOTE

    A value greater than the milling cutter radius must be entered in this field.

    Pocket depth
    Total depth of the pocket in the material.

    Z Step
    Indicates the maximum penetration step into the material. Depending on the pocket depth, the Z increment may decrease so that all passes are performed at the same depth.

    Working distance
    It indicates the lateral displacement between one pass and the parallel pass. It is recommended to set a pass distance equal to 60% of the milling cutter diameter to avoid movements over the corners.

    Entry depth increment
    Indicates the depth increment performed with one turn of the helix during the material entry procedure.

    Working Speed
    Indicates the programmed linear speed for machining. It is recommended to set a value suitable for the material, tool type and thickness to be cut.

    Downward Speed
    This speed is used during the entry procedure.

    X and Y Axis Zeroing
    Resets the origin of the X and Y axes at the lower-left point shown in the image.

    The position is acquired by placing the center of the milling cutter at the indicated point.
    For machines equipped with a “pointer laser”, positions can be acquired by referring to the point indicated by the laser itself.

    Executing the machining operation

    Enter the X, Y and R dimensions that define the shape of the rectangular pocket to be machined.
    Verify that the tool data are correct, especially the diameter.

    The following two execution modes are available

    Pocket-to-workbench-position mode

    To machine a pocket correctly, position the center of the machine at the pocket origin point, as shown in the figure in the previous chapter. This ensures that the entire machining operation develops correctly relative to the designated area.

    Then set the characteristic dimensions of the pocket shape to be machined.

    Before starting machining, it is essential to verify the accuracy of the selected tool data, paying particular attention to the diameter because it directly affects the precision and quality of the pocket.

    The “workbench position” must be acquired with reference to the bottom level of the pocket. To determine it correctly, move to the upper surface of the material and zero the Z position. From there, move downward by the desired pocket depth. The workbench position can then be acquired using the dedicated button. When using milling-cutter tools, it is recommended to perform this operation with the A axis at 90_ to avoid inaccuracies due to the actual tool length.

    Once the workbench position has been defined, zero the X and Y axes. This is done by pressing the relevant reset button and positioning the center of the milling cutter exactly at the point indicated in the figure by the reference symbol. On machines equipped with a pointer laser, the X and Y zero point can be acquired directly using the reference provided by the laser.

    The pocket depth depends directly on the level set as the workbench position and on the Z-axis position when the cycle is started using the “Cycle Start” button. Machining begins with a helical entry at the center down to the depth specified by the “Z Step” parameter. The area is then cleared with a concentric movement, following the distance set in the machining parameters.

    The machine movements required to reach the initial position take place at the so-called “clearance position”, which can be defined in the tool parameters. This ensures that the tool does not interfere with any obstacles during positioning movements.

    Position-above-piece and origin-value zeroing mode

    This mode requires setting and subsequently using the parameter: “Pocket depth”
