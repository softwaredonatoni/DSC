    DOC2.7 ISOCAM

    IsoCam is the software used to perform profile cutting with a saw blade. It allows profiles to be drawn or imported, the path to be selected and different machining methods to be applied.
    Job programming is divided into several stages, which are described in the following paragraphs.

    When IsoCam is opened, if no previously created job exists, the operator can create a new one starting from the first machining step.
    If a previously created job exists, it is loaded automatically and the operator is taken directly to the final machining step:

    Elements shared by the various steps

    The user interface consists of several areas.

    • Menu: quick utilities.

    • Top bar: functions specific to the active page.

    • Central area: contains the drawing or active area according to the page.

    • Sidebar: window containing the parameters to be edited.

    • Bottom bar: buttons generally available in different areas of the software.

    NOTE

    All these elements vary according to the operating context.

    The following elements remain visible at all times, regardless of the current stage of the process.

    Menu

    The menu bar is located at the top, above all other elements of this interface.

    View

    Provides the operator with settings relating to the visibility of pieces in the work area.

    Options

    Colour-related settings can be changed.

    Section drawing (step 1 of 4)

    The first programming stage consists of drawing the section to be machined. The window provides the standard controls of CAD software: draw line, draw arc, snap, move, etc.
    The underlying concept of the software is to create the section as a quick sketch, which is then edited entity by entity using the dedicated controls. Drawings in .dxf format generated by external CAD systems can also be imported at any time.

    Top bar

    Draw Line command
    Enables/Disables the line-drawing command.
    When enabled, it creates a new line starting from the end point of the last entity entered, if available; otherwise, the line is generated at the selected point.

    Draw Arc command
    Enables/Disables the arc-drawing command.
    When enabled, it creates a new arc starting from the end point of the last entity entered, if available; otherwise, the arc is generated from the selected point.

    Move selected segments
    After selecting an entity, press this button to move it within the work area.

    Mirror Shape
    After selecting an entity, this button can be used to flip it horizontally and/or vertically within the work area.

    Fillet
    After enabling the function, follow the parameters on the right.

    Invert active selection
    Inverts the active selection when the button is pressed.

    Delete selected segments
    Deletes the selected entities.

    Right-hand sidebar

    Line properties

    When a line is selected in the work area, the right-hand column is updated to show the properties of the selected entity, which can be edited by the user:

    Length

    Indicates the linear distance between the two ends of the selected line, calculated from their coordinates in the workspace.

    Angle

    Indicates the orientation of the line relative to the horizontal axis of the reference system.

    Δx

    Indicates the change in the X coordinate between the start and end points of a line or entity, i.e. the horizontal distance travelled relative to the X axis of the reference system.

    Δy

    Indicates the change in the Y coordinate between the start and end points of a line or entity, i.e. the vertical distance travelled relative to the Y axis of the reference system.

    Extend/Shorten selected line
    Extends or shortens the selected line by a specified amount, changing its length while keeping its angular direction unchanged. The change is defined using the dedicated input field.

    Round Angle
    Automatically rounds the line angle to the nearest multiple of 90_ (0_, 90_, 180_, 270_), making it easier to align with the orthogonal directions of the reference system.

    Scale connected segments

    Applies proportional scaling to all entities directly or indirectly connected to the selected line.
    When this option is active while the line is being extended or shortened, spatial consistency between the connected elements is maintained, preserving their relative positions in the preview.

    Arc properties

    When an arc is selected in the work area, the right-hand column is updated to show the properties of the selected entity, which can be edited by the user.
    The arc can be defined in several ways: by points, by centre, radius and arc, etc.
    The various properties are shown in the window on the right.
    A property can sometimes be changed in different ways, for example by changing the radius or the start/end point. The “Fixed centre” flag is used to select the method of modification.

    Radius

    Indicates the constant distance between the centre of a circular curve or arc and any point on its circumference.

    Start/end angle

    Angle of the start or end point relative to the centre.

    Tangent to Previous / Next

    Changes the start or end angle so that the arc is tangent to the previous or next entity.

    Fixed centre

    Determines the effects of a change to the radius or angle.

    Translate / Move selection

    When the “move” command is enabled, the movement parameters window appears. Movement can be performed directly by clicking in the drawing area (including with snaps active) or by setting the parameters.
    Confirm the movement using the “OK” button.

    Position selector
    Moves by the set “Delta” value in the direction of the arrow.
    The centre button resets the movement.

    Translation
    Total movement relative to the initial position.
    The numbers in the boxes on the right are used for the “array copy” command.

    Move copy

    When enabled, this function creates a copy of the selected entity and applies the movement only to the copy, leaving the original entity unchanged.

    NOTE

    This command is visible only when the values in the second column of the “Translation” parameter are 1.

    Mirror

    After enabling the command, set the centre of symmetry by clicking in the work area or entering the coordinates, select the mirror direction and press the “OK” button to confirm.

    Centre of symmetry

    Changes the coordinates of the centre of symmetry used to flip the selected entity horizontally or vertically.

    Coordinates to invert

    Indicates whether to flip horizontally, vertically or in both directions.

    Mirror copy

    When enabled, the mirroring operation creates a mirrored copy of the selected entity while leaving the original unchanged.

    Profile selection (step 2 of 4)

    The section drawn previously must be applied to a suitable profile.
    The profile can be linear or curved, in the X/Y plane or vertical; certain machining modes are enabled or disabled according to the selection. For example, a curved profile in the XY plane can be machined only with a vertical saw blade, while the opposite applies to a curved profile in the XZ or YZ plane.
    The profile type is selected using the buttons on the left, the parameters used to define the profile geometry are shown at the top centre, and a preview of the result is shown at the bottom centre.

    Central area

    Linear Profile

    Set the direction and length.
    The sign of the “Delta Z” value follows the Z axis (positive upwards, negative downwards).

    Arc Profile

    Define the direction, working plane, concavity and geometric properties.
    Any change to the geometric properties affects other variables.

    NOTE

    The maximum radius that can be set is 9999mm.

    Circular Profile

    This is machined externally only, using a horizontal saw blade.

    Linear Profile parameters

    Profile Execution

    Two modes are available: “Along X” and “Along Y”.

    Line length (L)

    Horizontal length of the base of the inclined segment, measured between the starting point and the horizontally projected end point.

    End-point Delta Z (H)

    Height of the inclined segment, i.e. the difference in position between the start and end of the segment.

    Arc Profile parameters

    Profile Execution

    Select either “Along X” or “Along Y”.

    Machining orientation

    Select either “XZ Plane” or “XY Plane”.

    Machining type

    Select either “Concave” or “Convex”.

    Length (L)

    Horizontal distance between the two ends of the arc, i.e. the chord connecting the start and end of the arc.

    Starting radius (R)

    Distance from the centre of the arc to a point on the arc itself. This determines the overall curvature of the arc.

    Vertical rise (H)

    Maximum height of the arc relative to chord L; this is the vertical distance between the highest point of the arc and the chord.

    Angle span (A)

    Central angle subtended by the arc, expressed in degrees.

    NOTE

    Changing any of the following values: “Length”, “Starting radius”, “Vertical rise” or “Angle span” automatically recalculates the remaining parameters.

    Circular Profile parameters

    Starting radius (R)

    Defines the radius from the starting point.

    Guard

    This flag indicates whether the C axis rotates during machining (guard enabled) or remains stationary at C=0_ (guard not present).

    Bottom bar

    Table view
    Enables/Disables the table view.

    Additional lights
    Enables/Disables additional lights for the 3D view.

    Default view management
    Changes the viewpoint.

    Machining parameters (step 3 of 4)

    The page is divided into panels containing the different types of data to be set for machining.

    Tool parameters

    The operator can define the tool parameters:

    For a new project, the data are loaded automatically according to the tool physically installed. For a previously saved job, the tool data are those already saved in the previous program.

    Tool name
    Shows the name of the selected tool.

    Thickness
    Indicates the blade thickness in the cutting direction (saw-blade body thickness).

    Diameter
    Maximum diameter of the saw blade, measured from one end of the toothed edge to the other.

    CRF (Flange Rotation Centre)
    Measures the distance between the inner edge of the tooth of the saw blade currently mounted on the machine and the C rotation axis.

    Safety position
    Safety distance between the saw blade and the worktable.

    RPM (Revolutions Per Minute)
    Number of saw-blade rotations per minute during operation.

    Machining orientation

    Linear Profile

    For linear profiles, machining can be performed with the saw blade vertical or horizontal (from the front or from the left).

    Horizontal Orientation

    Machining type

    Machining can be performed in two modes:

    Cut mode
    Performs mutually parallel cuts that follow the selected profile.

    Scraping mode
    Performs mutually parallel cuts transverse to the profile direction.

    Cut-mode configuration

    Mutually parallel cuts are performed following the selected profile, with the distance between cuts taken from a parameter.

    Step

    Indicates the distance between a cut position and the adjacent cut. If it is greater than the saw-blade thickness, material remains between the passes.

    Start / end extension

    Extends a cut at its start/end by the set value.

    Auto Plus

    Enabling this flag automatically increases the extension value according to a value established by the system.

    Excess material

    Thickness of material to be left above the required final section.

    Cut direction

    The cut can run from right to left or from left to right, depending on the selected configuration.

    Scraping-mode configuration

    The movement is transverse to the profile direction and is used for surface finishing of the piece.

    Scraping step

    Indicates the distance between one transverse movement and the next along the profile direction.

    Cutting speed and mode

    Depending on the previous selections, different menus appear for selecting the parameters required to define the machining operation.

    If the selected machining type is Cut-Mode Configuration, two types of machining parameters are available:

    Marble Mode
    The cut is performed in a single pass.

    Granite Mode
    The cut is performed in steps.

    Marble Mode

    General parameters:

    Cut in both directions (finishing)

    This flag allows a return speed different from the forward speed to be set.

    Never raise (finishing)

    WARNING!

    When this parameter is enabled, the saw blade must emerge completely from the cutting section.

    Speed parameters:

    Forward

    Execution speed of the forward pass.

    Return

    Execution speed of the return pass.

    Penetration

    Execution speed during pass penetration.

    Minimum

    When a non-zero value is set, the cutting speed depends on the cutting depth. Movement is therefore performed at the forward speed for cuts at zero depth and at the minimum speed when the cut reaches the maximum depth for the selected section.

    Granite Mode

    General parameters:

    Forward cutting removal

    Amount of material removed during the forward pass.

    Return cutting removal

    Amount of material removed during the return pass.

    If the selected machining type is Scraping Configuration, a single machining parameter is available:

    Machining speed

    Sets the speed at which scraping machining is performed.

    Machining parameters (advanced)

    Machining parameters (advanced)
    This button opens the advanced machining parameters window.

    This screen can be used to check and edit various parameters, many of which were set in steps 2 and 3.

    The first operation is to select the profile type to be used:

    Linear
    A linear cut is performed.

    Arc
    An arc cut is performed.

    Then set the following parameters:

    Machining

    This can be cut or scraping mode.

    Machining orientation

    Machining can be performed vertically or horizontally.

    Execute profile along

    Along X or Y.

    Machining Data

    The following parameters can be set for a Linear profile:

    Material thickness

    Defines the material thickness (in mm).

    Profile inclination (mm)

    Defines the profile inclination by specifying the difference in height between the end point and the start point.

    For an Arc profile, the parameters set in the previous steps are available.

    Both profiles also share the following machining data:

    Step

    Fixed in Y: maintains a fixed distance between cuts regardless of the underlying section.
    Along the chord: the step is measured as the distance between contact points on the section, so the movement changes according to the slope of the section.

    Cut direction

    Select either “Y_” or “Y-”.

    Complete profile machining

    Selects whether or not to machine the complete profile.

    Force cuts at angles

    Adds cuts at points where the slope changes.

    Remove overlapping cuts

    If this flag is enabled and the “Step” value is greater than the “Thickness” value, overlapping cuts are removed.

    Optimised step (colouring) % Overlap

    If the “Step” value is less than the “Thickness” value, the step is optimised on horizontal lines.

    Perform cut at start

    Selects whether or not to perform a cut at the start of the profile. The depth of this cut can be set using the adjacent box.

    Perform cut at end

    Selects whether or not to perform a cut at the end of the profile. The depth of this cut can be set using the adjacent box.

    Tool Data

    This section shows data set previously and other tool-specific parameters.

    Tool description

    A brief description of the tool.

    Tool magazine
    Opening this panel allows the tools to be managed: new tools can be created, existing tools edited, their order in the list changed, or tools removed.

    Position No.

    Indicates the position number of the selected tool in the magazine.

    Corrector No.

    Indicates the number identifying the selected tool name.

    Saw-blade core thickness (SA)

    Thickness of the central load-bearing body of the saw blade.

    Tooth shape

    The operator can select one of three tooth shapes:

    • Square

    • Spherical

    • Chamfered (in this case, the chamfer values can be defined)

    Select material
    This button, located immediately to the left of the penetration speed value, allows the following materials to be selected:

    • High-quartz granite

    • Low-quartz granite

    • Marble

    • Travertine

    • Sandstone

    Priority

    A strictly positive priority value can be set.

    Depth

    Indicates the tool cutting depth.

    Machining (step 4 of 4)

    A preview of the calculated cuts is displayed according to the previous selections. The page is divided into several areas containing controls for managing changes.

    After checking the cuts or making the required changes, press the “NEXT” button to open the page used to generate the cutting program.

    Menu

    In the fourth step, an additional item becomes visible in the top menu:

    Cuts

    This menu provides the operator with quick settings for the generated cuts.

    Add leading cut to separate pieces

    Removes the selected cut from the preview and recalculates the sequential cut number for all remaining cuts.

    Using the selected cut as a reference, removes cuts with a lower sequential number.

    Delete cuts after selected cut
    Using the selected cut as a reference, removes cuts with a higher sequential number.

    Selects all cuts one at a time according to their sequential cut number.

    Right-hand sidebar

    Program creation

    After preparation in the fourth step is complete, the final stage can be opened. This displays the result and generates the ISO file.
    The central area shows a 3D view of the generated machining operation, taking the operating mode into account. Click in the area to rotate the view and control the zoom.

    NOTE

    When the program starts, the most recently created job is displayed.

    Basic procedure

    Step 1

    To begin, press the "New job" button. Make sure the "Connected Segments" function is active, then enable the "line" command. Click repeatedly in the work area to draw the required section. When the drawing is complete, click the "line" command again to disable it. Then select each entity individually to check and, if necessary, edit its parameters.

    Step 2

    In this step, the operator can set basic general parameters relating to the required machining type.

    Step 3

    The tool parameters and the type, orientation and parameters of the selected machining operation can now be set.
    The “Machining parameters (advanced)” panel also provides an overview of all parameters set up to this point.

    Step 4

    A cut list is generated automatically for the current machining operation. Cuts can be inserted, edited and removed according to operating requirements.

    ISO Generation

    The final machining step allows the operator to create an ISO file from the resulting job or restart the procedure.
