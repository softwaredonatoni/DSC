    DOC3.14.1 AUTOMATIC NESTING (OPTIONAL)

    Automatic Nesting is particularly useful when there are many pieces to process and the different combinations can no longer be managed easily by an operator.
    Different solutions may be generated depending on the set parameters. They are displayed on the screen and the operator can select the preferred configuration.

    Buttons

    Add
    Allows the operator to create a configuration.

    Delete
    Allows the operator to delete a configuration.

    Edit
    Allows the operator to edit a configuration.

    Execute
    Calculates all configurations and adds the results to the list on the right.

    Editing a configuration

    Automatic Nesting allows the parameters used to calculate piece placement in the work area to be customised for each configuration.
    Depending on the type of pieces to be processed, some strategies may provide better performance.

    Name

    Name of the configuration shown in the list.

    Slab distance

    Distance that pieces must maintain from the slab edge when positioned.

    No. of solutions to search

    Number of solutions calculated by Nesting. The best of all calculated solutions is selected.

    No. of movement attempts

    Number of attempts made by moving the piece if it does not fit within the slab perimeter.

    Movement value

    Distance by which the piece is moved in an attempt to place it within the slab perimeter.

    No. of attempts on the same slab

    Number of attempts made to place the piece within the same perimeter if it does not fit.

    Solution calculation timeout

    Maximum time allowed for calculating each individual solution.

    Use list order

    Forces the program to attempt to position the pieces within the perimeter in the order in which they appear in the piece list.

    Use custom order

    Allows the order in which pieces are placed within the slab perimeter to be selected according to certain piece properties.
    To enable a sorting criterion, select the corresponding check box.
    The criteria are applied from top to bottom. This means that pieces are sorted according to the first criterion. If two or more pieces have the same value for the property linked to the first criterion, they are sorted according to the next criterion, and so on for every criterion in the list.
    For each criterion, ascending or descending order can be selected.

    Force piece before moving to the next

    Selects whether the program attempts to position the piece in different locations within the slab perimeter or moves on to placing the next piece without further attempts.

    Fixed starting point

    Selects the point on the perimeter from which piece placement starts.

    Fix rows-columns mode

    Selects whether pieces are placed according to a row, column or random arrangement logic.

    Piece rotation mode

    Selects the logic used to rotate pieces during placement attempts within the slab perimeter.

    Use largest inscribed rectangle

    When enabled, pieces are placed inside the largest-area rectangle contained within the perimeter.
    Otherwise, Nesting attempts to arrange the pieces over the entire available perimeter area.

    Enable Deep Nesting

    When disabled, pieces are placed on the slab to optimise use of the suction-cup material handling system for resolving collisions.
    When enabled, more complex piece combinations can be searched, although their arrangement may conflict with use of the handling system.

    Executing Nesting

    Pressing the blue arrow next to an item in the list calculates the Nesting using that configuration.
    A preview of the result is added to the section on the right. It shows the arrangement of the pieces within the perimeter and the percentage of slab area covered by the pieces.

    If the piece arrangement is unsatisfactory, press the blue arrow again to recalculate the result.

    After all Nesting configurations have been executed, the results are arranged with those that occupy the largest slab area shown first.

    After selecting the preferred configuration, press the confirm button and the pieces are positioned on the slab according to the selected arrangement. The operator can still change their positions in the work area.

    NOTE

    The pieces are placed on the slab taking into account subsequent use of the suction-cup material handling system to resolve collisions between pieces and the defects marked on the slab.
