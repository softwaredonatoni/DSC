    DOC3.21.1 CUT LIST

    The cuts to be performed by the machine are shown in this list.

    Using the cut list, the operator can:

    • Change the cut execution order.

    • Edit the characteristics of a cut.

    • Insert pauses between cuts.

    List items

    Enable/Disable cut
    Indicates whether the cut is enabled or disabled for machining.
    Pressing the button changes its status.

    Cut type
    Indicates the cut type (“Perimeter”, “Internal cut”, “Milling”, etc.).

    Machining type
    Indicates the machining type associated with the cut (“Linear“, “Arc“, “Milling“, etc.).

    Functions

    The arrangement of the cuts in the list on the right indicates the order in which they are performed.
    The buttons below can be used to change this order or insert a pause between one cut and the next.

    Move using arrows
    Moves the selected cut up or down in the list.

    Move to desired position
    Moves the currently selected cut to the position specified in the adjacent text box.

    Select order from the work area
    Allows the cut order to be selected directly from the work area.

    Pause
    Inserts a pause after the selected cut.

    Delete cut
    Deletes a cut selected in the list.

    Edit cut
    Edits certain properties of the selected cut.

    Additional piece properties
    Edits the additional properties of the piece selected in the work area.

    The following is also shown at the bottom of the list:

    Estimated cutting time
    Preview of the estimated time required to execute the cutting program for the items in the list.

    NOTE

    The estimated cutting time is updated whenever an operation is performed on the cuts.

    Select order from the work area

    This function allows the cut order to be selected directly from the work area.
    When the button is pressed, the program writes a number on each cut indicating its position in the list.

    To change the order, click in sequence inside the cut to be placed first, then the second cut, and so on.
    When finished, press the button again to confirm the selection.

    Pause

    A pause can be inserted between one cut and the next.
    The program performs all cuts preceding the pause, then stops the machine and waits for the operator to issue the Start command.

    The pause is always inserted after the selected cut has been performed.
    It can be used, for example, to change the tool.

    Delete cut

    After the button is pressed, an eraser icon appears next to each item in the list.
    Press a cut to delete it permanently.
