    DOC4.4 CUT COMBINATION

    This screen shows the spindle combinations used by the machine to perform the cuts.

    Combined cut list

    Each item in the list on the right shows the combination of spindles used to perform a set of cuts simultaneously.

    NOTE

    If a spindle is manually disabled using the dedicated command in the tool panel, it is not considered in cut combinations.

    As with standard cuts, their order in the list can be changed or they can be disabled.

    Enable/Disable cut
    Indicates whether the cut must be enabled or disabled for the working.
    Pressing the button changes its status.

    Move using arrows
    Allows the selected cut to be moved to the position above or below.

    Move to desired position
    Allows the currently selected cut to be moved to the position indicated in the adjacent text box.

    Pause
    Allows a pause to be inserted in the position immediately after the selected cut.

    NOTE

    Any operation performed on an item in the list affects all the cuts it contains.

    Buttons

    The following button is located in the bottom bar:

    Display Unloading
    Provides access to a screen through which the operator can create an unloading program to position rows of pieces on the dedicated belts.
