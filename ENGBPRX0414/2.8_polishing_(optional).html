    DOC2.8 POLISHING (OPTIONAL)

    The Polishing program can perform polishing using different machining types. The method used to acquire the slab geometry can also be selected: either by detecting the points that define the surface vertices (from three to a maximum of six) or by using a regular surface (rectangle) and entering the zero position and the values of the two sides.

    Machining modes

    To use this machining operation, first select one of the two available modes by pressing the corresponding button:

    NOTE

    The ‘
    Rectangle selection
    ' and '
    Free point selection
    ’ modes are mutually exclusive: enabling one automatically disables the other.

    Switch to Free point selection mode
    Pressing the button shown switches from the operating mode that uses a rectangle as the predefined shape to the mode in which the surface is acquired by selecting points.

    Switch to Rectangle selection mode
    Pressing the button shown switches from the operating mode in which the surface is acquired by selecting points to the mode that uses a rectangle as the predefined shape.

    Entry/exit mode

    The buttons shown switch tool entry and exit between progressive and standard mode.

    NOTE

    The ‘
    Progressive
    ' and '
    Standard
    ’ modes are mutually exclusive: enabling one automatically disables the other.

    Switch to progressive mode
    When this mode is enabled, at program start the machine moves from the working Z position to the safety Z position, then moves towards the first point of the surface to be polished (for a rectangle, the top-left point). It then moves along the surface perimeter, progressively lowering the Z position so that the tool reaches the working position at the end of the path. The machine then performs a polishing operation around the perimeter, after which the selected operations are performed in sequence. At the end of the work sequences, the machine makes another pass around the perimeter of the surface to be polished, then follows the same path while progressively raising in Z until the safety position is reached at the end of the path.

    Switch to standard mode
    When this mode is enabled, at program start the machine moves from the working Z position to the safety Z position, then moves towards the first point of the surface to be polished (for a rectangle, the top-left point). It then lowers in Z to the working position while keeping the X and Y axes stationary, after which the selected polishing operations begin. At the end of the set work sequences, the machine moves to the first point of the surface to be polished and then rises in Z to the safety position.

    Free point selection mode

    This mode is displayed as follows:

    Parameters

    Point positions

    Set
    This button enters the coordinates of each point. When the position has been acquired, the adjacent figure changes from red to green.

    NOTE

    A minimum of three and a maximum of six points can be entered.

    Clear
    This button deletes all saved positions if the setup is incorrect and the points need to be acquired again.

    Machining types

    Perimeter
    Polishing is performed only around the perimeter of the set geometric shape.

    Horizontal passes
    Multiple horizontal passes are performed.

    Vertical passes
    Multiple vertical passes are performed.

    Global repeat
    The machining cycles can be restarted by entering the number of repeats in the relevant box. The box in the “Completed” column shows the number of repetitions completed for the entire machining operation.

    Machining parameters

    Repetitions

    Each machining type can be repeated the number of times set in this field.
    If the value is set to “0”, that machining operation is not performed.

    Completed

    Displays the number of repetitions completed.

    Step [mm]

    Indicates the distance between one pass and the next, selectable for each machining type.

    Polishing tool parameters

    Machining speed
    Indicates the speed at which machining is performed.

    Downward speed
    Indicates the required positioning speed along the Z axis to the selected coordinate.

    Tool wear
    Allows tool wear to be taken into account during machining by entering the compensation value.

    Executing Free point selection mode

    WARNING!

    Between one operation and the next, the machine moves without rising to the safety position.

    The operator sets the positions of a minimum of three and a maximum of six available points by moving the machine manually and using the corresponding save controls. After the points have been defined, configure the machining parameters for each required polishing type. The specific parameters of the tool used for polishing are set at the same time.

    At any time before starting the polishing cycle, the operator can change the tool entry and exit mode by selecting one of the two available options.

    After configuration is complete, the machine's A axis must be inclined to 90_ and saw-blade rotation started. The operator can then execute the programmed cycles by pressing the “Cycle Start” button. During execution, progress can be monitored in the “Completed” column, which shows the cycles completed for each selected polishing type.

    Rectangle selection mode

    This mode is displayed as follows:

    Parameters

    Rectangle position

    Rectangle sides
    The shape on which machining is performed is defined by the values assigned to Y and X, which correspond to the sides of the rectangle. The coordinates of the lower-left vertex of the rectangle are acquired using the respective reset buttons below each axis. Both values must be reset.

    Machining parameters

    See the Free point selection machining parameters mode for the following operations: Perimeter, Horizontal/vertical passes and Global repeat.

    Zigzag
    Zigzag passes are performed.

    Polishing tool parameters

    See Free point selection saw-blade parameters for the following saw-blade parameters: Machining speed, Downward speed and Saw-blade wear.

    Y-axis step for Zigzag
    For zigzag polishing mode, the Y machining step can be changed, allowing the working path to be divided into multiple passes. If the value is left at zero or set higher than parameter B, the polishing step along the Y axis is equal to B.

    Executing Rectangle selection mode

    WARNING!

    Between one operation and the next, the machine moves without rising to the safety position.

    The operator defines the position of the rectangle to be polished by moving the machine manually and changing the corresponding coordinate values. Once the rectangle has been defined, configure the machining parameters for each required polishing type. The specific parameters of the tool used for polishing are set at the same time.

    At any time before starting the polishing cycle, the operator can change the tool entry and exit mode by selecting one of the two available options.

    After configuration is complete, the machine's A axis must be inclined to 90_ and saw-blade rotation started. The operator can then execute the programmed cycles by pressing the “Cycle Start” button. During execution, progress can be monitored in the “Completed” column, which shows the cycles completed for each selected polishing type.
