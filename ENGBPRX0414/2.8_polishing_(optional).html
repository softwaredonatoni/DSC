    DOC2.8 POLISHING (OPTIONAL)

    The Polishing program allows polishing to be performed using different types of working. The method for acquiring the slab geometry can also be selected: by detecting the points defining the surface vertices (from three up to a maximum of six), or by using a regular surface (rectangle) by entering the zero position and the values of the two sides.

    Working mode

    To use this working, first select one of the two available modes by pressing the corresponding button:

    NOTE

    The ‘
    Rectangle selection
    ’ and ‘
    Free point selection
    ’ modes are mutually exclusive: enabling one automatically disables the other.

    Switch to Free point selection mode
    Pressing the button shown in the figure switches from the working mode that uses a rectangle as the predefined figure to the mode in which the surface is acquired by selecting points.

    Switch to Rectangle selection mode
    Pressing the button shown in the figure switches from the working mode in which the surface is acquired by selecting points to the mode that uses a rectangle as the predefined figure.

    Entry/exit mode

    The buttons shown in the figure allow tool entry and exit to be changed between progressive and standard mode.

    NOTE

    The ‘
    Progressive
    ’ and ‘
    Standard
    ’ modes are mutually exclusive: enabling one automatically disables the other.

    Switch to progressive mode
    When this mode is enabled, at program start the machine moves from the working Z position to the safety Z position and then towards the first point of the surface to be polished (for the rectangle, the top-left point). It then moves along the perimeter of the surface, progressively lowering the Z position so that the tool is at the working position at the end of the path. After this phase, the machine performs a polishing pass around the perimeter, after which the selected workings are executed in sequence. At the end of the working sequences, the machine makes a pass around the perimeter of the surface to be polished, then follows the same path while progressively raising Z until the safety position is reached at the end of the path.

    Switch to standard mode
    When this mode is enabled, at program start the machine moves from the working Z position to the safety Z position and then towards the first point of the surface to be polished (for the rectangle, the top-left point). Keeping the X and Y axes stationary, it then lowers in Z to the working position, after which the selected polishing workings begin. At the end of the set working sequences, the machine moves to the first point of the surface to be polished and then raises in Z to the safety position.

    Free point selection mode

    This mode is displayed as follows:

    Parameters

    Point positions

    Set
    This button allows the coordinates of each point to be entered. Once the position has been acquired, the status of the adjacent figure changes from red to green.

    NOTE

    A minimum of three and a maximum of six points can be entered.

    Clear
    This button deletes all saved positions if the setting is incorrect and the points need to be acquired again.

    Working types

    Perimeter
    The polishing operation affects only the perimeter area of the set geometric figure.

    Horizontal passes
    Multiple horizontal passes are performed.

    Vertical passes
    Multiple vertical passes are performed.

    Global repetition
    The working cycles can be started again by entering the number of repetitions in the appropriate box. The box in the “Performed” column shows the number of repetitions completed for the entire working.

    Machining parameters

    Steps

    Each working type can be repeated a fixed number of times, entered in this dedicated field.
    If the value is set to “0”, the corresponding working is not performed.

    Made

    Displays the number of repetitions performed.

    Step [mm]

    Indicates the distance between one pass and the next, selectable for each working type.

    Tool parameters for polishing

    Working speed
    Indicates the speed at which the working is performed.

    Downward speed
    Indicates the desired speed when positioning along the Z axis at the selected coordinate.

    Tool wear
    Allows tool wear to be taken into account during the working by entering the compensation value.

    Executing Free point selection mode

    WARNING!

    Between one working and the next, the machine moves without rising to the safety position.

    The operator sets the position of a minimum of three up to a maximum of six available points by moving the machine manually and using the corresponding save commands. Once the points have been defined, the working parameters are configured for each desired polishing type. At the same time, the specific parameters of the tool to be used for polishing are also set.

    At any time before starting the polishing cycle, the operator can change the tool entry and exit mode by selecting one of the two available options.

    Once configuration is complete, the machine A axis must be inclined to 90_ and disk rotation started. The operator can then execute the programmed cycles by pressing the “Start cycle” button. During execution, progress can be monitored in the “Performed” column, which shows the cycles completed for each selected polishing type.

    Rectangle selection mode

    This mode is displayed as follows:

    Parameters

    Rectangle position

    Rectangle sides
    The figure on which the working is performed is determined by the values assigned to Y and X, which correspond to the sides of the rectangle. The coordinates of the bottom-left vertex of the rectangle are acquired using the respective reset buttons located below each axis. Both values must be reset.

    Machining parameters

    For the following workings, refer to the Free point selection working parameters mode: Perimeter, Horizontal/vertical passes and Global repetition.

    ZigZag
    Zigzag passes are performed.

    Tool parameters for polishing

    For the disk parameters Working speed, Downward speed and Disk wear, refer to Free point selection disk parameters.

    Y-axis Step for ZigZag
    For zigzag polishing mode, the Y working step can be changed, allowing the working path to be divided into multiple passes. If the value is kept at zero or set to a value greater than parameter B, the polishing step along the Y axis is equal to the value of B.

    Executing Rectangle selection mode

    WARNING!

    Between one working and the next, the machine moves without rising to the safety position.

    The operator defines the position of the rectangle to be polished by moving the machine manually and changing the corresponding coordinate values. Once the rectangle has been defined, the working parameters are configured for each desired polishing type. At the same time, the specific parameters of the tool used for polishing are also set.

    At any time before starting the polishing cycle, the operator can change the tool entry and exit mode by selecting one of the two available options.

    Once configuration is complete, the machine A axis must be inclined to 90_ and disk rotation started. The operator can then execute the programmed cycles by pressing the “Start cycle” button. During execution, progress can be monitored in the “Performed” column, which shows the cycles completed for each selected polishing type.
