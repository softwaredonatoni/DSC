    DOC3.13.12 SURFACE MACHINING (OPTIONAL)

    This function allows the operator to machine the material surface.

    Machining types

    To use this machining operation, first choose one of the two available modes by selecting the corresponding button:

    NOTE

    The 'Rectangular surface' and 'Zigzag surface' modes are mutually exclusive: enabling one automatically disables the other.

    Rectangular surface
    The machine performs parallel passes to move across the surface.
    The disk is used for this machining operation.

    Zigzag surface
    The machine performs zigzag passes to move across the surface.
    The milling cutter is used for this machining operation.

    Parameters

    Axis C Rotation

    Determines the machining orientation, which can be horizontal (0_) or vertical (90_) relative to the work plane.

    NOTE

    The '0_' and '90_' modes are mutually exclusive: enabling one automatically disables the other.

    Pass Extension

    Each cut generated by this machining operation is extended at both the start and end by the length specified by this parameter.

    Depth cutting

    Indicates the machining depth in the material.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the desired cut.

    Executing Rectangular Surface

    After setting the machining parameters, select a side of the piece on which to perform the machining operation.
    The cuts are performed from bottom to top.

    Executing ZigZag Surface

    After setting the machining parameters, select a side of the piece on which to perform the machining operation.
    The cuts are performed from bottom to top.


    Slab machining parameters

    The operator can change parameters relating to surface machining from the slab machining parameters panel.

    Rectangular surface

    This screen shows the machining parameters for “Rectangular surface” mode.

    Parameter description

    Distance between forward passes
    Represents the distance between the forward pass and the next return pass.

    Distance between return passes
    Represents the distance between the return pass and the next forward pass.

    Forward passes only
    If enabled, all passes are performed in the forward direction, i.e. from left to right across the piece.

    Return passes only
    If enabled, all passes are performed in the return direction, i.e. from right to left across the piece.

    Raise disk at end of pass
    If enabled, the disk is raised at the end of each pass.

    Piston pressure
    Enables piston pressure on the material and allows its intensity to be set

    NOTE

    The parameters for passes in a specific direction are mutually exclusive.
    If either is enabled, the program also forces disk raising at the end of each pass to be enabled.

    Speed parameter description

    Plunge
    Determines the speed during the tool penetration phase into the material.

    Forward
    Indicates the desired speed for the forward cutting phase.

    Back
    Indicates the desired speed for the return cutting phase.

    Zigzag surface

    This screen shows the machining parameters for “Zigzag surface” mode.

    Parameter description

    Distance between forward passes
    Represents the vertical distance between the starting point of the diagonal pass and its ending point in the forward direction.

    Distance between return passes
    Represents the vertical distance between the starting point of the diagonal pass and its ending point in the return direction.
