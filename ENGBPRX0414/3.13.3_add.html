    DOC3.13.3 ADD

    This function can be used to add a cut parallel to an existing cut at the desired distance.
    This machining operation can be applied to both linear cuts and curved arcs.

    Parameters

    To add a cut, the following parameter must be set:

    Distance

    Distance from the selected cut at which to add the parallel cut.

    Executing the machining operation

    NOTE

    The machining operation can be applied by pressing the button to the left of the appropriate cut in the polygon list.
    A red icon with an 'X' indicates that the machining operation cannot be applied to the desired cut.

    Once the distance parameter has been set, select the cut relative to which the new cut is to be created.

    The direction in which to add the new cut is calculated so as not to damage the piece: outward if an element of the external polygon is selected, or inward if an internal polygon is selected.
    If the distance value is negative, the added cut is calculated in the direction opposite to the intended movement direction.

    As shown, the new parallel cut is inserted in the Added Machining Operations section and reproduces the characteristics of the selected cut, such as direction and machining type.
