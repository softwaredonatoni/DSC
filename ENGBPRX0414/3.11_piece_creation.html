    DOC3.11 PIECE CREATION

    Parametrix is designed for machining flat, closed geometric figures representing pieces.

    Piece creation mode

    As can be seen from the top navigation bar,

    pieces can be created using one of the following modes:

    DXF file import
    By importing files with the “.dxf” extension created using an external CAD program.

    Create rectangles
    By creating rectangular figures and setting their width and height.

    Create parametric figures
    By creating parametric figures such as kitchen worktops, stairs and other geometric figures.

    CSV file import
    By importing files with the “.csv” extension obtained using spreadsheet management programs such as Microsoft Excel.

    History
    By reimporting pieces created previously.

    Favorites
    By importing pieces saved in a favourites list.

    Create commercial pieces
    By creating a large number of rectangular figures whose width and height can be changed as required.

    A more detailed description of how each mode works is provided in the corresponding paragraph of this chapter.

    The selected function is highlighted in light green. When the “Create Pieces” panel is opened, “Create rectangles” mode is selected.

    Import pieces into Parametrix

    To complete creation of one or more pieces correctly, use the following button, which is available in every section of the panel:

    Import pieces
    Confirms creation of the displayed pieces and inserts them in the list of pieces to be machined.

    NOTE

    Operation of the piece list, located on the right side of the panel, is explained in the corresponding chapter.

    Find Piece
    Searches for the source DXF file of the selected piece.
