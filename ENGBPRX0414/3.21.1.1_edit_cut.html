    DOC3.21.1.1 EDIT CUT

    This panel allows the operator to modify certain characteristics of a cut.

    Buttons

    In the top-left corner, the cut activation state can be modified.

    Enable/Disable cut
    Activates or deactivates the selected cut.

    NOTE

    A deactivated cut is not executed by the machine.

    Different versions of this panel are displayed depending on the type of selected cut.

    Disk Cuts

    When a disk cut, either linear or arc, is selected, the following panel is displayed:

    Disk cuts are characterized by a start point and an end point. The arrows define the direction of travel, from start to end.

    The table below shows the buttons that allow the operator to modify the cut characteristics:

    Reverse Cut Direction
    The operator can reverse the cut execution direction.

    Extension Amount
    Allows the length of each cut extension to be modified.

    Calculate Overcut
    Recalculates the cut extension amount according to the disk diameter and material thickness so that it corresponds to the disk overcut.

    Extend cut
    Extends the cut by the length specified by the extension amount.
    The left button extends the start of the cut, while the right button extends the end.

    Shorten cut
    Shortens the cut by the length specified by the extension amount.
    The left button shortens the start of the cut, while the right button shortens the end.

    Extend Start End to Slab Edge
    Extends the start of the cut to the slab edge.
    The value in the box is used when the cut is to be extended by a specified amount beyond the slab.

    Extend Final End to Slab Edge
    Extends the end of the cut to the slab edge.
    The value in the box is used when the cut is to be extended by a specified amount beyond the slab.

    Extend Short Cuts
    If the selected cut is too short to allow the disk to penetrate the material completely, this button extends the cut, where possible, until it becomes a through cut.

    Some data relating to cut execution are also displayed.

    Plunge
    Cut penetration into the material. The operator can modify this value.

    Speed Percentage
    Percentage of the set speed used to execute the cut. The operator can modify this value.

    NOTE

    The speed percentage of arc cuts cannot be modified.

    Inclination
    Cut inclination angle. Cannot be modified.

    Edit the Cut from the Work Area

    Selecting a cut in the work area and right-clicking opens a window for quickly modifying the cut.

    The buttons correspond to the functions already listed. The end of the cut closest to the point where the button was pressed is extended.

    Internal Arc Cuts

    For arc cuts whose curvature faces toward the inside of the piece, it must be considered that disk overcut during machining could damage the side.
    For this reason, these cuts must be executed differently from external cuts.

    Parametrix provides two modes for cutting internal arcs, selectable with the button at the top right.

    Inclined Arc
    A miter cut is executed to size. The correct inclination is calculated automatically.

    Offset Arc
    The cut is executed without inclination but shifted toward the outside of the piece relative to its correct position.

    NOTE

    By default, Parametrix recommends setting these cuts to “inclined arc“ mode.
    If this is not desired, the execution mode of each cut must be changed individually.

    Each working mode has advantages and disadvantages:

    • Inclined arcs provide a better finish on the final result, which therefore requires less manual finishing work.
      However, they require greater effort from the machine, so the working must be performed at lower speeds and with more steps.

    • Offset arcs require less machine effort during working and can therefore be performed at higher speeds.
      On the other hand, disk overcut causes greater damage to the material, and more material must also be removed during manual finishing.

    Holes and Milling Operations

    Workings such as holes and milling operations allow fewer modifications by the operator.

    Information is available for:

    Plunge
    Cut penetration into the material. The operator can modify this value.

    Tool diameter
    The diameter of the tool used for the cut is displayed.

    Rims and Corner Holes

    Corner holes and rims are workings composed of multiple holes and milling operations, respectively. When one of these items is selected, a list of all the cuts that make it up is displayed.

    The operator can activate or deactivate each cut individually using the button on each list item, or act on all cuts in the working at the same time using the button at the top.
    The buttons below the list allow the order in which the individual cuts are executed to be modified.

    Move with arrows
    Moves the selected cut to the position above or below.

    Move to desired position
    Moves the selected cut to the position specified in the adjacent text box.

    In addition, the operator can modify the working penetration using the field below:

    Plunge
    Penetration of the cuts into the material. The operator can modify this value.

    NOTE

    The plunge depth of all cuts that make up the working is the same
    Changing this value changes the penetration of all cuts in the list.
