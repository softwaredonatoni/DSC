    DOC3.21.1.1 EDIT CUT

    This panel allows the operator to modify certain characteristics of a cut.

    Buttons

    In the top-left corner, the cut can be enabled or disabled.

    Enable/Disable cut
    Enables or disables the selected cut.

    NOTE

    A disabled cut is not performed by the machine.

    Different versions of this panel are displayed according to the type of cut selected.

    Saw blade cuts

    When a linear or arc cut made with the saw blade is selected, the following panel is displayed:

    Cuts made with the saw blade have a start point and an end point. The arrows define the travel direction, from start to end.

    The table below shows the buttons that the operator can use to modify the cut characteristics:

    Reverse cut direction
    The operator can reverse the cut execution direction.

    Extension amount
    Changes the length of each cut extension.

    Calculate overcut
    Recalculates the cut extension according to the saw blade diameter and material thickness so that it matches the saw blade overcut.

    Extend cut
    Extends the cut by the specified extension amount.
    The button on the left extends the start of the cut, while the button on the right extends the end.

    Shorten cut
    Shortens the cut by the specified extension amount.
    The button on the left shortens the start of the cut, while the button on the right shortens the end.

    Extend start point to slab edge
    Extends the start of the cut to the edge of the slab.
    The value in the box is used to extend the cut by a specified amount beyond the slab.

    Extend end point to slab edge
    Extends the end of the cut to the edge of the slab.
    The value in the box is used to extend the cut by a specified amount beyond the slab.

    Extend short cuts
    If the selected cut is too short for the saw blade to penetrate the material completely, this button extends it, where possible, until it becomes a through cut.

    Additional cut execution data is also displayed.

    Plunge
    Cut penetration into the material. The operator can modify this value.

    Speed percentage
    Percentage of the set speed used to perform the cut. The operator can modify this value.

    NOTE

    The speed percentage of arc cuts cannot be modified.

    Inclination
    Cut inclination in degrees. This value cannot be modified.

    Edit the cut from the work area

    Select a cut in the work area and press the right mouse button to open a window for quickly editing the cut.

    The buttons correspond to the functions already listed. The end of the cut closest to the point where the button was pressed is extended.

    Internal arc cuts

    For arc cuts whose curvature faces towards the inside of the piece, the saw blade overcut may damage the side during machining and must therefore be taken into account.
    For this reason, these cuts must be performed differently from external cuts.

    Parametrix provides two modes for cutting internal arcs, selectable using the button in the top-right corner.

    Tilted arc
    A dimensioned miter cut is performed. The appropriate inclination is calculated automatically.

    Offset arc
    The cut is performed without inclination, but is shifted towards the outside of the piece from its correct position.

    NOTE

    By default, Parametrix recommends machining these cuts in “tilted arc“ mode.
    If this mode is not required, the execution mode of each cut must be changed individually.

    Each machining mode has advantages and disadvantages:

    • Tilted arcs provide a better finish on the final result, which therefore requires less manual finishing.
      However, they place greater stress on the machine, so machining must be performed at lower speeds and in more passes.

    • Offset arcs place less stress on the machine and can therefore be performed at higher speeds.
      However, the saw blade overcut causes greater damage to the material, and more material must be removed during manual finishing.

    Holes and Milling Operations

    Machining operations such as holes and milling allow fewer modifications by the operator.

    Information is available for:

    Plunge
    Cut penetration into the material. The operator can modify this value.

    Tool diameter
    Displays the diameter of the tool used for the cut.

    Recesses and Corner Holes

    Corner holes and recesses are machining operations consisting respectively of multiple holes and milling operations. When one of these items is selected, a list of all its constituent cuts is displayed.

    The operator can enable or disable each cut individually using the button on each list item, or act on all cuts in the machining operation simultaneously using the button at the top.
    The buttons below the list change the order in which the individual cuts are performed.

    Move using arrows
    Moves the selected cut up or down in the list.

    Move to the required position
    Moves the selected cut to the position specified in the adjacent text box.

    The operator can also modify the machining penetration using the field below:

    Plunge
    Penetration of the cuts into the material. The operator can modify this value.

    NOTE

    The plunge is the same for all cuts making up the machining operation.
    Changing this value changes the penetration of all cuts in the list.
