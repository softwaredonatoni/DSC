    DOC3.13.18 FLUTES

    Cette fonction permet d’appliquer des usinages avec l’outil de type fraise actuellement monté sur la machine à la coupe sélectionnée, qu’elle soit courbe ou droite, afin d’obtenir des flutes.

    Paramètres

    Le résultat varie en fonction de la valeur des paramètres suivants :

    Nombre de flutes

    Indique combien de flutes doivent être appliquées à l’usinage courant sur la coupe sélectionnée.

    REMARQUE

    Ce paramètre est visible uniquement lorsque le mode d’insertion des flutes par nombre est sélectionné.

    Recalculer nombre
    Recalcule le nombre de flutes de manière à remplir la coupe sélectionnée.

    REMARQUE

    Ce paramètre est visible uniquement lorsque le mode d’insertion des flutes par nombre est sélectionné.

    Longueur

    Indique jusqu’à quelle distance les flutes pénètrent dans la coupe.

    Distance

    Cette valeur représente la distance entre les flutes et tient compte du diamètre de l’outil monté.

    Distance de début

    Cette valeur définit la distance entre les sommets des flutes à l’intérieur de la pièce, en réglant l’espace vide qui les sépare.

    Allongement intérieur

    Indique jusqu’à quelle distance les flutes sont prolongés au-delà de la coupe de référence.

    Profondeur initiale

    Pénétration dans le matériau au point initial de la rainure de drainage.

    Profondeur finale

    Pénétration dans le matériau au point final de la rainure de drainage.

    Type de flutes sur arcs

    Pour les flutes sur courbes, trois modes sont disponibles et sont illustrés ci-après.

    REMARQUE

    Ce paramètre est visible uniquement lorsqu’une coupe courbe est sélectionnée.

    Épaisseur de coupe

    Pour les flutes insérés en mode disque, la variable d’épaisseur de coupe est disponible.

    REMARQUE

    Ce paramètre est visible uniquement lorsque le mode disque est sélectionné pour insérer les flutes.

    Chevauchement de la rainure d’égouttage

    Pour les flutes insérés en mode remplissage, le pourcentage peut être modifié.

    REMARQUE

    Ce paramètre est visible uniquement lorsque le mode remplissage est sélectionné pour insérer les flutes.

    Recalculer nombre

    Le bouton situé à droite du nombre de flutes permet de remplir la coupe sélectionnée avec le plus grand nombre possible de flutes, en fonction de la valeur des autres paramètres.

    Mode d’insertion des flutes

    Les options d’insertion des flutes sont les suivantes :

    Insertion par nombre
    Les flutes sont insérés en fonction du nombre saisi.

    REMARQUE

    Si ce mode d’insertion est choisi, l’insertion par remplissage ne peut pas être utilisée, et inversement.

    Insertion par remplissage
    Les flutes sont insérés en fonction de la distance saisie.

    Mode disque
    Le disque est utilisé pour usiner les flutes.

    REMARQUE

    Si ce mode est choisi, le mode fraise ne peut pas être utilisé, et inversement.

    Mode fraise
    La fraise est utilisée pour usiner les flutes.

    Mode flutes sur arcs

    Lorsqu’une coupe courbe d’un polygone est sélectionnée, un nouveau paramètre apparaît afin de choisir l’une des trois valeurs suivantes :

    Radiaux
    Les flutes sont disposés le long de la courbe de manière à être orientés vers le centre de l’arc.

    Alignement sur l’arc
    Les flutes sont disposés parallèlement le long de la courbe et ont tous la même longueur.

    Alignement tangentiel
    Les flutes sont disposés parallèlement le long de la courbe. Leur longueur varie de façon à maintenir toutes les extrémités intérieures à la pièce sur une même ligne droite, tout en respectant l’allongement des extrémités extérieures à la pièce.

    Mode 1 : Radiaux

    Dans ce mode, les flutes partagent un même point d’origine et sont perpendiculaires à la tangente correspondante sur la coupe courbe sélectionnée.

    Mode 2 : Alignement sur l’arc

    Dans ce mode, les flutes sont parallèles entre eux et sont alignés sur l’arc aussi bien pour la distance que pour l’allongement intérieur.

    Mode 3 : Alignement tangentiel

    Dans ce mode, les flutes sont parallèles entre eux et sont alignés sur l’arc pour l’allongement intérieur, tandis qu’ils sont prolongés jusqu’à atteindre la tangente située à la distance spécifiée par la valeur de longueur.

    Exécution de l’usinage

    REMARQUE

    Il est possible d’appliquer l’usinage en appuyant sur le bouton situé à gauche de la coupe appropriée dans la liste des polygones.
    Une icône rouge avec un « X » indique que l’usinage ne peut pas être appliqué à la coupe souhaitée.

    Une fois le résultat souhaité obtenu, affiché et constamment mis à jour dans l’aperçu de l’usinage, l’opérateur peut confirmer l’opération en appuyant sur le bouton vert « OK », situé juste sous les paramètres définis.
    Les flutes affichés dans l’aperçu sont alors appliqués à la coupe sélectionnée : leur couleur passe au vert foncé, aussi bien dans l’aperçu que, par la suite, dans la zone de travail, indiquant ainsi leur application.

    La liste des coupes située à gauche est également mise à jour en fonction du nouvel usinage appliqué et des paramètres des flutes.
    Il est possible d’appliquer plusieurs usinages de ce type à une seule coupe, à condition que leurs paramètres ne soient pas identiques.
