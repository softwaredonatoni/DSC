    DOC2.3 PROGRAMME ISO

    La page de programmation des fichiers ISO permet de gérer et de lancer les usinages à l’aide de fichiers .pgm créés auparavant avec des programmes CAD-CAM.

    Liste

    La liste du programme ISO, initialement vide, contient tous les programmes ISO pouvant être exécutés séquentiellement.

    Boutons

    Une série de boutons permet de gérer la liste.

    Ouvrir le fichier
    Ouvre l’Explorateur de fichiers afin de créer une liste de fichiers à exécuter.

    Nouvelle liste ISO
    Ajoute un fichier à la liste des fichiers à exécuter.

    Ajouter une pause
    Ajoute une pause à la liste des fichiers à exécuter.

    Supprimer l’élément sélectionné
    Supprime un fichier de la liste des fichiers à exécuter.

    Vider la liste
    Supprime toute la liste des fichiers à exécuter.

    Déplacer l’élément sélectionné vers le haut
    Déplace vers le haut le fichier ISO sélectionné dans la liste des fichiers à exécuter.

    Déplacer l’élément sélectionné vers le bas
    Déplace vers le bas le fichier ISO sélectionné dans la liste des fichiers à exécuter.

    Dans la partie inférieure se trouvent également les deux boutons relatifs aux modes d’exécution des programmes :

    Manuel / automatique
    Définit si l’état de la machine est manuel ou automatique.

    Unique / suivant automatique
    Définit si le programme suivant doit démarrer automatiquement ou non.

    Ouvrir le fichier

    Appuyer sur ce bouton affiche une fenêtre « Ouverture du fichier », comme illustré ci-dessous :

    Cette fenêtre est divisée en plusieurs composants :

    • Liste des fichiers

      • comprend tous les fichiers au format .pgm présents dans le répertoire actuellement sélectionné

    • Boutons entre la liste Fichiers et la liste Fichiers sélectionnés

    • Liste des fichiers sélectionnés

      • Liste initialement vide

    • aperçu du fichier sélectionné

      • Affiche un aperçu d’un fichier .pgm sélectionné dans Fichiers ou Fichiers sélectionnés

    • Barre inférieure et filtre de recherche

    Boutons centraux, placés entre la liste « FICHIERS » et la liste « FICHIERS SÉLECTIONNÉS »

    Sélectionner l’élément
    Déplace l’élément sélectionné de la liste FICHIERS vers la liste FICHIERS SÉLECTIONNÉS.

    Supprimer l’élément
    Supprime l’élément sélectionné de la liste FICHIERS SÉLECTIONNÉS.

    Insérer une pause
    Ajoute une pause à la position suivant l’élément sélectionné dans FICHIERS SÉLECTIONNÉS.

    Déplacer l’élément sélectionné vers le haut
    Déplace l’élément sélectionné d’une position vers le haut dans la liste FICHIERS SÉLECTIONNÉS.

    Déplacer l’élément sélectionné vers le bas
    Déplace l’élément sélectionné d’une position vers le bas dans la liste FICHIERS SÉLECTIONNÉS.

    Le contenu de la barre inférieure est présenté ci-dessous :

    Effacer le filtre de recherche
    Vide la barre de texte située à gauche de ce bouton.

    Tri par dernière modification
    Trie les fichiers présents dans FICHIERS en fonction des modifications les plus récentes (première image) ou les moins récentes (deuxième image).

    Tri alphabétique
    Trie les fichiers présents dans FICHIERS par ordre alphabétique ou par ordre alphabétique inverse.

    Afficher les fichiers de la clé USB
    Affiche tous les fichiers portant l’extension .pgm présents sur la clé USB.

    Afficher le dossier ISO
    Affiche le contenu du dossier ISO.

    Afficher le contenu
    Affiche les lecteurs présents sur l’ordinateur et le dossier Bureau.

    Supprimer le fichier
    Active le mode de suppression des fichiers, permettant de supprimer les fichiers .pgm de FICHIERS.

    Activer/Désactiver la copie
    Permet d’activer/désactiver la fonction de copie (copie le fichier sélectionné dans le dossier ISO).

    Code du programme ISO

    Le code du programme ISO en cours d’exécution s’affiche dans cette fenêtre :

    Boutons

    Dans cette section du programme ISO se trouvent les boutons et fonctions suivants.

    Minuterie et Réinitialisation
    Indique la durée d’exécution de l’ensemble du fichier .pgm.
    Appuyer sur le bouton réinitialise la minuterie

    Aperçu ISO
    Active ou désactive l’affichage de l’aperçu ISO.

    Recherche de bloc
    Ce bouton n’est affiché qu’après le chargement d’au moins un programme dans la liste ; il permet de rechercher un bloc par ligne.

    Recherche de bloc par ligne
    Ce bouton remplace le bouton « Recherche de bloc » après avoir appuyé sur ce dernier.
    L’opérateur peut rechercher une ligne de code spécifique dans une petite fenêtre affichée à l’écran.

    Après avoir saisi un nombre dans le champ « Numéro de ligne » et appuyé sur le bouton « Aller à », l’affichage du code du programme ISO se déplace vers la ligne souhaitée, ou vers la dernière ligne disponible si le nombre saisi dépasse le nombre de lignes du programme ISO sélectionné.

    Il est possible de terminer la recherche d’un bloc et de rétablir l’affichage du bouton « Recherche de bloc » en appuyant sur le bouton Fermer :

    Fonction Dry Run (Activée / désactivée)
    En sélectionnant ce mode de travail, il est possible d’effectuer un usinage à la vitesse maximale de la machine.

    ATTENTION !

    L’utilisation de cette fonction impose de n’utiliser AUCUN type de matériau pendant l’usinage, car les vitesses définies dans le programme ISO ne sont pas respectées pendant l’exécution ; la commande numérique exécute l’ensemble du programme à la vitesse nominale maximale pouvant être atteinte avec les axes interpolés.

    Fonction Test ISO (Activée / désactivée)
    Cette option permet de tester le fichier chargé afin de vérifier qu’il ne contient aucune erreur de syntaxe.
    Appuyer sur le bouton « START CYCLE » : la machine exécute virtuellement toutes les lignes de code sans déplacer les axes.

    Panneau ventouses
    Accès au panneau de gestion des ventouses.

    Enregistrer
    Appuyer sur le bouton fait apparaître un clavier permettant de modifier le fichier .pgm chargé avant de le lancer.

    Recherche de bloc

    Pendant l’exécution de fichiers (.pgm), la fonction de recherche de bloc peut être utile pour repositionner l’outil au point où la machine a interrompu l’exécution du programme, en cas de blocage de l’outil dans le matériau ou d’autres types de blocage.

    Une fois le bouton enfoncé, il est possible de rechercher la ligne à partir de laquelle poursuivre/démarrer l’usinage en saisissant le numéro de ligne et en appuyant sur le bouton « Recherche de bloc par ligne », ou en faisant défiler le fichier à l’aide de la barre de défilement placée à côté du fichier puis en sélectionnant la ligne souhaitée.
    Après avoir sélectionné le point du programme à partir duquel la machine doit reprendre le travail interrompu, appuyer sur le bouton « Start cycle » ; la machine recalcule toutes les lignes de code du fichier .pgm sans effectuer aucun mouvement. La durée de cette opération dépend du nombre de lignes de code à générer sans effectuer de mouvement.

    Une fois le recalcul terminé, la machine active une pause automatique et demande un nouvel appui sur le bouton « Start cycle » pour démarrer l’usinage.
    Avant de démarrer le cycle, il est recommandé de tenir compte du positionnement initial de la machine, qui implique tous les axes simultanément.
    Cela est nécessaire car la machine se déplace de sa position actuelle jusqu’au point de début d’usinage en recherchant le trajet le plus court ; pour ce faire, tous les axes se déplacent afin d’atteindre exactement ce point.


    Cela signifie, par exemple, que l’axe Z ne descend pas une fois le point initial atteint, mais descend progressivement pendant le trajet. La machine ou le matériau pourrait être endommagé si elle entrait en collision avec du matériau présent sur le trajet.
    Selon la situation, il est donc possible de désélectionner le mouvement d’un ou plusieurs axes afin d’éviter tout dommage.
    Pour ce faire, il suffit de sélectionner les boutons situés au-dessus de chaque axe ; ils passent du vert au rouge.

    Les boutons redeviennent automatiquement verts après avoir appuyé sur « Start Cycle ».

    Exécution de l’usinage

    L’opérateur peut créer une liste de fichiers PGM en ouvrant les fichiers souhaités à l’aide de la fonction de chargement prévue à cet effet.

    Avant de démarrer l’exécution, il est possible, si nécessaire, de modifier l’ordre des fichiers dans la liste et d’insérer des pauses entre les exécutions. Ces pauses permettent de gérer le processus de manière plus souple et, si nécessaire, de l’interrompre en toute sécurité.

    En réglant le mode d’exécution sur « Automatique », la fonction « Test ISO » est également disponible ; elle permet de vérifier la validité du programme ISO sélectionné avant son exécution réelle.

    Pour démarrer le cycle d’exécution, l’opérateur doit appuyer sur le bouton « Démarrer cycle ». Le premier programme ISO chargé et affiché dans la liste est alors exécuté.

    Les programmes ISO peuvent être exécutés selon deux modes :

    Le mode « Unique » permet d’interrompre l’exécution de la programmation à la fin de chaque fichier ISO. Il est nécessaire d’appuyer de nouveau sur le bouton « Démarrer cycle » pour exécuter le fichier suivant de la liste.

    Le mode « Suivant automatique » permet d’exécuter les fichiers ISO en séquence, sans intervention manuelle, jusqu’à la fin de la liste.

    Dans les deux modes, les pauses éventuellement insérées entre les fichiers permettent à l’opérateur d’interrompre le cycle à tout moment, assurant ainsi un contrôle continu de l’exécution.
