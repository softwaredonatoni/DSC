    Barre supérieure

    Paramètres
    Permet d’accéder aux paramètres du programme Parametrix.

    Paramètres outil
    Appuyer sur le bouton pour accéder à la page des paramètres de l’outil. Se reporter au chapitre « Configuration de l’outil » pour une description détaillée de la page des paramètres.

    Rotation automatique 0/ 90 degrés
    L’axe « C » est automatiquement déplacé à 0 ou 90 degrés lorsque le bouton est enfoncé.

    Mise en position de stationnement automatique
    Lorsque ce bouton est enfoncé, la machine déplace automatiquement les axes « X », « Y », « Z » et « C » en position zéro.
    Les déplacements sont effectués par la machine dans l’ordre suivant :
    (A) - Axe « Z » en position zéro absolu ;
    (B) - Axe « C » en position 0 absolu ;
    (C) - Axes « X » et « Y » simultanément en position zéro absolu ;

    ATTENTION !

    Pour effectuer la mise en position de stationnement automatique, certaines conditions de sécurité doivent être respectées :
    La position de l’axe « A » doit être à 0_.
    S’assurer que la zone de déplacement concernée par le positionnement (voir figure ci-contre) est libre.

    Zéro
    Effectue le référencement des axes (cette opération est nécessaire lors du démarrage de la machine ou lorsque les indicateurs rectangulaires sont rouges).
    Lorsque le cycle de référencement est terminé, les indicateurs deviennent gris.
    La phase de référencement prévoit le déplacement séquentiel des axes :

    1. Axe Z

    2. Axe A

    3. Axe C

    4. Axes X et Y simultanément

    5. Axe B (Option : tour contrôlé)

    REMARQUE

    Le référencement n’est autorisé que lorsque la clé codée est insérée dans le poste prévu à cet effet, repérable sur la console opérateur.

    Activation / Désactivation de l’eau interne
    Appuyer sur ce bouton pour activer l’eau à l’intérieur de l’outil.
    Le témoin au-dessus du bouton change de couleur : Vert = Activée ; Rouge = Désactivée.

    Activation / Désactivation de l’eau
    Appuyer sur ce bouton pour activer l’eau du circuit principal.
    Le témoin au-dessus du bouton change de couleur : Vert = Activée ; Rouge = Désactivée.

    Changement manuel d’outil
    Appuyer sur le bouton pour lancer la procédure de changement d’outil.

    Maintenance
    Appuyer sur ce bouton pour afficher une fenêtre contenant toutes les opérations de maintenance de la machine.
    Les opérations de maintenance à effectuer ainsi que celles qui sont dans la norme s’affichent.
    Si au moins une opération de maintenance l’exige.

    Aide
    Appuyer sur ce bouton modifie légèrement l’aspect graphique et le comportement de tous les boutons actuellement visibles. Il est alors possible d’appuyer sur n’importe quel bouton portant un petit point d’interrogation dans l’angle supérieur gauche pour afficher un bref message décrivant sa fonction. Pour quitter ce mode d’assistance, il suffit d’appuyer de nouveau sur le bouton « Aide ».

    Les éléments qui composent cette section de l’interface commune sont expliqués ci-dessous, en prenant comme référence le cas où les axes ont déjà été référencés.

    Cote réelle : indique la position de l’axe par rapport à l’origine active.

    Réinitialisation de l’axe
    Appuyer sur ce bouton pour définir le zéro de l’origine active à la position actuelle de l’axe correspondant (X, Y ou Z).
    La réinitialisation de l’axe ne peut être effectuée que sur des origines différentes de 0 (zéro).
    Pour utiliser l’origine en coordonnées outil (TCP), il est nécessaire d’avoir réglé les dimensions correctes de l’outil monté avant d’appuyer sur le bouton Réinitialisation de l’axe.

    Rotation automatique _90 degrés
    La position de l’axe « C » est augmentée de 90 degrés dans le sens horaire.
    Exemple : la machine se trouve à 12 degrés ; en appuyant sur le bouton « Rotation automatique _90 degrés », la machine se positionne à 102 degrés : 12 _ 90.

    Rotation automatique -90 degrés
    La position de l’axe « C » est diminuée de 90 degrés dans le sens antihoraire.
    Exemple : la machine se trouve à 102 degrés ; en appuyant sur le bouton « Rotation automatique -90 degrés », la machine se positionne à 12 degrés : 102 - 90.

    Commandes

    Ce panneau contient plusieurs boutons dont le fonctionnement est expliqué ci-dessous :

    MAN (Activer le déplacement manuel)
    Pour utiliser la machine en mode manuel, les broches doivent être correctement positionnées et certaines fonctions doivent être activées. Le bouton est prévu à cet effet.

    REMARQUE

    Lorsque le mode manuel est activé, le voyant situé à côté devient vert.

    Axe des ventouses
    Axe de référence sur lequel les ventouses sont montées.

    Seuil d’alarme
    Indique le seuil au-delà duquel l’alarme est activée et la rotation de la broche est bloquée.

    Origine sélectionnée

    La modification de ce champ déclenche la mise à jour des valeurs des Axes.
    Les valeurs d’Origine peuvent varier de 0 à 19 inclus.

    La vitesse des axes X et Y est commandée par leurs potentiomètres respectifs, tandis que les autres axes sont commandés par le potentiomètre interpolé.

    Ventouses

    Il est possible d’utiliser les ventouses en mode manuel pour déplacer des pièces d’une zone de travail à une autre.

    Boutons des ventouses

    Activation / désactivation des ventouses
    L’écran affiche le groupe de ventouses vu de dessus, réparti dans les différentes zones qui le composent. Appuyer sur la zone concernée pour en changer l’état.
    En vert, la zone est configurée pour créer le vide.
    En rouge, la zone est configurée pour le soufflage.

    VENTOUSES : MONTER - Stationnement des ventouses
    Appuyer sur le bouton rétracte les ventouses afin de les ramener dans la zone de repos/stationnement.

    VENTOUSES : DESCENDRE - Préparer les ventouses
    Appuyer sur le bouton fait descendre les ventouses de la zone de stationnement jusqu’à la butée. Il est important que les ventouses disposent de l’espace nécessaire pour sortir complètement.

    SOULEVER LA PIÈCE : RELÂCHER - Déchargement de la pièce
    Appuyer sur le bouton abaisse l’axe Z jusqu’à ce que le matériau entre en contact avec le plan de travail, arrête la pompe à vide et active le soufflage de toutes les ventouses pour détacher la pièce. Après l’écoulement d’un délai, l’axe est relevé jusqu’à la cote de sécurité.

    SOULEVER LA PIÈCE : DÉMARRER - Levage de la pièce
    Avec cette commande, les ventouses sont amenées au contact du matériau, la pompe à vide est activée dans les zones indiquées en vert et le soufflage dans les zones indiquées en rouge ; lorsque le vacuostat signale que le vide est établi, l’axe est relevé jusqu’à la position définie pour les déplacements.

    ATTENTION !

    Faire attention aux ventouses actives et utiliser la plus grande surface possible pour soulever la pièce.

    VIDE - Commande de la pompe à vide
    Ce bouton active et désactive la pompe à vide. L’indicateur signale si la pompe est activée (vert) ou désactivée (rouge).

    SOUFFLAGE - Commande de soufflage
    Ce bouton active ou désactive le soufflage des ventouses qui ne sont pas configurées pour le vide. L’indicateur signale si le soufflage est activé (vert) ou désactivé (rouge).

    Conditions de sécurité

    Faire particulièrement attention aux ventouses actives pendant le levage et s’assurer que les zones utilisées sont suffisantes pour soulever la pièce à manutentionner. Toujours utiliser la plus grande surface de vide disponible pour saisir la pièce et vérifier que le matériau ne présente aucun défaut ni aucune rupture susceptible de créer des dangers ou des problèmes de fonctionnement de la machine.
    Une fois la pompe à vide activée, sa désactivation n’est autorisée qu’au moyen des fonctions automatiques prévues à cet effet. L’appui sur le bouton de réinitialisation ou sur le bouton d’arrêt d’urgence n’a aucun effet sur la pompe à vide, qui continue de fonctionner. L’arrêt de la pompe peut être forcé à l’aide du bouton prévu à cet effet dans la page « Commandes supplémentaires ».
    Dans les procédures automatiques, avant de soulever la pièce, l’état du vide est contrôlé par un capteur dédié : si une valeur de vide suffisante n’est pas détectée, l’alarme « manque de vide » apparaît. La pompe reste active jusqu’à ce que le vacuostat détecte une valeur correcte, sauf si elle est désactivée depuis la page « Commandes supplémentaires ».

    ATTENTION !

    Une coupure de l’alimentation de la pompe à vide entraîne une perte rapide du vide et, par conséquent, la chute du matériau soulevé par les ventouses.

    Bouton comportant un lien vers le guide en ligne correspondant.

    Code d’identification du problème à l’origine de l’alarme.

    Description
    Brève description de l’erreur détectée.

    État atteint par l’alarme (ON / OFF).

    Nombre d’occurrences d’activation de l’alarme.

    Date et heure de la dernière activation de l’alarme.
