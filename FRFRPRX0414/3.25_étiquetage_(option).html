    DOC3.25 ÉTIQUETAGE (OPTION)

    Cette fonction permet à l’opérateur de générer des étiquettes pour les pièces avant d’appuyer sur le bouton PGM.

    Boutons

    Le bouton permettant d’accéder à la fonction d’étiquetage se trouve dans la barre inférieure de l’écran principal de Parametrix.

    Étiquetage
    Ouvre le panneau permettant de gérer l’étiquetage

    Il existe deux modes d’étiquetage distincts, décrits ci-dessous.

    Mode Étiquetage de base

    Le mode de base propose à l’opérateur trois modes d’étiquetage possibles dans le panneau correspondant.

    Étiquetage dans la zone de travail
    Après avoir sélectionné une pièce, l’opérateur appuie sur ce bouton pour appliquer l’étiquetage directement dans l’aperçu.

    Étiquetage depuis la liste des pièces
    Cliquer sur ce bouton permet de générer les étiquettes depuis la liste des pièces.

    Étiquetage avec saisie manuelle des informations
    Cliquer sur ce bouton permet de générer les étiquettes en saisissant manuellement les informations de la pièce.

    Étiquetage dans la zone de travail

    La sélection d’au moins une pièce dans l’aperçu visible à l’écran puis l’appui sur ce bouton déclenchent l’avertissement suivant :

    Étiquetage depuis la liste des pièces

    Ce mode permet de sélectionner les pièces pour lesquelles l’impression des étiquettes doit être appliquée.
    Un petit panneau semblable à celui illustré ci-dessous s’ouvre :

    Imprimer les étiquettes
    Lance la procédure de génération des étiquettes sélectionnées.

    Étiquetage avec saisie manuelle des informations

    Ce mode permet de gérer les informations des étiquettes et leurs propriétés supplémentaires.
    Un petit panneau semblable à celui illustré ci-dessous s’ouvre :

    Propriétés supplémentaires
    Permet d’accéder au panneau de modification des propriétés supplémentaires d’une pièce.

    Propriétés supplémentaires pour l’impression des étiquettes

    En fonction des propriétés supplémentaires correctement définies, celles-ci peuvent être gérées dans le panneau suivant.

    Les boutons suivants permettent à l’opérateur de gérer rapidement les propriétés supplémentaires :

    Copier les propriétés supplémentaires
    Permet à l’opérateur de copier toutes les valeurs des propriétés supplémentaires actuellement affichées.

    Coller les propriétés supplémentaires
    Permet à l’opérateur de coller dans les champs des propriétés supplémentaires les valeurs précédemment copiées.

    Mode Étiquetage avancé

    Comme le mode précédent, ce mode propose des boutons permettant d’effectuer l’Étiquetage dans la zone de travail et l’Étiquetage depuis la liste des pièces.

    La liste des pièces visible à gauche contient une seule occurrence de chaque pièce.
    Le reste de la fenêtre affiche un aperçu de l’étiquette actuellement sélectionnée.

    Dans la partie inférieure de ce panneau, les boutons suivants sont mis à la disposition de l’opérateur :

    Activer/Désactiver la sélection multiple
    L’activation de ce mode permet de sélectionner librement plusieurs éléments de la liste.
    Sa désactivation permet à l’opérateur de ne sélectionner qu’un seul élément à la fois.

    Sélectionner tous les éléments de la liste
    L’activation du bouton sélectionne tous les éléments de la liste, tandis que sa désactivation désélectionne tous les éléments à l’exception de celui actuellement sélectionné.

    Impression des étiquettes dans Ouvrir état

    Une fois le PGM généré, il est possible d’imprimer les étiquettes correspondantes en accédant à la section « Ouvrir état », située dans la partie inférieure droite de la fenêtre. À ce stade, les cotations sont automatiquement ajoutées au dessin.

    Appuyer sur le bouton « Imprimer les étiquettes » affiche le panneau suivant permettant de sélectionner les étiquettes à imprimer.

    Le côté gauche du panneau contient toutes les pièces présentes dans l’état sélectionné, y compris les occurrences répétées.
    Le reste de la fenêtre affiche un aperçu de l’étiquette actuellement sélectionnée.

    Il est recommandé d’utiliser un format d’étiquette de dimensions appropriées (p. ex. 20 cm x 10 cm) afin de garantir une bonne lisibilité du dessin coté.

    REMARQUE

    La configuration de l’étiquette (format et contenu) est effectuée lors de l’installation ; elle est unique et ne peut pas être modifiée par l’opérateur.
