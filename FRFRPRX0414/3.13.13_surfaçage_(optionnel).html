    DOC3.13.13 SURFAÇAGE (OPTIONNEL)

    Cette fonction permet à l’opérateur d’effectuer un surfaçage sur la pièce.

    Paramètres

    Allongement de passe

    Chaque coupe générée par cet usinage est prolongée, aussi bien en tête qu’en queue, de la longueur indiquée par ce paramètre.

    Exécution de l’usinage

    À partir de l’épaisseur de dalle définie dans les paramètres du matériau, afin d’atteindre l’épaisseur cible définie dans les paramètres d’usinage, la pièce est usinée de la manière suivante :

    1. Tout d’abord, des coupes parallèles sont exécutées de gauche à droite à une distance définie dans les paramètres et avec les paramètres de coupe linéaire.

    2. Ensuite, des coupes sont effectuées le long de l’axe Y afin de créer un quadrillage, toujours avec les paramètres de coupe linéaire.

    ATTENTION !

    L’épaisseur initiale de la dalle doit être définie comme épaisseur du matériau (un palpage peut ensuite être ajouté pour une plus grande précision).
    L’épaisseur cible est définie dans les paramètres d’usinage (et se réfère à la cote du plan de travail).

    REMARQUE

    L’usinage suivant peut également être exécuté sur des pièces commerciales.

    Paramètres d’usinage de la dalle

    L’opérateur peut modifier les paramètres liés au surfaçage depuis le panneau des paramètres d’usinage de la dalle.

    Paramètres coupes de surfaçage

    Description des paramètres

    Distance entre passes horizontales
    Représente la distance entre deux passes parallèles dans la direction horizontale.
    Le bouton permet de décider si les passes doivent être exécutées du haut vers le bas ou inversement.

    Distance entre passes verticales
    Représente la distance entre deux passes parallèles dans la direction verticale.
    Le bouton permet de décider si les passes doivent être exécutées de gauche à droite ou inversement.

    Cote de surfaçage
    Définit l’épaisseur que le matériau doit avoir après le surfaçage.

    Tourner outil de 90 degrés
    Si cette option est activée, le surfaçage est exécuté avec l’axe A à 90_.
