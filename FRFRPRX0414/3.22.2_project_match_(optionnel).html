    DOC3.22.2 PROJECT MATCH (OPTIONNEL)

    Project Match est conçu pour la planification de projets de grande envergure.
    Il permet de gérer plusieurs dalles simultanément afin de programmer tous les usinages nécessaires au projet avec une vue d’ensemble.

    Panneau de commande

    En appuyant sur le bouton de la barre inférieure, un panneau s’ouvre et permet de naviguer dans la fonction.

    Pour accéder à Project Match, les boutons suivants sont affichés.

    Nouveau projet
    Permet de créer un nouveau projet.

    Charger projet
    Permet de charger un projet existant.

    Afficher aperçu
    Permet d’ouvrir un écran affichant l’aperçu de l’ensemble du projet.

    À l’intérieur d’un projet, le panneau dispose en revanche de boutons différents.

    Enregistrer zone de travail
    Permet d’enregistrer dans le projet les modifications apportées à la zone de travail sélectionnée.

    Enregistrer toutes les zones de travail
    Enregistre simultanément les modifications apportées à toutes les zones de travail du projet.

    Enregistrer et fermer projet
    Permet de quitter le projet Book Match en laissant le choix d’enregistrer ou non.

    REMARQUE

    Le panneau peut être déplacé en le faisant glisser sur l’écran.

    Nouveau projet

    En appuyant sur le bouton, une fenêtre s’ouvre et permet de créer un projet Book Match multi-dalles.

    Nom

    Nom sous lequel enregistrer le projet.

    Lignes

    Permet de définir le nombre de lignes du projet.

    Colonnes

    Permet de définir le nombre de colonnes du projet.

    Dalles

    Nombre total de dalles que le projet peut contenir.

    Dimensions zone de travail
    Permet de choisir les dimensions, en largeur et en hauteur, des zones de travail composant le projet.

    Charger un projet

    Cet écran affiche les projets enregistrés pouvant être ouverts.

    Fermer un projet

    Une fenêtre permettant de fermer le projet s’ouvre.

    Pour changer le mode de fermeture, utiliser le bouton :

    Mode de fermeture
    Permet de choisir de fermer le projet en enregistrant les modifications apportées ou sans les enregistrer.

    Projet

    Un projet est structuré en lignes et colonnes pouvant contenir les dalles.
    Dans cet écran, il est possible d’insérer des dalles dans le projet, de définir leurs périmètres et de positionner les pièces.
    L’opérateur peut déplacer librement les pièces d’une dalle à l’autre.

    Zones de travail

    Les zones de travail sont représentées par les cellules du projet.
    Chaque zone permet de gérer l’usinage d’une dalle en définissant un périmètre et en y insérant des pièces.

    Certaines informations sont affichées dans l’angle supérieur gauche de chaque zone de travail.

    Dalle

    Dimensions de la dalle (largeur x hauteur x épaisseur).

    Pièces

    Nombre de pièces positionnées à l’intérieur du périmètre.

    Surface dalles

    Surface du périmètre de la dalle.

    Surface pièces

    Surface des pièces positionnées à l’intérieur du périmètre.

    Pourcentage

    Pourcentage de la surface du périmètre occupée par les pièces.

    Coupes

    Longueur totale des coupes à exécuter sur la dalle.

    Minutes

    Estimation du temps, en minutes, nécessaire pour exécuter le programme de coupe sur la dalle.

    Paramètres projet

    Dans le panneau des paramètres utilisateur, la section « Dalles » permet de modifier certaines propriétés du projet actuellement ouvert.

    Lignes

    L’opérateur peut modifier le nombre de lignes du projet courant.

    Colonnes

    L’opérateur peut modifier le nombre de colonnes du projet courant.

    Totale

    Nombre total de zones composant le projet courant.

    Dalles

    Nombre de dalles insérées dans le projet courant.

    Pièces

    Nombre de pièces insérées dans le projet courant.

    Raccourcis
    Permet d’accéder à l’écran des raccourcis de Project Match.

    Raccourcis clavier

    Project Match dispose de commandes clavier permettant d’effectuer facilement des actions de routine, utiles pour simplifier le travail au bureau.

    Zoom sur projet

    Élargit la vue à l’ensemble du projet.

    Zoom sur zone

    Resserre la vue sur la zone de travail sélectionnée.

    Mode panoramique

    Permet de déplacer la vue en interagissant avec l’écran.

    Naviguer entre les zones

    Permet de changer la zone sélectionnée à l’aide des touches.

    Déplacer pièce

    Déplace la pièce sélectionnée dans les quatre directions.

    Tourner pièce

    Fait tourner la pièce sélectionnée respectivement dans le sens antihoraire et horaire.

    Tourner pièce de _90

    Fait tourner la pièce de 90 degrés dans le sens horaire.

    Tout sélectionner

    Si une zone de travail est sélectionnée, cette commande sélectionne toutes les pièces qu’elle contient.
    Sinon, elle sélectionne toutes les pièces du projet.

    Activer sélection multiple

    Active la sélection multiple de pièces/zones de travail.

    Annuler

    Annule la dernière opération exécutée.

    Copier dalle

    Copie la dalle dans la zone de travail sélectionnée.

    Couper dalle

    Coupe la dalle dans la zone de travail sélectionnée.

    Coller dalle

    Colle la dalle dans la zone de travail sélectionnée.

    Désélectionner

    Permet de désélectionner toutes les pièces/zones de travail.

    Confirmer périmètre ou photo

    À utiliser pour confirmer le périmètre/la photo

    Sélection suivante

    Sélectionne la pièce suivante dans la zone de travail sélectionnée.

    Aimant on/off

    Active/désactive l’aimantation des pièces.

    Commandes rapides

    Le bouton droit de la souris permet d’accéder à la fenêtre des commandes rapides.
    Les fonctions proposées changent selon que l’on clique à l’intérieur d’une zone de travail ou à l’extérieur de toutes les zones.

    Commandes projet

    Enregistrer usinages
    Permet d’enregistrer les modifications apportées à toutes les zones de travail.

    Rapport
    Permet d’enregistrer un fichier PDF contenant un rapport du projet.

    Nesting
    Permet d’exécuter le Nesting des pièces sur toutes les dalles du projet.

    Commandes zone de travail

    Verrouiller/Déverrouiller
    Si une zone de travail est verrouillée, il n’est pas possible de déplacer les pièces qu’elle contient ni d’en insérer de nouvelles.
    Il n’est pas non plus possible de modifier son périmètre ou de choisir d’autres photos.
    Il est nécessaire de la déverrouiller pour rétablir toutes les opérations.

    Couper
    Amène l’utilisateur à l’écran de gestion et d’optimisation des coupes de la dalle sélectionnée afin de créer le programme ISO.

    Enregistrer
    Permet d’enregistrer les modifications appliquées à la zone de travail individuelle.

    Rapport
    Permet d’enregistrer un fichier PDF contenant un rapport de la zone de travail sélectionnée.

    Importer fichier
    Charge dans le projet un fichier de sauvegarde de l’état d’une dalle.

    Nesting
    Exécute le Nesting des pièces dans la zone de travail sélectionnée.

    Nesting

    Lorsque la fonction de Nesting est activée sur l’ensemble du projet, deux modes sont disponibles.

    Insérer les pièces dans les dalles actuelles

    Insère les pièces sur les dalles déjà présentes dans le projet afin d’optimiser l’espace disponible

    Insérer dalles et pièces jusqu’à épuisement

    Des dalles sur lesquelles appliquer le Nesting sont créées jusqu’à épuisement de toutes les pièces de la liste.
    Les dimensions des dalles sont identiques à celles de la première dalle définie.
    Cette fonction donne une indication du nombre de dalles qui pourraient être nécessaires pour terminer le projet, sachant que les dalles à couper auront la même forme.

    Pour utiliser le Nesting jusqu’à épuisement des pièces, il est nécessaire de créer un périmètre afin d’indiquer au programme les dimensions des dalles qui seront utilisées.
    Des dalles de même dimension sont créées jusqu’à ce que toutes les pièces de la liste aient été insérées avec le Nesting.

    Rapport

    Enregistre un rapport au format PDF dans le dossier dédié au projet/à la zone de travail courante.

    Aperçu

    Cette fenêtre permet d’afficher une représentation globale du projet en temps réel.
    Il est possible d’insérer les pièces dans la zone de travail sélectionnée en cliquant à l’intérieur de leur aperçu.
    De plus, en faisant glisser l’arrière-plan d’une pièce, l’opérateur peut modifier la position de la pièce sur le plan de travail.

    Boutons

    Les boutons suivants se trouvent à gauche.

    Déplacer les pièces
    Permet de déplacer les pièces composant l’aperçu.
    Les boutons de la barre inférieure de la fenêtre sont affichés.

    Déplacer la vue
    Permet de déplacer la vue de l’aperçu avec toutes les pièces.

    Les boutons suivants se trouvent à droite.

    Ouvrir rendu
    Ouvre le dossier dans lequel sont enregistrés les rendus des projets.

    Personnaliser aperçu
    Ouvre un panneau permettant de personnaliser les couleurs des entités de l’aperçu.

    Rétablir position pièces
    Rétablit les pièces déplacées à leur position d’origine.

    Rétablir configuration projet
    Rétablit la configuration du projet.

    Enregistrer rendu
    Ouvre un panneau permettant d’enregistrer le rendu du projet.

    Planification d’un projet

    Créer un nouveau projet

    L’opérateur crée un nouveau projet en indiquant son nom, le nombre de lignes et de colonnes qui le composent, en se rappelant que chaque cellule correspond à une dalle, ainsi que les dimensions des cellules. Après confirmation, l’écran suivant s’affiche :

    Ajouter les dalles

    Insérer ensuite les dalles dans les zones de travail. Pour ce faire, sélectionner une zone, charger une photo depuis un fichier et choisir le périmètre.

    Importer les pièces

    À ce stade, importer les pièces à couper. Il est possible de charger aussi bien des fichiers DXF que des pièces standard. Le nombre de fichiers pouvant être chargés n’est pas limité.

    Ouvrir aperçu

    Lorsque la liste contient des pièces, il est possible d’ouvrir la fenêtre d’aperçu du projet.
    Celle-ci affiche toutes les pièces importées.

    Insérer les pièces dans les dalles

    Pour insérer les pièces dans les dalles, utiliser la méthode classique via la liste des pièces ou sélectionner l’intérieur des zones de pièces visibles dans l’aperçu.
    Elles sont alors insérées sur la dalle de la zone de travail sélectionnée.
    En faisant glisser une pièce depuis l’aperçu, elle se déplace également sur la dalle afin de choisir la meilleure partie de la dalle pour faire coïncider les veinages entre les différentes pièces. L’opération inverse est également possible : faire glisser la pièce depuis la dalle et vérifier dans l’aperçu si les veinages coïncident ou non selon sa nouvelle position.
