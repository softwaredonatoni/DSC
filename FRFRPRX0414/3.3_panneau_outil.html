    DOC3.3 PANNEAU OUTIL

    L’écran suivant permet à l’opérateur de gérer les outils de la machine.

    Sélection du type d’outil

    Chaque type d’outil possède un outil sélectionné, comme le montre l’image d’exemple suivante :

    Disque
    Liste des disques pouvant être montés sur la broche principale de la machine.
    « Disque 400 » de diamètre 400.0 mm est actuellement installé.

    Tools
    Liste des outils (fraises et forets carottiers) pouvant être montés sur la broche secondaire de la machine.
    « Fraise 26 » de diamètre 26.0 mm est actuellement installée.

    L’arrière-plan de la catégorie « Disque » apparaît en bleu clair car il s’agit de la catégorie d’outils actuellement sélectionnée.
    Il suffit de cliquer sur le rectangle du type d’outil souhaité pour mettre à jour la liste des outils située en dessous avec ceux disponibles pour ce type.
    À la suite du changement de type d’outil, l’outil est automatiquement sélectionné comme indiqué dans l’image d’exemple précédente.

    Liste des outils présents pour le type d’outil sélectionné

    La liste d’outils utilisée comme exemple dans l’image suivante comprend quatre disques : « Disque 400 », « Disque 625 », « Disque 2755 » et « Disque 325 ».
    Le premier disque de la liste est celui actuellement monté sur la machine ; cela est indiqué par l’arrière-plan vert clair et la coche verte.
    Dans la section de droite, les paramètres relatifs à l’outil sélectionné sont affichés.

    Éléments de la liste

    Type d’outil
    Représente le type de l’outil (disque, fraise, foret carottier).

    Informations principales de l’outil
    Les principales informations de l’outil sont affichées : nom (en haut) et diamètre (en bas).

    Forcer l’outil
    Permet à l’opérateur d’indiquer au programme quel outil est actuellement monté sur la machine.
    Utilisé lorsque l’outil a été changé manuellement.

    Filtre de recherche

    Dans la partie inférieure de la liste des outils se trouve une barre de recherche composée des éléments suivants :

    Les éléments composant le filtre de recherche sont décrits ci-dessous :

    Bouton de recherche par nom d’outil
    Si ce bouton est enfoncé, le mode de recherche par nom d’outil est activé et le bouton de recherche par diamètre est désactivé.

    Bouton de recherche par diamètre d’outil
    Si ce bouton est enfoncé, le mode de recherche par diamètre est activé et le bouton de recherche par nom d’outil est désactivé

    Bouton d’annulation du filtre appliqué
    Il ne peut être sélectionné que si un filtre a déjà été appliqué ; appuyer dessus vide le texte de la barre de recherche et rétablit l’affichage de tous les outils du type actuellement sélectionné.

    Barre inférieure

    La barre inférieure de la liste des outils propose des fonctions permettant d’ajouter et de supprimer des outils de la liste.

    Ajouter un outil
    Ce bouton permet de créer de nouveaux outils ; une fenêtre dédiée, illustrée ci-dessous, s’ouvre.

    Supprimer l’outil
    Ce bouton permet de supprimer l’outil sélectionné.

    REMARQUE

    Il n’est pas possible de supprimer de la liste l’outil actuellement monté sur la machine (indiqué par la coche verte).

    Dupliquer l’outil
    Permet de créer un nouvel outil en dupliquant les paramètres de l’outil actuellement sélectionné.
    Le nouvel outil porte le même nom que le précédent, suivi du mot « Copy ».

    Ajouter un outil

    Cette fenêtre permet de créer un nouvel outil. Les paramètres requis varient selon le type d’outil à créer.
    L’image suivante montre la fenêtre de création d’un nouvel outil pour chaque type disponible :

    Disque

    Fraise

    Foret carottier

    Liste des paramètres de l’outil sélectionné

    Cette liste contient tous les paramètres relatifs à l’outil actuellement sélectionné.
    Toute modification de la sélection de l’outil permet à l’opérateur d’afficher les valeurs mises à jour de l’outil souhaité et, si nécessaire, de modifier chaque valeur.
    La liste des paramètres et les valeurs correspondantes sont également mises à jour lorsqu’un autre type d’outil (Disque / Tools) est sélectionné, en affichant les valeurs de l’outil sélectionné pour chaque catégorie.

    Paramètres du disque

    Les paramètres associés à un disque sont indiqués ci-dessous.

    Nom
    Nom de l’outil auquel sont associés les paramètres actuellement visibles.

    Diamètre
    Mesure du diamètre maximal de l’outil.

    Épaisseur du disque
    Mesure de l’épaisseur du disque, à mesurer sur les dents.

    CRF - Centre de rotation de la bride
    Distance entre le bord intérieur de la dent du disque et l’axe de rotation C.

    Cote de dégagement
    Cote de sécurité prise en compte par la machine pour effectuer les positionnements lors de l’exécution de programmes automatiques.

    RPM
    Indique la vitesse maximale de rotation de la broche en tours par minute.
    Cette valeur correspond à 100% du potentiomètre de commande du disque.

    Eau interne
    Permet d’activer ou de désactiver l’utilisation de l’eau interne pendant les usinages.

    REMARQUE

    Pour les outils de type disque, elle est toujours désactivée.

    Eau externe
    Permet d’activer ou de désactiver l’utilisation de l’eau interne pendant les usinages.

    REMARQUE

    Pour les outils de type disque, elle est toujours activée.

    Vitesse de rotation du disque

    Le bouton suivant se trouve à droite du paramètre RPM :

    Informations RPM
    Permet d’afficher le tableau de conversion de la vitesse en RPM.

    Cette fenêtre affiche un tableau contenant les conversions de vitesse de rotation en RPM selon le diamètre du disque sélectionné.
    Les valeurs recommandées pour le disque sélectionné sont mises en évidence en vert.

    Paramètres de fraise et de foret carottier

    Les paramètres relatifs aux outils tels que les fraises et les forets carottiers sont indiqués ci-dessous.

    Longueur de l’outil
    Indique la distance entre la pointe de l’outil et un point pris comme référence.

    Palpage de l’outil

    Si la machine est équipée du dispositif optionnel de palpage de l’outil, la procédure peut être lancée depuis ce panneau.
    Permet de lancer un cycle permettant de calculer le diamètre, dans le cas d’un disque, ou la longueur, pour les fraises et les forets carottiers.

    Boutons

    Dans la partie droite du panneau se trouve l’un des boutons suivants.

    Démarrer le palpage du disque
    Permet de lancer le cycle de palpage pour mesurer le diamètre du disque monté.

    Démarrer le palpage de l’outil secondaire
    Permet de lancer le cycle de palpage pour mesurer la longueur de l’outil secondaire monté.

    REMARQUE

    Le bouton de palpage du disque n’est disponible que dans la section « Disque » du panneau.
    Le bouton de palpage de l’outil secondaire n’est disponible que dans la section « Tools » du panneau.

    Procédure

    Pour mesurer le diamètre du disque ou la longueur du foret carottier/de la fraise actuellement monté sur la machine, appuyer sur le bouton correspondant dans la section droite du panneau.
    À la fin du cycle, le programme met automatiquement à jour la donnée correspondant à la mesure de l’outil palpé.

    Autres boutons

    Le bouton suivant se trouve en bas à gauche de l’écran :

    Passer au panneau « Paramètres d’usinage de la dalle »
    Appuyer sur ce bouton permet de passer du « Panneau Outil » au panneau « Paramètres Dalle ».
