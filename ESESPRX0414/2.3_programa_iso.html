    DOC2.3 PROGRAMA ISO

    La página de programación de archivos ISO permite gestionar e iniciar mecanizados mediante archivos .pgm creados previamente con programas CAD-CAM.

    Lista

    La lista del programa ISO, inicialmente vacía, contiene todos los programas ISO que pueden ejecutarse secuencialmente.

    Botones

    Hay una serie de botones para gestionar la lista.

    Abrir archivo
    Abre el explorador de archivos para crear una lista de archivos que deben ejecutarse.

    Nueva lista ISO
    Añade un archivo a la lista de archivos que deben ejecutarse.

    Añadir pausa
    Añade una pausa a la lista de archivos que deben ejecutarse.

    Eliminar elemento seleccionado
    Elimina un archivo de la lista de archivos que deben ejecutarse.

    Vaciar lista
    Elimina toda la lista de archivos que deben ejecutarse.

    Mover elemento seleccionado hacia arriba
    Desplaza hacia arriba el archivo ISO seleccionado dentro de la lista de archivos que deben ejecutarse.

    Mover elemento seleccionado hacia abajo
    Desplaza hacia abajo el archivo ISO seleccionado dentro de la lista de archivos que deben ejecutarse.

    En la parte inferior se encuentran además los dos botones relativos a los modos de ejecución de los programas:

    Manual / automático
    Define si el estado de la máquina es manual o automático.

    Individual / siguiente automático
    Define si el siguiente programa se iniciará automáticamente o no.

    Esta ventana se divide en los siguientes componentes:

    • Lista de archivos seleccionados

    Botones centrales, situados entre la lista «ARCHIVOS» y la lista «ARCHIVOS SELECCIONADOS»

    Seleccionar elemento
    Mueve el elemento seleccionado de la lista ARCHIVOS a la lista ARCHIVOS SELECCIONADOS.

    Eliminar elemento
    Elimina el elemento seleccionado de la lista ARCHIVOS SELECCIONADOS.

    Insertar pausa
    Añade una pausa en la posición posterior al elemento seleccionado en ARCHIVOS SELECCIONADOS.

    Mover elemento seleccionado hacia arriba
    Desplaza el elemento seleccionado una posición hacia arriba en la lista ARCHIVOS SELECCIONADOS.

    Mover elemento seleccionado hacia abajo
    Desplaza el elemento seleccionado una posición hacia abajo en la lista ARCHIVOS SELECCIONADOS.

    Borrar filtro de búsqueda
    Vacía la barra de texto situada a la izquierda de este botón.

    Ordenar por última modificación
    Ordena los archivos de ARCHIVOS según las modificaciones más recientes (primera imagen) o menos recientes (segunda imagen).

    Orden alfabético
    Ordena los archivos de ARCHIVOS en orden alfabético o en orden alfabético inverso.

    Visualizar archivos de la memoria USB
    Muestra todos los archivos con extensión .pgm presentes en la memoria USB.

    Visualizar carpeta ISO
    Muestra el contenido de la carpeta ISO.

    Visualizar contenidos
    Muestra las unidades presentes en el ordenador y la carpeta Escritorio.

    Eliminar archivo
    Activa el modo de eliminación de archivos, que permite eliminar archivos .pgm de ARCHIVOS.

    Activar/Desactivar copia
    Permite activar/desactivar la función de copia (copia el archivo seleccionado en la carpeta ISO).

    Código del programa ISO

    El código del programa ISO en ejecución se muestra en esta ventana:

    Botones

    En esta sección del programa ISO se encuentran los siguientes botones y sus respectivas funciones.

    Temporizador y Reset
    Indica el tiempo de ejecución de todo el archivo .pgm.
    Al pulsar el botón se restablece el temporizador

    Vista previa ISO
    Activa o desactiva la visualización de la vista previa ISO.

    Búsqueda de bloque
    Este botón solo se mostrará después de cargar al menos un programa en la lista; permite buscar un bloque por línea.

    Búsqueda de bloque por línea
    Este botón sustituirá al botón «Búsqueda de bloque» después de pulsar este último.
    El operador puede buscar una línea de código específica en una pequeña ventana que se mostrará en la pantalla.

    Tras introducir un número en el campo «Número de línea» y pulsar el botón «Ir a», la visualización del código del programa ISO se desplazará hasta la línea deseada o hasta la última línea disponible si el número introducido supera el número de líneas del programa ISO seleccionado.

    Es posible finalizar la búsqueda de un bloque y restablecer la visibilidad del botón «Búsqueda de bloque» pulsando el botón Cerrar:

    Función Dry Run (Activada / desactivada)
    Al seleccionar este modo de trabajo, es posible realizar un mecanizado a la velocidad máxima de la máquina.

    ¡ATENCIÓN!

    El uso de esta función obliga a NO utilizar NINGÚN tipo de material durante el mecanizado, ya que durante la ejecución no se respetan las velocidades del programa ISO; el control numérico ejecutará todo el programa a la velocidad nominal máxima alcanzable con ejes interpolados.

    Función Test ISO (Activada / desactivada)
    Con esta opción es posible probar el archivo cargado para comprobar que no contenga errores de sintaxis.
    Pulse el botón «START CICLO» y la máquina ejecutará virtualmente todas las líneas de código sin mover los ejes.

    Panel de ventosas
    Acceso al panel para gestionar las ventosas.

    Guardar
    Al pulsar el botón aparece un teclado que permite modificar el archivo .pgm cargado antes de ejecutarlo.

    Búsqueda de bloque

    Durante la ejecución de archivos (.pgm), la función de búsqueda de bloque puede resultar útil para reposicionar la herramienta en el punto donde la máquina haya interrumpido la ejecución del programa, por ejemplo si la herramienta se bloquea dentro del material o por otros tipos de bloqueo.

    Una vez pulsado el botón, es posible buscar la línea desde la que se desea continuar/iniciar el mecanizado mediante el número de línea, pulsando el botón «Búsqueda de bloque por línea», o desplazándose por el archivo con la barra situada al lado y seleccionando la línea deseada.
    Después de seleccionar el punto del programa desde el que la máquina reanudará el trabajo interrumpido, pulse el botón «Start ciclo»; la máquina volverá a calcular todas las líneas de código del archivo .pgm sin efectuar ningún movimiento. La velocidad de esta operación depende del número de líneas de código que deban generarse sin realizar ningún movimiento.

    Una vez finalizado el recálculo, la máquina activa una pausa automática y solicita volver a pulsar el botón «Start ciclo» para iniciar el mecanizado.
    Antes de iniciar el ciclo se recomienda tener en cuenta el posicionamiento inicial de la máquina, que implica todos los ejes simultáneamente.
    Esto es necesario porque la máquina se desplaza desde la posición actual hasta el punto en el que empieza a trabajar buscando la trayectoria más corta y, para ello, todos los ejes se mueven para llegar exactamente a dicho punto.


    Esto significa, por ejemplo, que el eje Z no baja una vez alcanzado el punto inicial, sino que desciende gradualmente durante el recorrido. Esto podría dañar la máquina o el material si la máquina colisionara con material situado en medio de la trayectoria.
    Por tanto, en función de la situación, es posible deseleccionar el movimiento de uno o varios ejes para evitar daños.
    Para ello, basta con seleccionar los botones situados encima de cada eje, que pasarán de verde a rojo.

    Los botones volverán automáticamente a verde al pulsar «Start Ciclo».

    Ejecución del mecanizado

    El operador puede crear una lista de archivos PGM abriendo los archivos deseados mediante la función de carga correspondiente.

    Antes de iniciar la ejecución, es posible —opcionalmente— modificar el orden de los archivos en la lista e insertar pausas entre una ejecución y la siguiente. Estas pausas permiten gestionar el proceso con mayor flexibilidad y, si es necesario, interrumpirlo de forma segura.

    Al configurar el modo de ejecución como «Automático», también está disponible la función «Test ISO», útil para comprobar la corrección del programa ISO seleccionado antes de la ejecución real.

    Para iniciar el ciclo de ejecución, el operador debe pulsar el botón «Iniciar ciclo». De este modo se ejecutará el primer programa ISO cargado y mostrado en la lista.

    Los programas ISO pueden ejecutarse según dos modos operativos:

    El modo «Individual» permite interrumpir la ejecución de la programación al finalizar cada archivo ISO. Es necesario volver a pulsar el botón «Iniciar ciclo» para proceder con la ejecución del siguiente archivo de la lista.

    El modo «Siguiente automático» permite ejecutar los archivos ISO secuencialmente, sin intervención manual, hasta el final de la lista.

    En ambos modos, las pausas insertadas entre los archivos permiten al operador interrumpir el ciclo en cualquier momento, garantizando así un control continuo de la ejecución.
