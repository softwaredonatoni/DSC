General information

The information contained in this document applies only to the software versions indicated on the title page.
Some functions provided by the product may not be described in this documentation; in such cases, Donatoni Macchine is not obliged to guarantee these functions or preserve them in future versions.

Purpose of the manual

This manual provides the operating instructions required for a thorough understanding of the DContour program and useful information for troubleshooting malfunctions.

Machine technical documentation Operational document

DOC2 DCONTOUR

The system has been designed to make it easier for the operator to use and manage the machine. The software allows you to:

  • Control the machine in Manual mode

  • Send commands/instructions to be executed by the machine

  • Load and execute working files

  • Manage the tool magazines

  • Monitor machining execution on screen

  • View statistics relating to the machine and the work it has performed

Top section

Top bar

The top bar of the application displays active warning and error messages. The operator can access the Alarms page by pressing the messages.

Time
Indicates the current time.

Message
Icon indicating the presence of a message.

Alarm
Icon indicating the presence of an alarm.

Error
Icon indicating the presence of an error.

Machine operating status

The operating status of the machine is visible at the top of every page of the application.
The logo always remains white, while the background can change color according to the operating status of the machine.

The possible operating statuses are listed below:

Standby
No machining operation is running and the machine has detected no errors.

Machining
The machine is operating correctly and is executing a working file.

Error
The machine sensors have detected errors that prevent operation.

Warning
Indicates that there are anomalies that need to be checked.

Side menu

The side menu is located on the left and allows navigation between the different program pages.

Menu
Allows the side bar to be expanded and collapsed. When the menu is expanded, the page names are visible.

ISO
Main page of the application. From this page, the machine can be managed in Manual/MDI/Automatic mode.

Tools
Tool magazine management page.

Alarms
Page displaying active warnings and errors on the machine and their history.

Origins
Page where the machine origins can be viewed and managed.

Statistics
Page for viewing machine and machining statistics.

Tools
Page for viewing and managing advanced machine tools.

CadCam
Allows third-party CadCam software to be opened for creating working files.

Machine settings
Allows access to the system parameters page.

Bottom bar

On the right side of the bottom section of each screen, except on the “Machine settings” page, there are utility buttons.

Version
Indicates the current software version.

Remote Assistance
Opens a panel for requesting remote assistance from a Donatoni technician.

Minimize
Allows the program window to be hidden by minimizing it.

Shutdown
Allows the application to be closed or restarted. Allows the computer to be shut down or restarted.

Remote Assistance

Clicking the remote assistance button in the bottom bar opens a panel containing the ID and Password to provide to Donatoni technical support when required to allow remote connection to the machine.

NOTE

The remote assistance icon and the panel background will be green if the system is online and ready for connection, and red otherwise.

ID
Field indicating the ID of the remote assistance session.

Password
Field indicating the password of the remote assistance session.

Copy as image
Allows an image of the remote assistance panel to be copied to the clipboard.

Copy as text
Allows text containing the ID and Password for the connection to be copied to the clipboard.

Reload
Allows remote assistance to be reloaded in the event of a malfunction.

Close
Allows the remote assistance panel to be closed.

Application/Computer Shutdown/Restart

Clicking the shutdown button in the bottom bar opens a window where you can choose whether to close or restart the application or the computer.

DOC2.1.1 MANUAL MODE

In this mode, the machine can be moved manually.

Axis display

The upper area displays the absolute and relative machine positions and allows machine movement to be controlled.

Positive axis movement
Moves the machine in the POSITIVE direction along the selected axis. The movement depends on the active JOG mode.

Negative axis movement
Moves the machine in the NEGATIVE direction along the selected axis. The movement depends on the active JOG mode.

JOG mode

This central panel allows you to select the increment for manual axis movement and also enable the relative axis position.

Continuous JOG
Allows continuous movements to be performed.

JOG 1
Allows movements of 1 mm for each JOG pulse.

JOG 0.1
Allows movements of 0.1 mm for each JOG pulse.

JOG 0.01
Allows movements of 0.01 mm for each JOG pulse.

JOG 0.001
Allows movements of 0.001 mm for each JOG pulse.

Relative axis position
Enables display of the relative axis coordinates.

NOTE

When this function is enabled, the machine center coordinates and the coordinates relative to the position of the machine at the moment the function was enabled are displayed.

Commands

The following commands are available in Manual mode:

Rapid mode
Allows the machine to move more quickly in JOG mode.

Remote Control enable
Enables use of the Remote Control.

Vacuum pump
Turns the vacuum pump on or off.

External water enable
Turns the external spindle water on or off.

Internal water enable
Turns the internal spindle water on or off.

T-axis inclination (Optional)
Allows the head axis inclination to be controlled and displayed for adjustment.

Lower telescopic devices
Allows the telescopic devices to be lowered.

Raise telescopic devices
Allows the telescopic devices to be raised.

Head inclination commands (Optional)

Negative axis inclination
Tilts the head T axis in the negative direction.

No axis inclination
Moves the T axis to the 0_ position; the spindle direction is therefore perpendicular to the worktable.

Positive axis inclination
Tilts the head T axis in the positive direction.

Current inclination display
Displays the current T-axis inclination in degrees.

DOC2.1.3 AUTOMATIC MODE

In this mode, automatic cycles can be executed and working files can be loaded for automatic execution.

Axis display

The machine center position and the distances to travel to reach the target position are always displayed at the top of the page, organized by individual axis.

ISO control

The large panel in the lower-left area of this page allows a working file to be loaded and executed, edited, and its progress displayed.

Select working file
Allows a file to be selected for execution.

Edit working file
Enters file editing mode, where the ISO code can be edited directly. The file must then be saved to exit editing mode.

Change execution mode
Allows the ISO code execution mode to be changed.

Cutting preview
Enables display of the cutting preview.

Workpiece probing
Enables display of the summary table of completed probing operations.

List of machining operations with tools
Enables display of the list of machining operations to be performed, with the corresponding tools.

Laser projector display (Optional)
Allows the laser projection to be displayed and the layer display to be managed.

Cutting preview

Completed machining operations are highlighted in green, while operations in progress are highlighted in yellow. The instruction currently being executed is highlighted within the ISO code.

Workpiece probing

During execution of a working file, probing operations can be performed on the workpiece; the results are saved in a summary table.

List of machining operations with tools

Displays the list of machining operations that will be performed during the work cycle.

Edit machining operations

Allows individual machining operations to be enabled/disabled.

Manual working file editing
Allows the working file to be edited manually.

Save working file
The working file is overwritten with the changes made by the operator.

Enable/disable machining operation
Allows the individual machining operation to be enabled/disabled.

Laser projection display (Optional)

Allows you to choose the layers to display with the laser; they can be activated from the list on the right. A DXF containing the drawing to be projected with the laser can also be opened manually.

Laser commands (Optional)

The projection laser is managed using these commands.

Activate/Deactivate projection
Allows the laser projection to be activated or deactivated.

Delete projection file
Deletes the projection file.

NOTE

To reload the projection file, use the ‘
OPEN
’ command or reload the entire working.

Load projection file
Allows a new DXF projection file to be loaded.

Increments

These commands, located in the central area on the right side of the interface, allow the tool position to be fine-tuned during a profiling operation.

Increment 0.001
Allows the tool position to be fine-tuned during machining in steps of 0.001mm.

Increment 0.01
Allows the tool position to be fine-tuned during machining in steps of 0.01mm.

Increment 0.1
Allows the tool position to be fine-tuned during machining in steps of 0.1mm.

Decrease tool radius
Pulse to dynamically reduce the tool radius by the selected increment.

Increase tool radius
Pulse to dynamically increase the tool radius by the selected increment.

Commands

The following commands are available in the bottom-right panel in Automatic mode:

Dry Run
Allows DRY RUN mode to be activated or deactivated: the program will be executed without activating the cooling water.

Vacuum pump
Turns the vacuum pump on or off.

Setup
Enables the vacuum cup setup phase on the worktable. When active, the machine executes the cycle that positions the stops and suction cups on the worktable.

Join vacuum zones
When enabled, the two vacuum/blow bars are managed as a single bar. When not selected, the two bars are operated independently.

Lower telescopic devices
Allows the telescopic devices to be lowered.

Raise telescopic devices
Allows the telescopic devices to be raised.

Parking
Allows the machine to be moved to the parking position.
