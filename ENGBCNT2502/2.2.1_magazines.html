    DOC2.2.1 MAGAZINES

    This page is used to view and manage the mounted tool and the tools in the magazines.

    Magazine

    Displays the magazine according to its actual position on the machine.

    Clamp
    Displays the tool held in the clamp associated with the magazine.

    Open magazine
    Opens the magazine.

    Close magazine
    Closes the magazine.

    Mounted Tool

    Displays the currently mounted tool and provides controls for managing several functions.

    Open clamp
    Opens the clamp.

    NOTE

    The “Open clamp” command is executed only after the user confirms the following message:

    Close clamp
    Closes the clamp.

    Measure tool length
    Starts the measurement cycle for the length of the selected tool Edge.

    The selected tool Edge is the one with the following background:

    Measure tool radius
    Starts the measurement cycle for the radius of the selected tool Edge.

    Return tool
    Starts the cycle for returning the mounted tool to its assigned position in the corresponding magazine.

    Commands

    Commands for managing the mounted tool.

    Force mounted tool
    Forces the selected tool as the mounted tool.

    NOTE

    The tool can be selected using:

    Mount tool
    Starts the cycle for picking up the selected tool.

    Manual tool change parking
    Starts the cycle for positioning the machine at the manual tool change position.

    Tool Information

    Displays read-only information about the selected tool.

    Reset tool Edge statistics
    Resets the statistics for the tool Edge.

    Tool management
    Opens the tool management page.
