    The system has been designed to facilitate machine operation and management for the operator. The software allows the operator to:

    • Control the machine manually

    • Send commands/instructions to be executed by the machine

    • Load and run working files

    • Manage the tool magazines

    • Monitor working execution on screen

    • View statistics relating to the machine and the work it has performed

    Upper Section

    Top Bar

    The top bar of the application displays active warning and error messages. The operator can access the Alarms page by pressing the messages.

    Time
    Indicates the current time.

    Message
    Icon indicating the presence of a message.

    Alarm
    Icon indicating the presence of an alarm.

    Error
    Icon indicating the presence of an error.

    Machine Operating Status

    The machine operating status is visible at the top of every page of the application.
    The logo always remains white, while the background can change color depending on the machine operating status.

    The possible operating statuses are listed below:

    Idle
    No working is running and the machine has detected no errors.

    Working
    The machine is operating correctly and is running a working file.

    Error
    The machine sensors have detected errors that prevent operation.

    Warning
    Indicates that there are anomalies that must be checked.

    Side Menu

    The side menu is located on the left and allows navigation between the different program pages.

    Menu
    Expands and collapses the side bar. When the menu is expanded, the page names are visible.

    ISO
    Main page of the application. From this page, the machine can be managed in Manual/MDI/Automatic mode.

    Tools
    Tool magazine management page.

    Alarms
    Page displaying active warnings and errors on the machine and their history.

    Origins
    Page used to view and manage the machine origins.

    Statistics
    Page used to view machine and working statistics.

    Tools
    Page used to view and manage advanced machine tools.

    CadCam
    Allows third-party CadCam software to be opened for creating working files.

    Machine Settings
    Allows access to the system parameters page.

    Bottom Bar

    Utility buttons are located on the right side of the bottom section of each screen, except on the “Machine Settings” page.

    Version
    Indicates the current software version.

    Remote Assistance
    Opens a panel for requesting remote assistance from a Donatoni technician.

    Minimize
    Minimizes the program window.

    Shutdown
    Allows the application to be closed or restarted. Allows the computer to be shut down or restarted.

    Remote Assistance

    Clicking the Remote Assistance button in the bottom bar opens a panel containing the ID and Password to provide to Donatoni technical support when remote connection to the machine is required.

    NOTE

    The Remote Assistance icon and the panel background are green when the system is online and ready for connection, and red otherwise.

    ID
    Field indicating the Remote Assistance session ID.

    Password
    Field indicating the Remote Assistance session password.

    Copy as Image
    Copies an image of the Remote Assistance panel to the clipboard.

    Copy as Text
    Copies text containing the ID and Password required for connection to the clipboard.

    Reload
    Reloads Remote Assistance in the event of a malfunction.

    Close
    Closes the Remote Assistance panel.

    Application/Computer Shutdown/Restart

    Clicking the Shutdown button in the bottom bar opens a window where the user can choose whether to close or restart the application or shut down or restart the computer.
