    DOC2.1 ISO

    This page displays various items of information about the machine status, such as the axis positions and the mounted tool.

    Operating Mode

    There are 3 operating modes, shown in a small panel at the top right.
    The commands displayed on the interface may vary according to the selected operating mode.

    Manual mode
    Sets the operating mode to “Manual”.

    MDI mode
    Sets the operating mode to “MDI”.

    Automatic mode
    Sets the operating mode to “Automatic”.

    Mounted Tool

    On the right-hand side of the interface, immediately below the operating mode selection panel, information about the mounted tool can be viewed and several operations can be carried out:

    Open clamp
    Opens the clamp.

    NOTE

    The “Open clamp” command is executed only after the user confirms the following message:

    Close clamp
    Closes the clamp.

    Clockwise spindle rotation (Manual mode only)
    Sets the spindle rotation clockwise.

    Counter-clockwise spindle rotation (Manual mode only)
    Sets the spindle rotation counter-clockwise.

    Spindle Data

    This panel, located at the top right, displays spindle data such as RPM and delivered torque.

    Feed

    This panel, located on the right, displays the feed rate and override.

    Commands

    The panel in the lower-right area always displays the following buttons:

    Enable commands
    Enables the machine commands by energising the axes.

    Disable commands
    Disables the machine commands by de-energising the axes.
