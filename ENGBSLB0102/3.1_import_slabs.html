    DOC3.1 IMPORT SLABS

    This section describes the optional “Bulk Slab Import” feature, which allows multiple identical slabs to be loaded into the system. The system then manages the numbering of the slab names. This optional feature can be requested for inclusion during the initial installation by our technician.

    When this optional feature is enabled, the “Homepage” screen is displayed as follows:

    Card

    A new selectable card is now displayed:

    Import Slabs
    This card opens a new window similar to 2.3 Edit Slab, with some additional parameters.

    Window

    When the window opens, the following screen is displayed:

    As shown, the screen is similar to the Edit Slab screen, but with some differences.

    Slab preview

    Unlike the other methods used to add a slab to the system (Take Photo and Open Photo), the slab can be loaded without an image by creating a slab simulation consisting of a rectangle that represents the slab dimensions.

    The size of this image is controlled by the parameters in “Bulk Slab Import” (the currently collapsed drop-down menu). Other image data can also be configured, such as the background colour, slab colour and distance of the slab from the bottom edge.

    The slab perimeter can be edited using the basic “Width” and “Length” parameters.

    The Slab Preview becomes the same as in Edit Slab when a slab image is imported using the “Open Photo” button. In this case, the only difference between “Edit Slab” and “Import Slabs” is the ability to import multiple slabs of the same type.

    Parameters

    Most parameters work exactly like those described in the Edit Slab chapter in both cases. The data described below is located in the “BULK SLAB IMPORT” subsection.

    Basic bulk import parameters

    The parameters in this group are displayed both when creating a “virtual” slab and when importing a slab image.

    NOTE

    The “*” symbol next to a name indicates that the parameter is mandatory.

    Progressive code separator
    Inserts the separator in the slab name between the Slab Name parameter and its progressive number.

    From
    Sets the number from which slab numbering starts.

    No. of slab copies
    Sets the number of copies to be created.

    WARNING!

    Enter fewer than 1000 copies.

    “VIRTUAL” slab parameters

    The parameters in this group are displayed when performing a bulk import without an image:

    NOTE

    The “*” symbol next to a name indicates that the parameter is mandatory.

    Image width
    Sets the width of the entire image.

    WARNING!

    This value must be greater than the slab width.

    Image height
    Sets the height of the entire image.

    WARNING!

    This value must be greater than the slab height.

    Background colour
    Sets the background colour of the “virtual” image.

    Slab colour
    Sets the background colour of the “virtual” slab.

    Bottom margin distance
    Sets the distance of the “virtual” slab from the bottom edge of the image.
